# configs/

Конфиги детекторов и экспериментов. Каждый эксперимент ссылается на конфиг по пути и коммиту.

[Статистические основания оценщика](../docs/research/notes/annotation-estimator-statistical-basis.md) описывают ограничения частот и средних. Эти расчёты не являются заданием для разметчика.

`annotation-estimator-policy.json` — общая рабочая политика обработчика и контекста LLM: порог, достаточные сочетания, разрешённые приближения, происхождение статистик и семантика неизвестной персоны/неопределённого вердикта. Подготовленные средние помечены отдельно от подключённых коэффициентов. Сам факт появления таблицы не включает её в оценщик.

Контекст для промпта: `python -X utf8 tools/export_annotation_context.py --output data/reference/annotation-llm-context.json`. Экспорт не читает `.env` и не содержит записей частот реальных ФИО. API-runner добавляет тот же контекст автоматически; SHA-256 политики сохраняется в манифесте. [Уточнения и выбор между промптом и MCP](../docs/project/annotation-context-config-2026-11-18.md).
