# Задача в одном примере

> **Сообщение 1:** «Меня зовут Маша»
> **Сообщение 5:** «…фамилия Смирнова»
> **Сообщение 9:** «…живу на Ленина, 10»

- По отдельности сообщения безобидны, а вместе — утечка ПДн по ФЗ-152
- Обычные фильтры смотрят на одно сообщение и такое пропускают
- **Наш модуль:** на каждом новом сообщении смотрит на всю сессию и ловит момент, когда она стала ПДн
- Заказчик — **Hivetrace**

<!-- ~1.5 мин. Пример синтетический. Отдельная сложность — разные люди: «Маша», «мама Смирнова», «коллега Петров» -->

# Что считается успехом

1. **Датасет** диалогов с разметкой момента, когда сессия стала ПДн
2. **Модуль**, который ловит этот момент: точность по сессиям + задержка в сообщениях
3. **Скорость:** обработка нового сообщения укладывается в бюджет латенси по мере роста сессии

| Оценка | Что нужно                                                                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3            | Работающий код                                                                                                                                         |
| 4            | Разобрались в теме, метриках и edge-кейсах; артефакты на GitHub/HF, документация, skill для запуска |
| 5            | Всё из 4 + публикация (Хабр / Medium / arXiv) после ревью ментора                                                               |

# Как устроена работа: по мотивам CRISP-ML

```
Бизнес-понимание → Понимание данных → Подготовка данных
        ↑                                      ↓
   Оценка качества  ←  Моделирование  ←────────┘
        ↓
  (Вывод в прод → Мониторинг)   ← опционально
```

| Фаза                          | Когда             | Вопрос фазы                                                               |
| --------------------------------- | ---------------------- | ----------------------------------------------------------------------------------- |
| Бизнес-понимание   | Ч1                    | Какую боль решаем, что такое «момент ПДн»?        |
| Понимание данных   | Ч1                    | Какие данные есть, что придётся генерировать? |
| Подготовка данных | Ч1 → Ч2             | Синтетика, разметка, версии датасета                 |
| Моделирование        | Ч2 → Ч3             | Бейзлайны → свой модуль                                         |
| Оценка                      | Ч2 → Ч3             | Метрики, латенси, разбор ошибок                           |
| Прод и мониторинг  | опционально | Демо-сервис, если останется время                       |
