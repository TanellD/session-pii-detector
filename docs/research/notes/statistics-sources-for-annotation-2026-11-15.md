# Источники статистики для правил разметки определяемости

- Проверено: 2026-11-15.
- Назначение: справочник оснований для разметчика, который определяет первый алерт по доступному префиксу диалога. Это не оценка качества детектора и не спецификация готового сервиса.
- Политика: население России; для жёлтых — положительная точечная оценка числа совместимых людей не более 100. Отдельные правила оранжевых ещё открыты.
- Связано: #39, #25; [политика](../../project/alert-policy-proposal-2026-11-13.md).

Практическое дополнение: [рабочий справочник и команды](annotation-statistics-handbook-2026-11-15.md) — нормализованная демография населения России всех возрастов, сводка численности организаций ФНС, исторические имена, варианты правил должностей, адресов и контактов.

## Какие источники пригодны

| Атрибут / сочетание | Источник | Какую величину получаем | Пригодность для разметки |
|---|---|---|---|
| Регион, город, часть сельских населённых пунктов | Росстат, ВПН-2020, том «Численность и размещение населения» | Число жителей территории, также по полу | Прямой счётчик в фиксированном переписном срезе; не актуальное население на сегодня |
| Регион + возрастная группа + пол | Росстат, ВПН-2020, том «Возрастно-половой состав» | Число людей в совместной группе | Предпочтительнее произведения отдельных долей. Точная дата рождения этим не покрывается |
| Муниципалитет + пол / возраст | БД ПМО и региональные таблицы | Опубликованный совместный разрез, если он имеется | Проверять единицу территории и период; район не равен городу, поселение не равно деревне |
| Малое село / деревня | Региональные итоги переписи, при необходимости официальные муниципальные документы | Число жителей конкретного населённого пункта | Требуется отдельно подтвердить полноту и дату; федерального файла недостаточно |
| Имя + регион + год рождения | ЕГР ЗАГС | Регистрации рождений с именем в доступном разрезе | Кандидат для исследования, не готовая доля имени среди нынешних жителей |
| Фамилия, отчество, полное ФИО + регион | Подтверждённого открытого текущего источника не найдено | — | Нельзя подставлять выдуманную частоту или считать отсутствие в рейтинге редкостью |
| Точный адрес | ГАР/ФИАС | Нормализованный адрес и его место в иерархии | Вспомогательный справочник; не число жителей дома или квартиры |
| Телефон / email | Подходящей официальной статистики числа владельцев не найдено | — | Наличие контакта не даёт воспроизводимого числа людей; нужны отдельные правила |
| Организация + должность | Подходящей общей статистики конкретных сотрудников не найдено | — | Отраслевая занятость и вакансии не равны числу людей на данной должности в организации |
| Родство / отношения | Подходящего общего коэффициента не найдено | — | Для принадлежности и контекста; не универсальная доля населения |

Отсутствие подходящего источника означает «по этому справочнику оценка не установлена», а не отрицательный эталон алерта. Имеющаяся статистика может быть достаточна без дополнительных неизвестных признаков; неизвестность одного источника не отменяет независимо сработавшее правило.

## Росстат: федеральные XLSX

### География и пол

- [Каталог тома](https://rosstat.gov.ru/vpn/2020/Tom1_Chislennost_i_razmeshchenie_naseleniya).
- [Прямой XLSX](https://rosstat.gov.ru/storage/mediabank/Tom1_tab-5_VPN-2020.xlsx).
- Доступ: HTTP GET файла; ключ не использовался. Это выгрузка, не REST API поиска жителей.
- Проверка: файл загружен и прочитан локально. Команда и ограничения инспектора:

```powershell
python -X utf8 tools/inspect_geography_population.py --download
```

В таблице есть вложенные итоги. Не суммировать город, содержащий его округ и регион. Совпадения по названию недостаточно: нужны регион, тип объекта и код либо проверенная строка иерархии. Федеральный файл перечисляет сельские населённые пункты только начиная с порога размера, указанного в заголовке, поэтому не даёт полной базы малых деревень.

### Регион, возрастная группа и пол

- [Каталог тома](https://rosstat.gov.ru/vpn/2020/Tom2_Vozrastno_polovoj_sostav_i_sostoyanie_v_brake).
- [Прямой XLSX совместного распределения](https://rosstat.gov.ru/storage/mediabank/Tom2_tab2_VPN-2020.xlsx).
- Доступ: HTTP GET; ключ при проверке не использовался.
- Проверка: файл загружен; прочитаны заголовок и начальные строки. Есть возрастные группы, общее/мужское/женское население, блоки городского и сельского населения. Полная нормализация всех блоков не выполнялась.
- Локальная копия: `data/external/geography/rosstat-vpn2020-age-sex.xlsx`, вне git.
- SHA-256 проверенной копии: `ad87b6b604af7fe957b63f43d3a6d07b6eabb67e9241a820c43d5472aa6840f3`.

Воспроизведение загрузки и проверки:

```powershell
New-Item -ItemType Directory -Force -Path data/external/geography | Out-Null
Invoke-WebRequest -Uri 'https://rosstat.gov.ru/storage/mediabank/Tom2_tab2_VPN-2020.xlsx' -OutFile data/external/geography/rosstat-vpn2020-age-sex.xlsx
Get-FileHash -Algorithm SHA256 -LiteralPath data/external/geography/rosstat-vpn2020-age-sex.xlsx
python -X utf8 -c "from openpyxl import load_workbook; w=load_workbook('data/external/geography/rosstat-vpn2020-age-sex.xlsx',read_only=True,data_only=True); s=w.worksheets[0]; print(s.title); [print(r[:7]) for r in s.iter_rows(min_row=1,max_row=12,values_only=True)]; w.close()"
```

Нужен `openpyxl`. Сохранять также область ячеек и заголовки блока: одна возрастная группа повторяется в разных территориях. Нельзя интерпретировать возрастную группу как точный возраст или делить её равномерно на годы без отдельного соглашения разметки. То же относится к делению года на даты рождения.

## БД ПМО: сайт запросов по муниципалитетам

- [Выбор региона](https://rosstat.gov.ru/storage/mediabank/MUNST.htm).
- [Официальная инструкция](https://rosstat.gov.ru/free_doc/new_site/bd_munst/instruction.htm).
- Доступ: веб-форма, затем экспорт результата в Excel/Word по инструкции Росстата. Документированный стабильный публичный REST API для нашей задачи не подтверждён; CGI веб-формы не объявляется поддерживаемым API.
- Вход: субъект → показатель → тип и выбранные муниципальные образования → год/период.
- Выход: таблица значений показателя для выбранных территорий и периодов.
- Что выбирать: численность населения; доступные возрастно-половые показатели. Перечень и детализация проверяются в каждом регионе.
- Состояние проверки: инструкция и каталог найдены в индексируемой официальной публикации. Сквозной запрос формы и экспорт в текущем окружении не выполнены из-за сетевой недоступности.

Для воспроизводимости разметки экспортировать один согласованный срез заранее, записать фильтры формы и хеш файла. Не поручать разметчикам каждый раз получать живую обновляющуюся таблицу.

В нём для каждого региона указаны сайт управления, найденный тематический раздел или явный пробел, а также координата строки в федеральном XLSX при совпадении. Ниже сохранён первоначальный выборочный разбор содержания публикаций.

Ниже проверены названия и состав публикаций, доступные в индексируемых официальных каталогах. Это выборочная проверка, не аудит всех регионов. Прямое чтение этих страниц из окружения завершилось сетевыми тайм-аутами; региональные файлы ещё не скачаны и их строки не сверены.

| [Новгородская область](https://53.rosstat.gov.ru/vpn_2020) | Переписные таблицы возраста/пола; образование с разрезом по городскому округу, муниципальным округам и районам | Сочетания территории и демографических признаков; образование — возможное будущее расширение | Наличие точного возраста по каждому малому населённому пункту |
| [Архангельская область](https://29.rosstat.gov.ru/main_indicators) | Оценка населения; возрастно-половые показатели муниципальных образований | Более свежие муниципальные группы | Отдельные файлы могут относиться к разным годам; единый свежий совместный срез не подтверждён |

Маршрут проверки остальных регионов: официальный каталог БД ПМО → территориальный Росстат → итоги переписи/раздел населения → файл с нужной единицей территории. Тип «село/деревня/город» уточнять классификатором, а не выводить из числа жителей.

## ГАР/ФИАС: адресный справочник и API

- [Официальное назначение ФИАС у ФНС](https://www.nalog.gov.ru/rn77/service/fias/).
- [Сайт поиска](https://fias.nalog.ru/), [выгрузки](https://fias.nalog.ru/Updates).
- Назначение: установить, что означает адрес, его идентификатор, тип и территориальный контекст. Не устанавливает, кто и сколько людей живёт в помещении.
- Практический путь: выбрать версию выгрузки, использовать нужные адресные объекты и иерархию; полная база домов для одного регионального признака не требуется.

Кандидат для автоматизации метаданных выгрузок:

```http
GET https://fias.nalog.ru/WebServices/Public/GetLastDownloadFileInfo
```

Проверочный запрос:

```powershell
Invoke-RestMethod -Method Get -Uri 'https://fias.nalog.ru/WebServices/Public/GetLastDownloadFileInfo' -TimeoutSec 20
```

Состояние: запрос в этом окружении завершился тайм-аутом. Действующий контракт, авторизация, имена полей ответа и актуальность endpoint не подтверждены. Это не готовая интеграция. До подтверждения использовать официальный сайт выгрузок; не скачивать автоматически большой архив только ради проверки endpoint. API адресов не заменяет статистику населения.

## ЕГР ЗАГС: имена по регионам

- [Аналитика имён](https://zags.nalog.gov.ru/analytics/names/).
- [Описание возможностей ФНС](https://www.nalog.gov.ru/rn77/news/activities_fts/13872282/).
- Доступ: веб-интерфейс с доступными фильтрами региона, периода и пола. Подтверждённого публичного API массовой выгрузки частот не найдено; внутренние запросы веб-страницы не считать официальным API.
- Состояние: назначение и региональная аналитика подтверждены официальным описанием. Интерактивные фильтры, полнота списка и выгрузка не проверены сквозным запросом.
- Ограничение: регистрации рождений с именем не равны нынешним жителям с этим именем. Не переносить частоту детей на взрослое население; не считать долю в опубликованном рейтинге долей во всех рождениях без нужного знаменателя.
- Сочетания имени и отчества упомянуты в описании сервиса подбора; численные совместные частоты ФИО и регионов, пригодные для разметки, этим не подтверждены.

## Как использовать статистику именно при разметке

Рекомендуемая процедура, ещё не принятая как инструкция:

1. Определить человека и смысл атрибута. Адрес банкомата не сужает население для пользователя; город работы не является городом проживания.
2. Взять действующее на этом префиксе состояние: более позднее значение того же атрибута заменяет прежнее без изменения истории разметки.
3. Выбрать зафиксированный источник, соответствующий сочетанию и популяции. Предпочитать готовую совместную ячейку отдельным частотам.
4. Записать число совместимых людей или точечную оценку, способ получения и ограничения; при необходимости сравнить с выбранным порогом.
5. Если источник не покрывает сочетание, отметить отсутствие статистического основания. Не придумывать вес и не считать отсутствующее значение нулём.

Пусть `C_before` — число людей до добавления факта, `C_after` — после. Для уточняющего совместимого факта доля оставшихся — `C_after / C_before`, коэффициент сужения — `C_before / C_after`. Доля от населения страны — `C_after / N_Russia`. Для замены атрибута коэффициент может показывать расширение, а не сужение. При отсутствии знаменателя или положительного результата эти отношения не рассчитываются.

Пример без вымышленных частот: при наличии региона, возрастной группы и пола взять одну соответствующую совместную ячейку. Не умножать население региона на общероссийскую долю пола и общероссийскую долю возраста. Добавление города нельзя оценить по региональной ячейке как будто это уже городской разрез.

Если есть только маргинальные счётчики, минимум этих счётчиков может ограничивать размер пересечения сверху при единой популяции и сопоставимых данных, но не задаёт точечную оценку пересечения. Модель независимости требует отдельного соглашения разметки. Ни один источник в этом обзоре не задаёт такого соглашения за команду.

В карточке основания разметки сохранять: `source_id`, `source_url`, `source_sha256`, `population_date`, `population_scope`, `geo_id`, выбранные строки/ячейки и фильтры, покрытые атрибуты, `count_or_estimate`, `estimation_method`, ограничения и версию правил. Полные агрегаты — вне git по ADR-0002; в репозитории ссылки, команды и описания.

## Практический вывод

География + пол и регион + возрастная группа + пол уже имеют проверенный федеральный источник. Для более мелких территорий найдены региональные кандидаты и маршрут выгрузки. Для полного ФИО, точного адреса проживания и личных контактов оснований для универсального численного правила пока не найдено. Нельзя обещать готовый счётчик по произвольной комбинации атрибутов.
