# Википедия: пилот явно написанных ФИО и доступность имени отца

- Дата: 2026-11-16.
- Статус: выполнен ограниченный сбор; только исследовательская диагностика.
- Связано: [проверка структурированных свойств](wikidata-name-father-2026-11-16.md), [эксперимент](../../experiments/2026-11-16-wikipedia-explicit-fullnames.md).

## Воспроизведение

Все числа ниже получаются командами:

```powershell
python -X utf8 tools/pilot_wikipedia_fullnames.py --download
python -X utf8 tools/pilot_wikipedia_fullnames.py
python -X utf8 tools/pilot_wikipedia_fullnames.py --latest-attempt
```

Сводки вне git: `data/reference/wikipedia-fullname-pilot-2026-11-16.completed.json` — завершённый проход; файл с окончанием `.latest.json` — последняя попытка, включая частичную. Тексты, заголовки, ФИО, идентификаторы элементов и семейные графы на диск не записываются. Версию ответа отмечают время и хеши; повторный сетевой запуск может дать другой результат после изменений источников. Полная сводка восстановлена из вывода первой успешной команды после перезаписи вторым запуском; это сохранённые результаты, не повторный расчёт. Исправленный код сохраняет завершённую сводку отдельно от частичной попытки.

## Что проверено

Одна ограниченная совокупность: человек с гражданством РФ и статьёй в русской Википедии, первые элементы по URI. Условия не доказывают проживание в России, этничность или то, что человек жив.

Начало статей получено через [MediaWiki Action API](https://www.mediawiki.org/wiki/API:Query), модуль [TextExtracts](https://www.mediawiki.org/wiki/Extension:TextExtracts#API). Запросы выполняются последовательно пакетами согласно [рекомендациям API](https://www.mediawiki.org/wiki/API:Etiquette). Три начальных слова распознаются только при поддерживаемом окончании отчества и согласовании частей с заголовком. Это узкий автоматический разбор, без ручной проверки каждого человека. Вложения, изображения и остальной текст статьи не собираются.

| Наблюдение | Количество |
|---|---:|
| Элементы в совокупности; получены начала статей | 500 |
| Поддерживаемые явно написанные ФИО | 468 |
| Начала статей, не прошедшие правило | 32 |
| Элементы с тремя заполненными структурированными свойствами | 15 |
| Из распознанных ФИО также имеют все три свойства | 14 |
| Элементы со связью с отцом | 19 |
| Распознано ФИО ребёнка, ровно один отец и одно русское имя отца | 11 |

Все распознанные написания полного ФИО различаются. При этом повторяются отдельные части. Единица наблюдения — элемент Викиданных, не независимо подтверждённый уникальный человек. Наличие свойств сравнивается с извлечением текста только по доступности: совпадение конкретных значений P735/P734/P5056 с написанием в статье пока не проверено.

Пропуск разбора не равен отсутствию ФИО. Не поддержаны некоторые преамбулы, псевдонимы, альтернативные записи и традиции именования. Частота успешного извлечения относится к этому правилу и этой совокупности, не ко всей Википедии.

## Зависимость частей

Те же строки сравниваются с независимыми перестановками столбцов, сохраняющими их маргинальные частоты. Конфиг: `permutations=499`, `seed=42`. Это разведочная проверка внутри смещённого источника, а не оценка вероятности ФИО жителя России.

| Статистика, биты | Наблюдается | Среднее перестановок | Верхнехвостовое p |
|---|---:|---:|---:|
| Общая зависимость тройки TC | 12,160184 | 12,160269 | 1,000 |
| MI фамилия — имя | 5,986006 | 5,980582 | 0,162 |
| MI фамилия — отчество | 6,062288 | 6,065483 | 1,000 |
| MI имя — отчество | 3,733810 | 3,609348 | 0,002 |

Большое значение TC не доказывает сильную реальную зависимость: при почти уникальных фамилиях оно почти такое же после перемешивания. И наоборот, отсутствие превышения TC не доказывает независимости. Сравнение «имя — отчество» выделяется, но общий пол и поколения могут объяснять часть связи. Дополнительная проверка внутри мужской и женской формы отчества отделена в сводке: форма написания не является независимо подтверждённым полом человека.

Наблюдаемые lift и ошибка произведения на обучающей таблице также сохранены. При редких тройках они сильно отражают малый объём и не являются коэффициентом, которым можно исправить российские частоты. Нулевые клетки нельзя толковать как отсутствие людей.

### Проверка формы отчества: только частичный повторный проход

Повторная попытка получила 200 начал статей и 187 поддерживаемых ФИО. Последующие пакеты вернули HTTP-ошибки; численный HTTP-статус та версия сборщика не сохраняла, поэтому причина отказа не установлена. Повторные запросы после этого не выполнялись. Исправленный сборщик прекращает дальнейшие обращения при отказах доступа или ограничении частоты и сохраняет численный статус.

Команда чтения именно этой попытки: `python -X utf8 tools/pilot_wikipedia_fullnames.py --latest-attempt`.

| Форма написания отчества | Строки | MI имя — отчество, биты | Среднее перестановок | p |
|---|---:|---:|---:|---:|
| Женская | 23 | 3,534219 | 3,547986 | 1,000 |
| Мужская | 164 | 3,256344 | 3,229094 | 0,258 |

Внутри форм превышения перестановочного фона в этой части выборки не обнаружено. Это не доказывает независимости и не объясняет полностью результат первого прохода: объёмы различаются, женская группа мала, пол не подтверждён отдельным полем. Полный проход с таким разделением ещё не выполнен. Приведённые p разведочные, без поправки на множественные сравнения; основанием изменения разметки они не являются.

## Отец и отчество

Для связи используется только явно записанный [P22](https://www.wikidata.org/wiki/Property:P22), затем [P735](https://www.wikidata.org/wiki/Property:P735) и русская метка имени отца. Множественные отцы или имена исключаются из покрытия однозначных пар; декартово произведение значений не создаётся. Отчество из имени отца не достраивается.

Пары пригодны пока для проверки доступности: заявления не проверены по первоисточникам и не учтены родственные кластеры. Коэффициент зависимости имени ребёнка от имени отца не рассчитан. Совпадение морфологии отчества с именем отца само по себе не было бы независимым подтверждением семейной связи.

## Что это даёт разметке

Википедия даёт совместные наблюдения частей ФИО и помогает исследовать зависимости, но не даёт готовой вероятности на всё население России. Основной калькулятор и принятые правила разметки не меняются; ФИО остаётся только в исследовательском режиме.

Следующие пробелы: точность извлечения, проверка согласования текста со структурированными полями, разрезы по поколениям и профессиям, учёт семейных кластеров, внешняя проверка на другом источнике с известным охватом. Увеличение числа биографий без этих проверок не устраняет смещение отбора.
