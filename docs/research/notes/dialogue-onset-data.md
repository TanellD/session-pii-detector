# Данные с моментом возникновения ПДн: близкий аналог

Проверено 09.11.2026 для [#13](https://github.com/TanellD/session-pii-detector/issues/13).

Источник: Yeongseop Lee, Seungun Park, Yunsik Son.
[Early Detection of Re-Identification Risk in Multi-Turn Dialogues via Entity-Aware Evidence Accumulation](https://doi.org/10.3390/app16083680),
Applied Sciences, 2026. Первичный источник: разделы о генерации, приложение с
примерами и промптом, Data Availability Statement.

## Что установлено по публикации

`woz_synthetic` строится шаблонно: каркас диалога и запланированные раскрытия.
`woz_stress` усложняет порядок, расстояние между фактами и упоминания других людей.
В ветке NAME+DIRECT эталон связан с появлением имени и прямого идентификатора;
в quasi-only с завершением запланированного набора признаков.
Это операциональная разметка риска, а не установленный порог по ФЗ-152.

Скрипты доступны по запросу автору. В проверенных источниках открытая выгрузка
не найдена. Примеры английские; русский корпус не подтверждён.
Промпт авторов предназначен для zero-shot-оценки модели, не для few-shot-генерации.

## Использование в проекте

Оставляем источник в пункте 2 с TODO по доступу, языку и качеству.
Без подтверждения русского языка данные могут служить только методическим примером
для создания русской синтетики. Даже при получении корпуса отдельно проверяем
лицензию, правила эталона и происхождение; прямой допуск не предполагается.
