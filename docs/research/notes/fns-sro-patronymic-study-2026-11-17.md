# Отчества и сочетания ИО: исследование ФНС и СРО

Дата: 2026-11-17. Статус: исследовательский пилот для правил разметки, без изменения политики алертов.

**Результат:** оба источника пригодны для наблюдения отчеств и совместных ИО. Независимое произведение имени и отчества не описывает все зависимости. Совместная поправка из фрагмента ФНС дала улучшение на СРО, но универсального коэффициента для России и полного ФИО эти данные не подтверждают.

## Воспроизведение и хранение

Все численные результаты ниже пересчитываются без сети:

```powershell
python -X utf8 tools/study_fns_sro_patronymics.py
```

Выход: `data/private/name-dependence/fns-sro-patronymic-results-2026-11-17.json`. Исходные ФИО и промежуточные минимальные страницы хранятся только в игнорируемой Git папке `data/private/name-dependence/`, по ранее данному разрешению пользователя. Сырые CSV/HTML с дополнительными сведениями, ИНН и номера аттестатов не сохраняются. В консоль выводятся агрегаты.

[Протокол, конфигурация, коммит-основа и тесты](../../experiments/2026-11-17-fns-sro-patronymics.md).

## Что именно получено

**ФНС:** [реестр МСП](https://www.nalog.gov.ru/opendata/7707329152-rsmp/), [выпуск от 10.11.2026](https://file.nalog.ru/opendata/7707329152-rsmp/data-10112026-structure-12052026.zip). Использован уже сохранённый фрагмент: первые читаемые XML-члены архива, только ИП с тремя заполненными частями имени. Это не полный ЕГРИП и не случайная выборка россиян. Дедупликация по ИНН выполнена в памяти при первоначальном получении; ИНН не сохранён.

**СРО:** [реестр Гильдии кадастровых инженеров](https://kadastrsro.ru/index.php/reestr/). Пройдены все 61 доступная страница по штатному параметру `filter[page]`. Выгрузка включает разные статусы членства, не только действующих членов. Получение:

```powershell
python -X utf8 tools/study_fns_sro_patronymics.py --download-sro
```

Из 3 029 строк СРО исключены 165 без поддерживаемого номера аттестата; 54 повторные строки с одинаковыми аттестатом и ФИО свёрнуты; ещё 4 строки из 2 групп с конфликтующими ФИО при одном аттестате исключены целиком. Осталось 2 806 записей. Это согласованные реестровые записи, не доказанная идеальная перепись уникальных людей. Отбор по наличию аттестата может смещать состав по времени получения квалификации. Совпадающее ФИО при разных аттестатах не сворачивается автоматически.

Номера аттестатов заменены локальными хешами. Сохраняются только три части ФИО и этот ключ. Кеш страниц позволяет продолжать сбор после прерывания без повторного скачивания завершённых страниц. Пагинация не является атомарным снимком: изменения источника во время обхода полностью исключить нельзя.

CSV оказался неудобен: большой объём дополнительных полей и медленная передача. В его проверенном фрагменте поле аттестата содержит поясняющий текст, поэтому точное сравнение всей ячейки с номером не срабатывает. Для итогового корпуса использованы подписанные поля HTML, а не предположения о столбцах CSV.

## Повторяемость частей имени

Знаменатель каждой колонки — свой корпус. ФО означает фамилию с отчеством, ИО — имя самого человека с его отчеством. Отчество не восстанавливается из имени отца. Регистр, пробелы и ё/е нормализованы; мужские и женские написания не объединены.

| Величина | ФНС | СРО |
|---|---:|---:|
| Записей для анализа | 9 519 | 2 806 |
| Различных написаний О | 2 080 | 309 |
| Написаний О с частотой ≥5 | 148 | 65 |
| Различных ИО | 5 059 | 1 406 |
| ИО с частотой ≥5 | 366 | 118 |
| ИО с частотой ≥20 | 32 | 2 |
| Доля записей в ИО с частотой ≥5 | 38,74% | 34,93% |
| ФО с частотой ≥5 | 9 | 0 |
| Различных полных ФИО | 9 501 | 2 802 |
| Максимальная частота полного ФИО | 2 | 2 |

Для О и частых ИО уже есть повторяемость, пригодная для пилотной проверки. Полное ФИО почти всегда единично: из этого нельзя получить надёжную поправку на вероятность конкретной тройки. Отсутствующее в корпусе ФИО не означает отсутствие носителей в России.

## Зависимость ИО после учёта формы отчества

Отдельно проверены мужская и женская суффиксальные формы отчества. Это **не независимо наблюдаемый пол человека**; соответствующее поле общего вычислительного кода здесь используется только как техническая группа формы. Неподдерживаемые формы не достраиваются.

В обеих группах обоих источников взаимная информация ИО выше результата перестановки отчеств между записями той же группы. Перестановочный p = 0,005 при 199 перестановках. Следовательно, обнаруженная связь не объясняется одним лишь смешением мужских и женских форм в этих корпусах. Это не размер ошибки национальной вероятности и не доказательство её причины. Прямую взаимную информацию без перестановочного сравнения не интерпретируем: редкие категории сами создают положительное смещение оценки.

Практическая проверка сравнивает произведение маргинальных частот с его смесью с совместной частотой. Доля смеси выбирается на validation, результат считается на test. Пространство исходов — частые пары, выбранные только по train, плюс общая категория OTHER.

| Источник | Минимум пары в train | Улучшение на test | Средняя разность потерь, бит | Средняя доля test в выбранных парах |
|---|---:|---:|---:|---:|
| ФНС | 3 | 5 из 5 разбиений | −0,01807 | 34,49% |
| ФНС | 5 | 5 из 5 разбиений | −0,01510 | 24,40% |
| СРО | 3 | 1 из 5 разбиений | −0,00054 | 32,67% |
| СРО | 5 | 1 из 5 разбиений | +0,00041 | 18,75% |

Отрицательная разность означает улучшение. На СРО поправка нестабильна: в части разбиений validation выбирает нулевую поправку, в других test может ухудшиться. Обнаружить зависимость и достаточно точно оценить её частотную таблицу — разные задачи. Эти разбиения не являются независимыми репликациями и не заменяют интервалы неопределённости.

## Перенос между источниками

При пороге пары 5 и seed 42 поправка, выбранная на ФНС, дала на СРО потери 3,17661 вместо 3,25593 бит: разность −0,07932. Выбранные пары покрывают 980 из 2 806 записей СРО; остальные объединены в OTHER. Это результат на том же пространстве событий, без подбора параметра по СРО.

После исключения 9 записей СРО с полным ФИО, встречающимся в ФНС, улучшение сохраняется: 3,17236 вместо 3,25114 бит, разность −0,07878. Совпадение ФИО не доказывает совпадения человека; исключение служит консервативной проверкой возможного пересечения. Разные написания одного человека таким способом не обнаруживаются.

В обратном направлении validation СРО выбирает нулевую поправку, поэтому результат равен независимому приближению. По одному такому переносу нельзя заявлять универсальную переносимость поправки. Абсолютные потери разных направлений не сравниваются: выбранные наборы пар различаются.

## Что можно использовать для задачи

- О: исследовательский словарь наблюдаемых написаний и частот отдельно для каждого источника. Частоты по двум корпусам не складывать как частоты всего населения.
- ИО: использовать ФНС как основу следующего исследовательского приближения и СРО как отдельную внешнюю проверку. Не назначать каждой паре один общий множитель.
- ФО и ФИО: пока описывать наблюдаемую редкость и разреженность. Не переносить найденную поправку ИО на полное ФИО.
- Для основной разметки эти данные пока не подтверждают оценку «в России ≤100 совместимых людей». Исследовательский режим сохраняется. Отдельное качественное правило полного ФИО остаётся [предложением](../../project/fio-annotation-rule-proposal-2026-11-17.md).

Следующий содержательный шаг — расширять фрагмент ФНС по заранее описанному плану охвата и проверить оценку на ещё одном взрослом реестре с другой профессиональной структурой. Для числа россиян дополнительно нужны обоснование охвата, смещений и неопределённости; само увеличение числа реестровых строк этого не обеспечивает.
