# Зависимости признаков, ФИО, малые населённые пункты и должности

- Дата: 2026-11-15.
- Назначение: основания правил разметки; не оценка NER или детектора.
- [Рабочие решения](../../project/annotation-gap-resolution-2026-11-15.md).

## Пол и возраст

Пол остаётся отдельным атрибутом. Его наличие не означает обязательного множителя «половина населения». Если имя уже почти определяет пол, явное указание того же пола почти не добавляет информации.

Точное правило: P(A, B) = P(A) × P(B | A). Замена условной вероятности на P(B) требует независимости. Это ограничение расчёта, а не дополнительное условие разметки.

Для профессии и пола используем опубликованную совместную ячейку. Для имени и пола нужны совместные либо условные частоты с известным знаменателем. Нельзя дважды применять долю пола: сначала при выборе частоты имени «среди мужчин», затем ещё раз как независимый фильтр.

Возраст не вводим как факт о человеке и не просим разметчика его угадывать. Возрастные группы источника можно объединить с корректными весами для восстановления частот среди всех возрастов. Это внутреннее устройство справочника. Статистика новорождённых без восстановления живущих поколений не равна статистике всех жителей.

## ФИО и исследовательский режим

Объединение фамилии, имени и отчества в ФИО — операция над активным набором атрибутов одного человека. Исторические упоминания сохраняются. Если оценка уже использует ФИО, повторно умножать её на частоты частей нельзя: это повторный учёт тех же сведений.

Объединение не доказывает независимость частей. Точная цепочка:

```text
P(Ф, И, О) = P(Ф) × P(И | Ф) × P(О | Ф, И)
P(Ф, И, О, пол) = P(Ф, И, О) × P(пол | Ф, И, О)
```

Части могут зависеть через пол, регион, языковые традиции и семейное происхождение. Даже условную независимость после учёта этих факторов нужно проверять на данных.

Аудит нынешних словарей обнаружил различные суммы записей и дубли после нормализации; охват живущего населения не подтверждён, проверенный совместный справочник полных троек не найден. Воспроизведение: `python -X utf8 tools/audit_name_frequencies.py`.

«Исследовательский режим» означает: частоты можно изучать и сравнивать как неподтверждённое приближение, но ими нельзя обосновывать эталонный алерт основной разметки. Калькулятор сохраняет ФИО и сообщает о недостатке данных для этого расчёта. Другие достаточные правила, например красный маркер, действуют. Это не вывод «ФИО не сужает круг» и не запрет размечать ФИО.

## Малые населённые пункты

Пользователь подтвердил временное правило: для конкретного идентифицированного пункта с подтверждённой численностью не более 5 000, если точного значения нет, используем 5 000 как явно указанное консервативное приближение.

В API атрибута geography нужны `specific_settlement_under_5000_confirmed: true`, непустой `population_bound_source` (источник и дата), название конкретного пункта в `value` и роль проживания. Пользователь интерфейса подтверждает эти условия отдельно. Отсутствие строки, тип «деревня» и геокодирование сами по себе предел не подтверждают. Источник должен позволять отличить пункт от одноимённых. Опубликованное значение выбранной территории имеет приоритет; дополнительного уменьшения по полу для этого приближения нет.

Если известно только «живёт где-то в пункте до пяти тысяч», круг включает жителей всех подходящих пунктов на известной территории. Он не равен 5 000. Средний размер пункта для случайного жителя требует веса численности, а не обычного среднего по пунктам. Группированные таблицы не дают точной суммы квадратов размеров отдельных пунктов.

Дополнять справочник следует региональными таблицами по отдельным пунктам, затем группировками для оценки охвата. Примеры официальных группировок: [Бурятия](https://03.rosstat.gov.ru/storage/mediabank/pub-01-01_%D0%A2%D0%B5%D1%80%D1%80%3D81000000.pdf), [Смоленская область](https://67.rosstat.gov.ru/storage/mediabank/05%20%D0%93%D0%A0%D0%A3%D0%9F%D0%9F%D0%98%D0%A0%D0%9E%D0%92%D0%9A%D0%90%2B%D0%A1%D0%95%D0%9B%D0%AC%D0%A1%D0%9A%D0%98%D0%A5%2B%D0%9D%D0%90%D0%A1.pdf). Они найдены в официальном поисковом индексе; полный импорт и даты статистического среза этих файлов ещё не проверены. Категория размера пункта не решает оценку населения улицы.

## Соответствие должностей

Расширен [словарь](../../../configs/occupation-okz-mapping.json). Это авторское проверяемое соответствие распространённых русских названий опубликованным укрупнённым группам, не полный официальный индекс. Основа: [структура и индекс МОТ](https://ilo.int/public/english/bureau/stat/isco/isco08/index.htm), [определения классификации](https://ilostat.ilo.org/methods/concepts-and-definitions/classification-occupation/), [российское кодирование РМЭЗ НИУ ВШЭ](https://www.hse.ru/rlms/codifiers/isco/). Последний источник прямо объясняет роль обязанностей и квалификации, включая неоднозначность медсестёр.

| Название / обязанности | Опубликованная группа ОКЗ |
|---|---|
| Инженер-проектировщик, архитектор, графический дизайнер | 21 |
| Врач / учитель / бухгалтер / программист / юрист | 22 / 23 / 24 / 25 / 26 |
| Техник-электрик / фельдшер / страховой агент / фотограф / техник компьютерных сетей | 31 / 32 / 33 / 34 / 35 |
| Секретарь / банковский кассир / складской учёт | 41 / 42 / 43 |
| Повар / продавец / няня / охранник | 51 / 52 / 53 / 54 |
| Каменщик / сварщик / ювелир / электромонтажник / пекарь | 71 / 72 / 73 / 74 / 75 |
| Оператор установки / сборщик электрооборудования / водитель | 81 / 82 / 83 |
| Уборщик / сельскохозяйственный подсобный рабочий / грузчик | 91 / 92 / 93 |
| Помощник повара / уличный продавец непродовольственных товаров / дворник | 94 / 95 / 96 |

Для неоднозначных названий возвращаются варианты и вопрос об обязанностях. Автоматического выбора самой редкой группы нет. Неизвестное название остаётся неопределённым, а не получает нулевую частоту.

Частота всей группы — приближение для входящего в неё названия. Наличие слова «кардиолог» не означает отдельной частоты кардиологов. Детализация ограничена принятой таблицей; полный официальный российский классификатор со всеми изменениями не импортирован. Новые соответствия требуют предметной проверки по обязанностям.

Полный словарь и его размеры: `python -X utf8 tools/estimate_occupation_candidates.py --list-mapping`. Пример уточнения: `python -X utf8 tools/estimate_occupation_candidates.py --occupation логист`.

## Как получить зависимости

Первый источник — [каталог Росстата по рабочей силе](https://rosstat.gov.ru/labour_force/). Поисковый индекс показывает микроданные за 2024 и 2025 годы. Файлы, состав полей и веса ещё не проверены: заголовок не доказывает наличие любого среза. Найден также [сборник «Труд и занятость в России — 2025»](https://rosstat.gov.ru/storage/mediabank/Trud_2025.pdf), индексирующий таблицу распределения по полу и занятиям за 2024 год. Источник калькулятора пока не заменён без проверки нового.

Порядок исследования:

1. Проверить кодбук: занятие и версия классификатора, пол, субъект РФ, тип поселения, занятость, вес, период и охват. Возраст не использовать как индивидуальный фильтр.
2. Рассчитать взвешенные таблицы «регион × профессия × пол», суммируя все доступные возраста. Доступ и обработка микроданных требуют проверки условий и приватности; строки людей в репозитории не сохранять.
3. Использовать совместное абсолютное число напрямую, если оно доступно. Для условных долей согласовать знаменатель: долю среди занятых нельзя умножать на всех жителей без учёта занятости.
4. Сравнить P(профессия | регион, пол) с P(профессия) либо отношение совместной частоты к произведению маржинальных. Проверять объём выборки и устойчивость, а не только статистическую значимость.
5. Отсутствие наблюдений малой группы не считать отсутствием людей. Укрупнять группы или исследовать сглаживание. Объединяя волны, учитывать повторное участие, изменения весов и классификаторов.
6. Сверить агрегаты с опубликованными итогами; только затем обновлять справочник и расчёты около порога.

Резерв — [документация РМЭЗ НИУ ВШЭ](https://www.hse.ru/rlms/doc). Это обследование, не реестр жителей каждого села; наличие профессии не гарантирует региональную репрезентативность. Состав конкретного работодателя остаётся отдельным пробелом: региональная частота не заменяет штат организации.

## Готовые работы

[Rocher, Hendrickx, de Montjoye (2019), Estimating the success of re-identifications in incomplete datasets using generative models](https://doi.org/10.1038/s41467-019-10933-3) оценивают идентифицируемость с учётом зависимости признаков через генеративную модель на копулах. Это источник метода, не готовые российские коэффициенты. Риск реидентификации также не тождествен нашему продуктовому порогу числа совместимых людей.

Для MVP предпочтительнее объяснимые совместные таблицы и условные частоты. Сложный метод имеет смысл при подходящих данных и проверке оценок. Это исследование оснований разметки, не обучение детектора ПДн.
