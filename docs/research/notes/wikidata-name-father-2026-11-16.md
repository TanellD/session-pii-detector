# Википедия и Викиданные: имя, фамилия, отчество и имя отца

- Дата: 2026-11-16.
- Статус: проверены свойства и выполнен ограниченный агрегатный запрос покрытия; корпус персональных записей не собирался.

## Доступные связи

Викиданные предоставляют свойства [имя P735](https://www.wikidata.org/wiki/Property:P735), [фамилия P734](https://www.wikidata.org/wiki/Property:P734), [патроним/матроним P5056](https://www.wikidata.org/wiki/Property:P5056), [отец P22](https://www.wikidata.org/wiki/Property:P22). Связка P22/P735 даёт имя отца, когда заполнены обе записи. P5056 шире русского отчества и требует проверки конкретной традиции именования.

Отчество не равно имени отца буквально. Производное отчество может требовать морфологических исключений; семейная связь не доказывает официальную форму отчества. Различать три уровня: явно наблюдаемое отчество, явно записанное имя отца, вычисленная форма. Если отчество получено из имени отца, нельзя затем использовать его как независимое подтверждение правильности той же связи.

Для проверки зависимости имени и отчества отец вообще не обязателен: достаточно достоверно извлечь обе части одного ФИО. Связь с отцом полезна для происхождения отчества и межпоколенческого исследования. Для зависимости имени ребёнка от имени отца нужен отдельный набор реальных пар, не искусственная генерация.

## Выполненный запрос

Проверен [официальный SPARQL-сервис](https://www.wikidata.org/wiki/Wikidata:SPARQL_query_service). Запрос возвращает только общие счётчики; имена и идентификаторы людей не запрашиваются в результате.

```powershell
python -X utf8 tools/check_wikidata_name_coverage.py --download
python -X utf8 tools/check_wikidata_name_coverage.py
```

Запрос: `configs/wikidata-name-coverage.sparql`. Результат: `data/reference/wikidata-name-coverage-2026-11-16.json`, вне git. Все числа ниже воспроизводятся указанными командами.

| Проверка | Количество |
|---|---:|
| Элементы в ограниченном запросе | 500 |
| Заполнено имя | 243 |
| Заполнена фамилия | 128 |
| Заполнен патроним/матроним | 25 |
| Заполнены все три свойства | 15 |
| Есть связь с отцом | 19 |
| Через отца доступно его имя | 13 |

Это первые по URI элементы, удовлетворяющие условиям «человек, гражданство РФ, статья в русскоязычной Википедии», а не случайная выборка. Числа не оценивают полноту Викиданных в целом или свойства населения. Наличие свойства не гарантирует единственного значения, русской метки и подтверждённой формы ФИО. Наличие имени отца не гарантирует заполненности имени самого ребёнка: соответствующие счётчики не являются готовым числом полных пар.

## Ограничения определения совокупности

Русская статья, российское гражданство, этничность, рождение в России и проживание в России — разные условия. Выбранное гражданство использовано только как явный воспроизводимый фильтр проверки, не как замена целевому населению. Исторические гражданства и периоды нельзя молча смешивать.

Отсутствие даты смерти не доказывает, что человек жив. Известные биографии и особенно заполненные семейные связи могут отражать отдельные профессии, поколения и семьи. Несколько детей одного отца требуют учёта семейных кластеров при статистической проверке; их нельзя считать полностью независимыми наблюдениями.

## Как продолжать сбор

Сначала извлекать явно написанное ФИО из статьи либо согласованные свойства Викиданных. Сохранять происхождение каждого поля и неоднозначность. Русская метка элемента фамилии может обозначать общую фамилию, а не точную половую форму человека; её нельзя автоматически подставлять как наблюдаемую строку ФИО.

Связь с отцом проверять через отдельный элемент и источники утверждения. Не восстанавливать неизвестных родителей из одного отчества. Множественные имена, псевдонимы и разные фамилии требуют явного правила выбора значения, иначе соединение свойств создаст несуществующие комбинации.

Для исследования считать отдельно пары «имя — фамилия», «имя — наблюдаемое отчество» и «имя ребёнка — имя отца». Учитывать пропуски и сравнивать зависимости с перестановочным фоном. Не переносить частоты известных биографий на всех жителей России без внешней проверки.

Основной калькулятор пока не получает новых коэффициентов ФИО. На диск допустимы только сводные агрегаты без персональных записей и семейных графов согласно ADR-0002.

Продолжение выполнено: [пилот явно написанных ФИО в начале статей](wikipedia-explicit-fullnames-2026-11-16.md). Он отдельно проверяет извлечение текста, перестановочный фон и доступность однозначных связей с отцом.
