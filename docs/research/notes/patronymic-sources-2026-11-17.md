ФНС и очищенные реестровые словари могут иметь пересекающееся происхождение. Их согласие не считать независимым подтверждением. Профессиональный реестр другой отрасли полезнее для внешней проверки переносимости, но тоже не становится выборкой населения России.

## Важное различие в очищенном наборе

В авторском описании `fname` у отчества обозначает имя, от которого образовано отчество, то есть имя отца. Это не имя носителя отчества. Таблица соответствия «имя отца → отчество ребёнка» не даёт совместного распределения «имя самого человека → его отчество».

`regorgs` связан с кодами ИНН организаций/ИП, а `regfl` — с кодами ИНН физлица. Эти признаки нельзя автоматически называть текущим регионом проживания. Отсечение редких форм означает, что отсутствие строки не равно отсутствию носителей. До чтения самих файлов и выяснения знаменателя частоты остаются исследовательскими.

## Проверка форматов без сохранения персональных строк

Добавлен проверяющий скрипт, который читает XSD ФНС и CSV СРО с ограничением размера ответа. Он сохраняет только структуру, хеши и агрегаты. Имена, номера аттестатов и исходные строки таблицы не сохраняются и не печатаются.

```powershell
python -X utf8 tools/check_patronymic_source_formats.py --download
# Прочитать сохранённый результат без сети:
python -X utf8 tools/check_patronymic_source_formats.py
# Синтетические проверки:
python -X utf8 -m unittest discover -s tests -p 'test_patronymic_source_formats.py'
```

Результат: `data/private/name-dependence/patronymic-source-formats-2026-11-17.json`. При недоступности источника фиксируется отказ, без вывода содержимого исключений. Проверка структуры ещё не является сбором репрезентативного корпуса и не подтверждает национальные частоты.

## Предлагаемый порядок дальнейшей работы

Сначала расширять наблюдаемые тройки из одного выпуска реестра МСП ФНС: этот путь уже опробован и не требует токенов социальных сетей. Из одного согласованного массива строить О, ИО, ФО и ФИО, сохраняя общий знаменатель и способ дедупликации. Отчество «при наличии» не исключать молча из знаменателя, когда оценивается доля во всей исходной совокупности.

Параллельно добиваться доступа к очищенному словарю для проверки написаний и маргинальных частот. Профессиональные реестры использовать как отдельный проверочный срез после удаления повторных записей; не смешивать все источники в одну частоту. Википедия и уже найденные университетские документы остаются дополнительными источниками наблюдаемых ИО и ФИО, с сильными ограничениями состава и времени.
