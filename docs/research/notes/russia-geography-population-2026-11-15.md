## Воспроизведение

Нужен Python с `openpyxl`. Из корня репозитория:

```powershell
python -X utf8 tools/inspect_geography_population.py --download
```

Файл сохраняется в исключённый из git `data/external/geography/`. Уже имеющаяся копия не перезаписывается. Выход содержит URL, SHA-256, лист и номер строки, население и долю от страны. Загруженная при проверке копия имеет SHA-256:

`0b232b3d2ab5daa231568acc719ac6fda4fb0979a01a0da6bacc69be6f252474`.

Выбор точных названий строк:

```powershell
python -X utf8 tools/inspect_geography_population.py --name "Белгородская область" --name "г. Валуйки"
```

Скрипт служит инспекцией исходной таблицы, а не готовым географическим резолвером. Если одинаковые названия повторяются, он возвращает все совпадения с координатами строк; выбирать территорию без контекста нельзя. Неизвестное название не получает нулевую численность.

## Предлагаемая структура географического слоя

Для пользователя: страна → субъект (область, республика и другие типы) → город/сельский населённый пункт → более точный адрес. Внутри модели хранить отдельно адресную/административную и муниципальную иерархии; не предполагать, что у всех объектов одинаковый набор промежуточных уровней.

У географического объекта: `geo_id`, `name`, `type`, `region_id`, `parent_id`, `gar_id`, `oktmo`, `okato`, `valid_from`, `valid_to`. Для города, села, деревни, посёлка и других типов сохранять исходный тип, а не выводить его по размеру населения.

У статистического наблюдения: `geo_id`, `population`, `population_date`, `source_url`, `source_sha256`, `source_row`, `coverage_status`. Код без ведущих нулей теряет идентичность: коды хранить строками. Несколько источников не сливать только по названию.

Для географии проживания доля страны — `population(geo) / population(Russia)` в одном согласованном срезе. Уточнение региона до города заменяет широкое условие узким, а не умножает две вложенные доли. Если город не разрешён однозначно, учитывать объединение совместимых территорий с исключением дублей либо сохранять оценку неизвестной.

Место работы, поездка или место рождения не означают текущее проживание. Их нельзя фильтровать статистикой жителей как будто это один атрибут.

## Что ещё нужно сделать

Собрать и проверить региональное покрытие малых населённых пунктов; связать идентификаторы классификаторов и статистики, обработать переименования и объединения; выбрать фиксированную дату и территориальный охват базовой популяции; затем считать доли. Данные разных периодов можно использовать лишь с явным описанием приближения. ВПН-2020 не выдаётся за актуальное население.

Прямые каталоги Росстата при проверке возвращали тайм-ауты либо HTTP 403; прямой XLSX удалось получить через стандартный `urllib` с проверкой сертификата. Сбор полноценной базы не завершён. Персональные записи не загружались.
