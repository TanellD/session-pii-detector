# Расширение статистики ФИО по открытым документам

- Дата: 2026-11-16.
- Основание: пользователь подтвердил начало с открытых документов без API соцсетей.
- Статус: выполненное исследование ограниченного набора публикаций; основная разметка не изменена.
- [Предыдущий пилот](public-fullname-source-pilot-2026-11-16.md), [реестр направлений](../../../configs/fullname-source-candidates.json).

## Воспроизведение

```powershell
# Показать сохранённую сводку и пересчитать поправку множественных проверок.
python -X utf8 tools/batch_public_fullname_statistics.py
# Повторить ограниченный сбор фиксированных страниц; результат зависит от их текущего состояния.
python -X utf8 tools/batch_public_fullname_statistics.py --download
```

Все измеренные числа этого отчёта воспроизводятся этими командами. Результат: `data/reference/public-fullname-batch-2026-11-16.json`, вне git. В нём зафиксированы URL, хеши HTML, параметры перестановок, статистики выпусков и учреждений. HTML, ФИО и словари соответствий анонимных категорий не сохранены. Если публикация изменится, её новый хеш отличится; воспроизведение старых результатов опирается на сохранённую числовую сводку, не архив персональных записей.

## Охват и извлечение

| Источник | Выбранные выпуски | Клетки/блоки для извлечения | Поддержанные полные ФИО | Неподдержанные записи | Различные полные написания |
|---|---|---:|---:|---:|---:|
| МГУ, кафедра системного анализа ВМК | Магистратура 2020–2025 | 54 | 53 | 1 | 47 |
| ТГУ, кафедра ботаники | Заголовки годов 2010–2025 | 135 | 118 | 17 | 118 |

Всего поддержана 171 строка. Это количество записей, не подтверждённая численность уникальных людей. Кандидат с двумя частями или дополнительными вариантами написания не получает угаданное отчество. Неподдержанные записи не означают ошибку источника: правило извлечения намеренно узкое.

МГУ: фиксированные ссылки из [архива](https://sa.cs.msu.ru/alumni), ФИО извлекается только из одноимённой колонки таблицы. Подписи фотографий, научные руководители и контакты не входят в подсчёт. ТГУ: [архив кафедры](https://bot.tsu.ru/department/graduates/), извлекаются выделенные написания под выбранными заголовками годов. Страница содержит и более ранние поколения; они не включены в этот прогон. Состав выпускников, полнота архивов и принадлежность всех строк живущему населению не подтверждены. Два учреждения не объединяются в национальный знаменатель.

Архив [НГУ](https://hf.nsu.ru/alumni.html) найден через веб-поиск, но локальный запрос не прошёл; в численные итоги не включён. Не использовать выдачу поисковика как полный список выпускников.

## Совпадения между выпусками

В МГУ найдены совпавшие написания между выпусками 2020/2022, 2023/2024, 2024/2025; количества соответственно 1, 3 и 2. Причина не установлена: возможны повторная публикация, особенности страницы, разные люди с одинаковым ФИО или повторное обучение. Автоматического объединения людей не производится.

Для проверки чувствительности дополнительно посчитан вариант «одна запись каждого полного написания». Это математический сценарий, не дедупликация людей. В ТГУ в поддержанных строках повторных полных написаний не найдено; это не доказывает отсутствие повторов за пределами поддержанного формата.

## Зависимости и перестановочный фон

Использованы 499 перестановок с seed 42. Порядок строк предварительно канонизируется, поэтому повторная передача тех же строк в другом порядке не меняет фон. Проверки каждой пары и TC ограничены совокупностями опубликованных строк.

| Показатель | МГУ | ТГУ |
|---|---:|---:|
| TC, биты | 9,6134 | 10,5106 |
| Средняя TC после перестановок | 9,3871 | 10,5106 |
| Перестановочное p для TC | 0,002 | 1,000 |
| p для TC в сценарии одной записи каждого написания | 1,000 | 1,000 |
| MI имени и отчества, биты | 4,1119 | 3,8039 |
| Средняя MI имени и отчества после перестановок | 3,9127 | 3,7201 |
| Непоправленное p имени и отчества | 0,002 | 0,012 |

В МГУ вывод о TC чувствителен к повторным написаниям. Нельзя переносить эту разницу в поправку частоты реальных людей. В ТГУ общая TC неотличима от фона; для пары имени и отчества есть исследовательский сигнал, который требует отдельной проверки.

Команда показа сводки применяет поправку Бонферрони к четырём объединённым показателям каждого учреждения: размер семейства равен 8. Для пары имени и отчества ТГУ скорректированное p равно 0,096. При обычном ориентире 0,05 это не подтверждённый результат. Покогортные и чувствительные сценарии остаются диагностическими; множество всех возможных проверок ещё шире, так что их нельзя выбирать постфактум как доказательство.

Большая эмпирическая TC здесь в основном отражает разреженность таблиц. Ни сырая TC, ни статистическая значимость не задают коэффициент числа носителей ФИО. Явный пол источники не предоставляют в проверенных колонках; отделить зависимость через пол от других причин этим прогоном нельзя.

## Что готово и что дальше

Готов ограниченный сбор без персональных записей на диске, раздельные совокупности, отчёт о неподдержанных формах, совпадения между выпусками, перестановочный фон и сценарий чувствительности. Отказы доступа не обходятся; сетевой сбой допускает один повтор. Полнота обработки фиксированного списка помечается отдельно: отказ не становится нулевым количеством выпускников.

Для следующего расширения нужны большие структурированные списки с повторяющимися именами и отчествами, разные учреждения и подтверждение причин повторов в публикациях МГУ. Каталоги только лучших выпускников не смешивать с полными списками. Пока нет подтверждённого основания ни для общероссийских частот ФИО, ни для универсального коэффициента независимости. Возрастные свойства выборки рассматриваются как ограничение переносимости и не добавляют возраст в классы разметки.
