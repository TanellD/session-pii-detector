## К ментору
1. Что считается «моментом, когда сессия стала ПДн»? Ментор ждёт, что нарушение будет привязано к конкретному сообщению, но формального определения не дал — готовим своё в #10 и согласуем.
2. Какие данные доступны: только синтетика или есть обезличенные сессии HiveTrace?
3. На каком уровне считать F2: по сессиям, по моменту нарушения, по сообщениям? Как он сочетается с задержкой срабатывания?
4. Входят ли сессии агентов (harness вроде Claude Code: код, логи, вывод инструментов) в MVP или это перспектива?
5. Можно ли модулю вызывать внешние API (например, стороннюю LLM)? Мы исходим из полностью локальной работы — в ответе это не подтверждено явно.
6. regex + GLiNER — требование совместимости с продом HiveTrace или совет для быстрого старта?
7. Можно ли получить пример ответа NER API HiveTrace, чтобы сделать `session_verdict` совместимым?
8. Сбрасывается ли `session_verdict` после нарушения, или сессия остаётся помеченной навсегда?
9. «Сообщение или список сообщений» на входе: список — это пакетная отправка истории (нужен вердикт на каждое сообщение) или одна реплика из нескольких частей?
10. Каков формат защиты Talent Hub?
11. Какая площадка публикации предпочтительнее?

## Внутри команды
