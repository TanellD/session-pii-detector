## Приложение: черновик контракта сервиса

Гипотеза для обсуждения; детали контракта — в задаче #12 (`Kopylov-Andrey`).

**Запрос** — на каждое новое сообщение:

```json
{
  "session_id": "s-123",
  "message_id": 7,
  "role": "user",
  "text": "Мой номер 8-900-000-00-00, я Маша из бухгалтерии",
  "previous_assistant_message": "Как с вами связаться?"
}
```

- `role`: `user`, `assistant` или `tool` (вывод инструментов в harness).
- `previous_assistant_message` — опционально (вопрос 7).
- Список сообщений обрабатываем как пакет: по каждому вернём отдельный ответ в порядке `message_id`.

**Ответ** — формат NER плюс `session_verdict`:

```json
{
  "session_id": "s-123",
  "message_id": 7,
  "entities": [
    {"type": "PHONE", "start": 10, "end": 25, "score": 0.98, "zone": "orange", "person_id": "p1"},
    {"type": "FIRST_NAME", "start": 29, "end": 33, "score": 0.95, "zone": "yellow", "person_id": "p1"},
    {"type": "WORKPLACE", "start": 37, "end": 49, "score": 0.81, "zone": "yellow", "person_id": "p1"}
  ],
  "message_verdict": {"has_pii": true, "max_zone": "orange"},
  "session_verdict": {
    "is_pii": true,
    "level": "alert",
    "first_violation_message_id": 7,
    "persons": [
      {
        "person_id": "p1",
        "alert": true,
        "rule": "score",
        "score": 0.86,
        "markers": [{"message_id": 7, "type": "PHONE"}, {"message_id": 7, "type": "FIRST_NAME"}, {"message_id": 7, "type": "WORKPLACE"}],
        "special_category": false
      }
    ]
  }
}
```

- `level`: `none` — ПДн нет; `warning` — скор выше заданной доли порога, раннее предупреждение; `alert` — нарушение.
- `rule` — почему алерт: `red_marker` (красный маркер), `two_orange` (два оранжевых), `score` (скор выше порога).
- `persons` — уровень и скор по каждому человеку в сессии.

**Что хотим уточнить:**
- Совпадает ли `entities` с форматом вашего NER API (поля, названия типов, смещения в символах)?
- Где хранить состояние сессии: на нашей стороне по `session_id` (тогда нужен срок хранения), или HiveTrace передаёт состояние в каждом запросе?
- Нужны ли `persons` и `score`, или достаточно `is_pii` и номера сообщения нарушения?
