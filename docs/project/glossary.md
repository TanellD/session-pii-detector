# Глоссарий

Пополняется по ходу исследования. Сюда попадают только термины, о значении которых команда договорилась.

| Термин | Значение у нас | Источник / дата |
|---|---|---|
| Сессия | Последовательность сообщений для решения запроса пользователя, объединённая `session_id`. MVP рассматривает чат-бота; состав ролей для оценки фиксируется конфигурацией. | PR #19, уточнение протокола |
| ПДн | Персональные данные в смысле ФЗ-152 | ФЗ-152, ст. 3 |
| Маскирование ПДН (PII-redaction) | Процесс, в результате которого происходит затруднение понимания ПДн — средства обезличивания и применения псевдонимов, которые устраняют, уменьшают, маскируют или обезличивают ПДн либо предотвращают ненужную, несанкционированную и (или) нежелательную обработку ПДн, но не ограничиваются ими. | ГОСТ ISO/IEC 29100-2021 |
| Уровень одного сообщения (turn-level) | Традиционное извлечение ПДн, концентрирующееся на одном конкретном сообщении и не связывающее части большого диалога вместе | |
| Уровень сессии (cross-turn) | Извлечение ПДн на всех сообщениях сессии пользователя с LLM/агентом | |
| Совокупная утечка ПДн (СУП) (Cumulative PII Exposure (CPE)) | Накопление в рамках сессии (cross-turn) утечек ПДн и формирования при их суммировании идентифицируемого личного профиля | [S17] |
| Изоляция сущностей (entity isolation) | Хранение разных типов сущностей (личностей, чьи ПДн в сумме могут слиться в четкий портрет) по отдельности, чтобы они не сливались друг с другом. Это позволит избежать влияния информации об одной сущности на идентифицируемость другой.| |
| Триггер (trigger), эталонный момент | Первое сообщение `t_gold`, на котором по версионированной эталонной политике требуется алерт с учётом доступного префикса сессии. Не обязан определяться только числовым скором. | [Метрики](../kb/metrics.md) |
| Атрибут | Типизированные сведения, которые могут принадлежать одному или нескольким людям. Для оценки первой версии единица — упоминание атрибута с границами в тексте. | Проект протокола PR #19 |
| Человек | Владелец атрибутов, представленный локальным ID в сессии; совпадение номеров ID эталона и предсказания не требуется. | Проект протокола PR #19 |
| Неопределённо | Служебная группа атрибутов с неизвестной принадлежностью; не утверждает единого владельца. | Проект протокола PR #19 |
| Unknown | Неуверенный эталон сессии, мешающий установить необходимость алерта или первый момент; учитывается отдельно от положительных и отрицательных. | [Метрики](../kb/metrics.md) |
