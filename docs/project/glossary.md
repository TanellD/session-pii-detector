# Глоссарий

Пополняется по ходу исследования. Сюда попадают только термины, о значении которых команда договорилась.

| Термин | Значение у нас | Источник / дата |
|---|---|---|
| Сессия | Диалог пользователя с большой языковой моделью (LLM), который состоит из нескольких следующих друг за другом взаимосвязанных запросов и ответов с сохранением предыдущего контекста беседы | |
| ПДн | Персональные данные в смысле ФЗ-152 | ФЗ-152, ст. 3 |
| Маскирование ПДН (PII-redaction)| Процесс, в результате которого происходит затруднение понимания ПДн - средства обезличивания и применения псевдонимов, которые
устраняют, уменьшают, маскируют или обезличивают ПДн либо предотвращают ненужную, несанкционированную
и (или) нежелательную обработку ПДн, но не ограничиваются ими.| ГОСТ ISO/IEC 29100-2021 |
| Уровень одного сообщения (turn-level) | Традиционное извлечение ПДн, концентрирующееся на одном конкретном сообщении и не связывающее части большого диалога вместе | |
| Уровень сессии (cross-turn) | Извлечение ПДн на всех сообщениях сессии пользователя с LLM/агентом | |
| Совокупная утечка ПДн (СУП) (Cumulative PII Exposure (CPE)) | Накопление в рамках сессии (cross-turn) утечек ПДн и формирования при их суммировании идентифицируемого личного профиля | [S17] |
| Изоляция сущностей (entity isolation) | Хранение разных типов сущностей (личностей, чьи ПДн в сумме могут слиться в четкий портрет) по отдельности, чтобы они не сливались друг с другом. Это позволит избежать влияния информации об одной сущности на идентифицируемость другой.| |
| Триггер (trigger) | Сообщение, после которого score СУП для какой-либо сущности превышает допустимый порог безопасности. | |
