# Постановка задачи (по описанию ментора)

## Проблема
Каждый запрос в LLM может содержать безобидные данные: сначала пользователь шлёт своё имя, а потом в следующем сообщении добавляет фамилию. Изолированно эти данные ни о чём не говорят, а вместе являются утечкой ПДн по ФЗ-152.

ПДн — всё, что попадает под ФЗ-152, от телефонов и адресов до медицинских данных.

## Задача
Разработать модуль, который анализирует сессию пользователя при каждом новом сообщении и складывает безобидные сигналы, с быстрой обработкой.

Отдельный вопрос — линковка сущностей: «Меня зовут Маша» … «у мамы фамилия Смирнова» … «а коллега Петров». В контексте речь о трёх разных людях: в какой момент мы уверены, что это точно ПДн, а когда нет?

## Критерий успеха
1. Собран набор диалогов, где размечен момент, когда сессия становится ПДн.
2. Модуль ловит этот момент (точность по сессиям, задержка в сообщениях).
3. Время обработки нового сообщения укладывается в бюджет латенси по мере роста сессии.

## Оценка
- **3** — что-то навайбкодили, код запускается с Claude.
- **4** — разобрались в теме, метриках и edge-кейсах. Артефакты на GitHub/HF, документация, skill для запуска.
- **5** — всё из 4 + публикация (Хабр / Medium / arXiv), прошедшая ревью ментора.
