Для конкретного пункта с подтверждённым пределом не более 5 000 разрешена база 5 000 с источником и датой; отсутствие строки этого не подтверждает. Источник профессиональных частот пока остаётся временным за 2023 год, более новые публикации найдены, но ещё не импортированы.

## Запуск

Из корня репозитория:

```powershell
python -X utf8 tools/annotation_calculator.py
```

Открыть `http://127.0.0.1:8765`. Сервис слушает только локальный интерфейс, не сохраняет сессии и не журналирует запросы. История остаётся в памяти вкладки до перезагрузки. Атрибуты добавляются последовательно; можно выбирать человека, неизвестную принадлежность и флаг неуверенности. Внешний поиск адреса выполняется только по отдельной кнопке с явным названием DaData.

При подготовке окружения: `python -m pip install -r tools/requirements-annotation.txt`. При отсутствии локальных производных справочников выполнить команды ниже; исходные статистические файлы хранятся в `data/` и требуют восстановления из источников, а проверенный PDF — из предоставленного пользователем файла.

```powershell
python -X utf8 tools/inspect_rosstat_occupation_pdf.py
python -X utf8 tools/build_annotation_geography_reference.py
python -X utf8 tools/build_housing_occupancy_reference.py
python -X utf8 -m unittest discover -s tests -p test_*.py
```

## Что согласовано и работает

| Пробел | Принятое решение | Реализация / ограничение |
|---|---|---|
| Дата профессиональной статистики | Временно использовать проверенные данные за 2023 год, указывая дату | Таблица Росстата занятий по полу |
| Сопоставление занятий | Выбор опубликованной группы ОКЗ; небольшой словарь подсказок | Неоднозначные названия возвращают варианты; полный классификатор узких кодов не загружен |
| Работа + профессия + пол | `1+(s-1)*q`, где `q` — совместная доля профессии и пола среди всех занятых | Согласованное приближение, а не измерение организации |
| ФИО | Только исследовательский источник; в основной оценке неизвестная частота | Аудит подтвердил разные знаменатели и дубли; репрезентативность не установлена |
| География | Временно использовать перепись с датой | Выбор конкретной строки с регионом/контекстом, группы размера без пересечений |
| Телефон/email | Полный личный телефон и email одного человека дают алерт | Одиночный контакт это правило не включает; общие контакты не считаются личной парой |
| Адрес отдельно | Не алерт | Вложенные географические компоненты не обходят исключение |
| Численность по адресу | Среднее занятого помещения подтверждённого типа разрешено как приближение | Отдельно квартира, индивидуальный дом, коммунальная квартира целиком |
| Многоквартирный дом целиком | Число квартир × среднее жителей занятой квартиры | Согласованное временное допущение: все квартиры заняты. Без числа квартир оценка неизвестна |
| Адрес с другим признаком | При принятой положительной оценке в пределах порога — алерт | Родство и компоненты адреса не считаются новым независимым личным признаком |
| Родство | Только связь людей, без численного уменьшения | Новый статистический коэффициент не назначается |
| Автопоиск адреса | DaData; пользователь добавит ключ локально | Адаптер реализован, проверен на синтетическом ответе; настоящий вызов ожидает ключ |

Сервис показывает отдельные основания. Когда нет совместной статистики географии и профессии, отдельные счётчики не перемножаются и не выдаются за совместное число. При этом уже достаточное принятое сочетание может дать алерт независимо от отсутствия частоты другого атрибута. Неопределённость не превращается в отрицательный вердикт. Первый алерт сохраняется при позднем обновлении текущих фактов.

## Воспроизводимые результаты аудита и жилья

Анонимная сводка частот: `python -X utf8 tools/audit_name_frequencies.py`. Повторный анализ фиксированной версии в памяти, без сохранения словарей/примеров:

```powershell
python -X utf8 tools/audit_name_frequencies.py --download --revision ac26a24a9bf0ac05e3330668c5103400a1cbf4ea
```

Команда сводки воспроизводит суммы `names=2605725`, `midnames=2679948`, `surnames=4163020`. Это суммы счётчиков источника, не размеры подтверждённых независимых выборок уникальных людей. Их нельзя использовать как общий знаменатель ФИО. Найдены дубли после нормализации регистра/`ё`, отсутствующие ключи и неизвестные словарные метки пола. Микроданные и исходные словари не сохраняются; только обезличенная сводка в `data/reference/name-frequency-audit.json`.

Команда `python -X utf8 tools/build_housing_occupancy_reference.py` воспроизводит общероссийские средние жителей занятого помещения: отдельная квартира **2,3152949159**, индивидуальный дом **2,7118277716**, коммунальная квартира целиком **2,8904702970**. В отличие от среднего домохозяйства, учтены помещения с несколькими домохозяйствами. Это среднее по помещениям, не математическое ожидание размера жилья случайного жителя. Выбор такого приближения согласован явно.

## Что остаётся фактически незавершённым

- Настоящий вызов DaData: нужен `DADATA_API_KEY` в `.env`. Ключ в чат не передаётся. Подсказка требует выбора пользователем; она не является данными о жильцах.
- Для многоквартирного дома правило теперь согласовано и реализовано: число квартир × среднее жителей занятой квартиры, с явным предположением полной заселённости. Число квартир берётся из выбранной подсказки `house_flat_count`; его отсутствие не подменяется нулём или средним размером одной квартиры.
- Источник числа квартир: поле `house_flat_count` в [документации DaData](https://dadata.ru/api/suggest/address/). Адаптер сохраняет его в памяти выбранной подсказки, если оно доступно. Доступность поля при настоящем запросе ещё не проверена до ключа. В интерфейсе нужно выбрать тип «Многоквартирный дом целиком»; адрес с квартирой оценивается отдельно как квартира.
- Неполный адрес до улицы: доступна численность выбранной территории, но нет проверенного населения улицы. Два универсальных коэффициента «полный/неполный» не придуманы; оценка зависит от подтверждённого объекта.
- Малые сельские населённые пункты: в используемой федеральной таблице ограниченное покрытие, неизвестная деревня не попадает в минимальную группу. Усреднение по неполному списку поселений не объявлено национальным.
- Общепопуляционные частоты ФИО: источник не подтверждён. Перенос на население остаётся исследованием, по согласованию не используется для эталонной разметки.
- Основной датасет: требуется командное принятие версии инструкции. Текущий рабочий прототип не меняет прежние аннотации.

Эти ограничения видны в результатах калькулятора; они не помечены закрытыми ради завершения списка.
