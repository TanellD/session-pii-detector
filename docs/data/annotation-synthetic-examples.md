# Синтетические примеры и разбор разногласий

Версия annotation-mvp-v2. Все люди, адреса и контакты вымышлены. Код телефона намеренно несуществующий, домен `.invalid` тестовый. Это учебные сценарии политики, не проверка NER и не сведения о реальных людях.

Воспроизведение:

```powershell
python -X utf8 tools/build_annotation_mvp_examples.py
python -X utf8 tools/annotation_contract.py --check-cases tests/fixtures/annotation-mvp-cases.json
```

Границы в машинном файле вычислены как индексы Unicode code points, `[start, end)`. ФИО не является сущностью: везде выделяются отдельные Ф/И/О. `null` у персоны означает неизвестную принадлежность; такие строки не объединяются в одно лицо.

Флаги примера и неуверенной разметки относятся ко всему кейсу. Синтетическое происхождение датасета не означает, что в тексте каждого диалога описан учебный пример: is_example отмечает именно контекст текста. Пример не подавляет правило алерта.

Если алерт не возник, это означает отсутствие сработавшего достаточного правила. При неизвестной статистике весь кейс отмечен как неуверенная разметка, требующая уточнения ТЗ.
