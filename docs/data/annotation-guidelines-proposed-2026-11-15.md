# Черновик инструкции: основания первого алерта

> Исторический черновик. По явному поручению пользователя актуальные решения сведены в [первую рабочую инструкцию MVP](annotation-guidelines.md) и [минимальный формат](schema.md). Они имеют приоритет, включая исключение организации из дополнения к ФИО/парам и полный адрес как достаточный качественный дополнительный признак без оценки жильцов.

- Дата: 2026-11-15.
- Статус: proposed, решения лида для рассмотрения командой. Действующая инструкция и существующие аннотации не изменены.
- [Источник правил, реализация и ограничения](../project/annotation-gap-resolution-2026-11-15.md).

## Единица учёта

Обновление рабочих решений от 2026-11-17: полные пары ФИ, ИО и ФО одного человека включены в оранжевый список. Каждая пара — один составной маркер; исходные части сохраняются без повторного учёта. При сборке полного ФИО три пары отдельно не накапливаются. Сам цвет не задаёт алерт: действует [согласованное правило сочетания с дополнительным личным атрибутом](../project/partial-name-alert-working-rule-2026-11-17.md). Это производные сочетания существующих сущностей, не новые спановые классы NER.

Упоминание атрибута относится к выбранному человеку, новому человеку либо имеет неизвестную принадлежность. Неизвестная принадлежность не прикрепляется к говорящему автоматически. Адрес другого объекта, например банкомата, не становится адресом проживания человека.

Неуверенный атрибут учитывается, если человек выбран; признак неуверенности сохраняется в основаниях. Общий адрес нескольким людям автоматически не назначается. Родство используется для связи людей, без коэффициента редкости.

## Активные факты и история

Упоминания не переписываются. Позднее значение того же смыслового атрибута того же человека заменяет активное значение; одинаковый повтор не уменьшает круг повторно. Город работы не заменяет город проживания. При сборке фамилии, имени и отчества отдельные части заменяются полным ФИО в активном учёте. Источники упоминаний сохраняются.

Первый алерт определяется по доступному префиксу и не переносится назад с учётом будущих сведений. Позднее исправление не удаляет исторический первый алерт. В калькуляторе фиксируется порядок ввода атрибутов; для датасета дополнительно нужны индексы сообщений.

## Достаточные основания

- Полный красный маркер соответствующего класса и контекста — непосредственный алерт. Контрольная сумма не подтверждает существование документа.
- Полный личный телефон и полный личный email одного человека — алерт по отдельному правилу. Контакты разных людей не объединяются. Одиночный контакт не включает это правило.
- Для принятого статистического основания — положительная точечная оценка в пределах порога из `configs/annotation-estimator-policy.json`. Доли зависимых признаков не перемножаются автоматически.
- Полный адрес без других личных признаков — не алерт. Территория/улица/дом в его составе не считаются дополнительными признаками.
- Адрес с другим личным признаком допускает алерт при принятой оценке адреса в пределах порога. Среднее разрешено лишь для подтверждённого типа занятой жилой единицы. Многоквартирный дом целиком не заменяется квартирой.
- Для целого многоквартирного дома разрешено временное приближение: число квартир × среднее жителей занятой квартиры с явным допущением полной заселённости. Без положительного целого числа квартир оценка неизвестна. При наличии квартиры в адресе множитель числа квартир дома не применяется.

## Использование статистики

Пол остаётся атрибутом; совместные счётчики или условные вероятности исключают его повторный учёт. Возраст не используется как критерий человека. Исторические данные занятий и географии временно разрешены лидом с явным указанием даты.

Частоты частей ФИО из проверенной библиотеки используются только для исследования. Для основной разметки они не задают национальную частоту. Неоднозначная профессия требует выбора опубликованной группы ОКЗ; несопоставленная профессия не получает нулевую/малую частоту `other`.

Когда нет достаточного источника либо совместной статистики, сохраняется неопределённость. Она не является отрицательным алертом. При наличии другого достаточного основания алерт допустим, даже если частота дополнительного атрибута неизвестна.
