# Инструкция по разметке

Статус: **не составлена**. Заполняется по итогам исследования.

Из постановки: в наборе диалогов размечен момент, когда сессия становится ПДн.

После первой версии изменения — только через PR и с новой версией датасета.

## Связь с контрактом упоминания

### Поля gold-разметки

- `type` — проектный тип ПДн после маппинга;
- `text` — исходный фрагмент без нормализации;
- `start` / `end` — границы в исходной строке.

Gold-разметка **не** содержит `source`, `confidence`, `confidence_kind`,
`detector_version` — это свойства предсказания, а не разметки.

### Поля выхода детектора

Совпадают с контрактом адаптера: `id`, `type`, `text`, `start/end`, `confidence`,
`confidence_kind`, `source`, `detector_version`. См.
[контракт адаптера](../research/notes/mention-contract.md).

Схема не включает владельца атрибута, сессионный алерт или нормализованное
значение; такие поля принадлежат другим этапам (#21 и #24). После согласования
первые версии разметки будут версионированы вместе с датасетом.
