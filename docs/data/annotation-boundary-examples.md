# Пограничные случаи имён, профессий и владельцев

Дополнительные пограничные случаи проверяются в [наборе из ста пользовательских сессий](../experiments/2026-11-19-annotation-100-gemma.md):

| Фраза | Решение |
|---|---|
| «Хочу обратиться к психологу» | `психологу` → `occupation`, `person_id=null`; это не профессия говорящего. |
| «Я работаю психологом» | `психологом` → `occupation` говорящего. |
| «На встречу записались Соня и Тёмка» | Два `first_name`, две отдельные персоны. |
| «Передал Соне записку. Соня подтвердила, что Соня придёт» | Три спана одного человека. Для `Соне` occurrence=1; для двух `Соня` — 1 и 2. |
| «Сонины вещи лежат рядом» | Притяжательное прилагательное не выделяется как имя. |
| «Читаю рассказ. Персонажа зовут Тестимир» | `Тестимир` → `first_name` отдельного персонажа; пересказ не включает флаг примера на весь кейс. |
| «Это учебный вымышленный кейс. ИНН физического лица: 000000000000» | `is_example=true`, полный `individual_inn` с `person_id=null`, красный алерт. Нулевой номер — синтетический суррогат. |

Разметчик А создаёт владельца ИНН из слов «физического лица», разметчик Б оставляет `null`. При отсутствии описания конкретного человека верно Б. Само название типа реквизита не устанавливает владельца; красный алерт от этого не зависит.
