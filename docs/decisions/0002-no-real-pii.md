# ADR-0002: Никаких реальных ПДн в репозитории и датасете

- Статус: accepted
- Дата: 2026-10-26

## Контекст
Проект про ПДн. Публикация на GitHub/HF обязательна для оценки 4+. Хранение реальных ПДн создаёт юридические риски по самому ФЗ-152.

## Решение
Используем только синтетические данные. Имена, телефоны, адреса генерируются и не должны совпадать с реальными людьми намеренно. Тестовые примеры — тоже синтетика. Секрет-сканер в pre-commit.

## Последствия
Нужно уделить внимание реалистичности синтетики и честно описать это ограничение в карточке датасета и публикации.
