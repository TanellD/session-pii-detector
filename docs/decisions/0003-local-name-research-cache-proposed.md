# ADR-0003: Локальный кеш ФИО для исследования частот

- Статус: proposed.
- Дата: 2026-11-16.

## Контекст

Пользователь прямо разрешил сохранить результаты и ФИО на своём компьютере в нетрекуемой папке для анализа без повторного скачивания. Это специальное указание текущей сессии, уточняющее прежнее требование об обработке только в памяти. Принятый ADR-0002 не редактируется; изменение общей политики команды этим документом не объявляется принятым.

## Предлагаемая область исключения

Только локальные исследовательские наблюдения в `data/private/name-dependence/`, которая должна игнорироваться Git. Перед записью код проверяет `git check-ignore`. В репозиторий, тесты, примеры, документы и консольные логи реальные ФИО не добавляются. Учебный датасет остаётся синтетическим. ИНН для текущего сбора используется только в памяти и не сохраняется.

Кеш хранит ФИО и минимальные сведения о происхождении, а результаты анализа — обезличенные агрегаты. При существующем кеше команды анализа не используют сеть; частичная или неуспешная загрузка не должна подменять пригодный кеш.

## Последствия

Можно независимо пересчитывать статистику без повторных обращений к источникам. Локальные файлы содержат реальные ФИО, поэтому их нельзя добавлять в Git принудительно или включать в публикационные артефакты. Общая политика долговременного хранения требует отдельного решения команды.
