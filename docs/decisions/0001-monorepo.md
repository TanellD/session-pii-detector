# ADR-0001: Один репозиторий для кода и базы знаний

- Статус: accepted
- Дата: 2026-10-26

## Контекст
Команда из 4 человек, работаем с AI-агентами. Нужно хранить код, документацию, инсайты и материалы презентаций.

## Решение
Один репозиторий: код в `src/`, база знаний в `docs/`, материалы защит в `deliverables/`. Данные — вне git (HF Datasets).

## Альтернативы
- Два репо + submodule: двойные коммиты, рассинхрон, неудобно агентам.
- GitHub Wiki: нет ревью, агенты не видят её по умолчанию.

## Последствия
Код и документация меняются в одном PR; агенты видят базу знаний автоматически.
