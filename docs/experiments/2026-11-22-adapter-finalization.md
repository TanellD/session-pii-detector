# Завершение адаптера для MVP

- Дата / автор: 2026-11-22, команда проекта.
- Связано: PR #45.
- Код: изменения поверх 7fe3c84, правила pii_smoke_rules-v3.
- Данные: синтетические фикстуры репозитория, без реальных ПДн.
- Окружение: Windows, Python; модель и необязательный парсер не скачивались.

## Проверка

```powershell
python -X utf8 -m unittest discover -s tests
python -X utf8 -m benchmarks.adapter.adapter_check --output runs/pr45-final-regex.json
```

Регрессии проверяют сохранение исходного имени, границы парсера и происхождение контекстного результата, PERSON, телефоны обоих источников, checksum, исключение категорий и отсутствие потери соседних кандидатов при дубле. Smoke без модели явно пропускает модельные случаи. Это проверка кода, не качества модели или полного сервиса. Исторический отчёт на session-alerts-v1 не переносится на новую реализацию.

## Вывод

Оставлены согласованные ограничения позиционного разбора. Межтиповые пересечения и владельцев определяет обработчик. Для повторной оценки на новом локальном корпусе используйте python -X utf8 -m benchmarks.eval_gold --gold data/session-alerts-v3/sessions.json --split all --output runs/pr45-final-corpus.json. Для модельного прогона добавьте --with-model и зафиксируйте окружение; готовность модели здесь не подтверждена.
