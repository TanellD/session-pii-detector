# Эксперимент: достаточно ли собранных ФИ для правил разметки

- Дата / автор: 2026-11-17, команда проекта.
- Основание: пользователь попросил проанализировать доступный корпус и его достаточность для задачи.
- Гипотезы: корпус позволяет проверять зависимость фамилии и имени на частых сочетаниях; он может оказаться недостаточным для прямой оценки редкости на уровне принятого порога числа людей.

## Настройка

- Данные: актуальные страницы сообщества VK `vk`, язык `ru`, версия обработки 2. Кеш разрешён пользователем только локально вне Git. Закрытые/деактивированные профили и неподдерживаемые написания уже исключены сборщиком.
- Фиксация: `data/private/name-dependence/vk-groups/vk/annotation-evidence-manifest-2026-11-17.json` содержит список страниц, SHA-256 каждой и копию текущего плана. При повторном запуске новые страницы не подмешиваются; изменившиеся исходные файлы вызывают остановку. Данные сами по себе не репрезентативны для населения России.
- Два среза: все актуальные сохранённые страницы и отдельно доступные страницы текущего плана. При объединении сначала используются записи текущего плана, затем остальные, с дедупликацией ID. При конфликте полей сохраняется версия текущего плана. Одинаковые ФИ разных ID сохраняются.
- Коммит основы: `68b090e5db4664e3802e09a17976f45e1d7601bb`, изменения рабочего дерева.
- Среда: Windows, Python, CPU, стандартная библиотека.

Все численные результаты и расчёты воспроизводятся без сети:


## Процедура проверки частотного приближения

В каждом срезе выполняются пять разбиений с seed 42–46 на части 60% / 20% / 20%. Первая часть задаёт частоты и список частых пар отдельно внутри заявленного пола. Минимальное число наблюдений для включения пары: 5, 20 либо 50, три заранее заданных варианта. Пары отбираются только по первой части.

Для выбранной пары внутри пола базовая вероятность — `p(Ф|пол) × p(И|пол)`, совместная — `count(Ф,И|пол)/n_пола`. Все прочие пары объединены в одну категорию OTHER с вероятностью, дополняющей сумму до единицы. Таким образом, обе оценки задают нормированное распределение по одному и тому же набору категорий. Это не вероятность буквального написания каждого неизвестного ФИ: различия внутри OTHER не оцениваются.

Поправка — смесь независимой и совместной оценок `p_mix=(1−alpha)×p_ind+alpha×p_joint`. Alpha выбирается из заранее заданного списка `0, .25, .5, .75, .9, .99` только по второй части. На третьей сравнивается средний log loss базовой формулы и выбранной смеси. Пол уже учтён в обеих формулах. Дубли аккаунтов удаляются до разбиения. Общий скрытый источник и возможные аккаунты одного человека в разных частях остаются ограничением.

Это более узкая постановка, чем [прежняя проверка каждого ФИ с UNK](2026-11-16-vk-pair-sample-adequacy.md). Результаты нельзя напрямую сравнивать по величине log loss: события и словари различаются. Выигрыш на частых парах и OTHER не означает выигрыш для всех редких буквальных сочетаний.

## Иллюстрация точности на редких сочетаниях

Порог читается из `configs/annotation-estimator-policy.json`. В качестве явно условного примера взята популяция 150000000, это не свежая подтверждённая численность населения РФ. Изменить сценарий можно параметром `--scenario-population`.

При идеальной независимой репрезентативной выборке частота на пороге равна `p=порог/N`, ожидаемое число наблюдений — `n×p`, вероятность нуля — `(1−p)^n`, относительное стандартное отклонение — `sqrt((1−p)/(n×p))`. Основание — среднее и дисперсия [биномиального распределения NIST](https://www.itl.nist.gov/div898/handbook/eda/section3/eda366i.htm). Ориентир 20% относительного стандартного отклонения служит иллюстрацией масштаба, не новым требованием политики и не доверительной верхней границей алерта.

Фактический корпус VK не выполняет предпосылки случайной репрезентативной выборки. Эти формулы не создают доверительные интервалы для России и не разрешают умножать частоты корпуса на население страны.

## Результаты и ограничения

Численные таблицы и выводы представлены в [итоговой заметке](../research/notes/vk-annotation-evidence-2026-11-17.md). Основные ограничения: одна социальная площадка и одно сообщество, детерминированная неполная сетка страниц, фильтр открытости/написания, неподтверждённые имена, отсутствующий охват населения, неизвестная зависимость по регионам, отсутствие отдельного отчества. Большой объём не устраняет эти ограничения.

## Следующий шаг

Отделить корпус для оценки частых ФИ от корпуса для национальных оценок числа людей. Для второго необходимы охват, состав и внешняя проверка; для ФИО — явно наблюдаемые отчества. Принятые ADR, действующие правила разметки и основной калькулятор не менялись.
