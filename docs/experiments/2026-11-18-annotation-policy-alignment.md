- Команды:

```powershell
python -X utf8 -m unittest discover -s tests
python -X utf8 tools/audit_annotation_consistency.py
```

## Результаты

Полный прогон: **155 тестов успешно**, воспроизведение первой командой. Проверены сохранение ранней неуверенности, отсутствие алерта на неуверенном шаге, поздний первый алерт, возраст без придуманной численности, общий адресный этап, повтор без сети и отказ при другой аннотации. HTTP-проверка покрывает подключение этапа и повтор сохранённого результата без адресных запросов.

Regex в новом режиме выделяет синтетический полный СНИЛС с неверной контрольной суммой; исторический режим продолжает отклонять его. Исходные smoke-метки и исторические результаты не изменялись.

## Анализ ограничений

Это проверка реализации политики, не замер F2 на независимом gold. Возраст выделяется как жёлтый класс, но численный возрастной справочник ещё не подключён. Официальный каталог Росстата описывает однолетние возраста и пол; проверка предполагаемого прямого XLSX-адреса завершилась HTTP-ошибкой, файл не импортирован. Нельзя считать наличие каталога готовым коэффициентом.
