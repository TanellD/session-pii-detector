# Средние численности населённых пунктов и жилых домов

- Дата: 2026-11-18. Исследовательский расчёт для правил разметки.
- Issue: текущая задача закрытия статистических справочников.
- Гипотеза: полный переписной список позволяет получить средние по типу и региону без исключения малых деревень.

## Данные и воспроизведение

Базовый коммит: `68b090e5db4664e3802e09a17976f45e1d7601bb`; скрипт добавлен в рабочем дереве. Конфиг — константы и правила в `tools/research_population_size_means.py`. Windows, Python; специальные вычислительные ресурсы не требуются. Это проверка справочника, метрики детектора не вычислялись.

Источник: [Росстат, ВПН-2020/2021, обработка «Если быть точным»](https://tochno.st/datasets/allsettlements), версия `v20260925`. Дата публикации файла не означает численность на эту дату: население относится к переписи 2021 года. Это найденная полная основа для малых пунктов, а не утверждение об отсутствии более свежих локальных оценок. Национальный итог соответствует территориальному охвату этой переписи; его нельзя смешивать с другими наборами без сверки границ.

```powershell
python -m pip install -r tools/requirements-annotation.txt
python -X utf8 tools/research_population_size_means.py --download
python -X utf8 tools/research_population_size_means.py --download --housing
python -X utf8 -m unittest discover -s tests -p test_population_size_means.py
```

Повторный запуск не скачивает имеющийся архив. Результат и SHA-256: `data/reference/proposed-population-size-means.json`; исходник — `data/external/annotation-size-statistics/`. Оба находятся вне git. Команда выше воспроизводит все переписные числа следующей таблицы и расчёт многоквартирного дома.

## Результат по населённым пунктам

Численность в людях, округлена. Обычное среднее — `Σn/k`; среднее для случайного жителя — `Σn²/Σn`. Медиана рассчитана по всем объектам, включая незаселённые; в JSON есть также медиана только заселённых.

| Тип | Обычное среднее | Медиана | Среднее с весом населения — предложение для проживания |
|---|---:|---:|---:|
| Деревня | 60 | 9 | 1 294 |
| Село | 654 | 280 | 3 610 |
| Посёлок | 390 | 71 | 3 575 |
| ПГТ / рабочий посёлок | 5 964 | 4 614,5 | 10 826 |
| Хутор | 208 | 67 | 1 115 |
| Станица | 4 865 | 2 534 | 12 657 |
| Аул | 1 138 | 543 | 2 997 |
| Город | 92 304 | 25 749,5 | 2 312 410 |

Общее городское среднее с весом населения сильно зависит от крупнейших городов. Его не следует переносить на заведомо малый город: сначала регион, тип и известная категория размера; точная переписная численность конкретного пункта предпочтительнее любого среднего. Категории размера при отсутствии подтверждения не угадывать.

**Предложение:** конкретный идентифицированный пункт → точное доступное значение с датой → среднее с весом населения того же типа и региона → национальное среднее типа с явным допущением переноса. Это приближение, не верхняя граница и не доверительный интервал. Не использовать среднее деревни для фразы «живёт где-то в деревне» без определённого пункта. Если известно только подтверждённое ограничение «не более пяти тысяч», сохраняется ранее принятое отдельное правило, а не усреднение типа.

Агрегатор подготовил также региональные группы. Тип берётся из переписного названия, а не безусловно из современной DaData: административный статус мог измениться. Нераспознанные типы сохраняются отдельными группами `прочее: ...`; автоматически утверждать их коэффициенты нельзя. Сходимость итогов не доказывает безошибочность каждой записи или классификации.

## Дома: какие средние предлагаются

Для занятой квартиры **2,3153**, занятого индивидуального дома **2,7118** жителя — ранее принятые приближения по переписи. Воспроизведение: `python -X utf8 tools/build_housing_occupancy_reference.py`. Они относятся к занятому помещению, не ко всем пустующим домам и не к помещению случайного жителя.

Для целого МКД найден [анализ Института экономики города по формам Росстата, 2025](https://www.urbaneconomics.ru/sites/default/files/kompleksnyi_analiz_harakteristik_zhilishchnogo_fonda_rossiiskoi_federacii.pdf): рисунок 5.5 и раздел 6.1. За 2024 год: **51,58 млн квартир / 1,5201 млн МКД = 33,932 квартиры на дом**. При прежнем допущении заселённости всех квартир: **33,932 × 2,3152949159 = 78,56 жителя**. Воспроизведение: `python -X utf8 tools/research_population_size_means.py`.

**78,56 — предложение исследовательского приближения, не утверждённый коэффициент алерта.** Это обычное среднее по домам, а не среднее с весом жителей; распределение домов очень неоднородно. Сочетаются фонд 2024 года и заселённость по переписи 2021 года. Пустующие квартиры не вычитаются. В расчёте используются все МКД, а не меньшая выборка домов с определённым способом управления. Для дома с известным числом квартир предпочтительна его собственная характеристика. Квартира, индивидуальный дом, общежитие, дом блокированной застройки и МКД не взаимозаменяемы.

### Проверка по отдельным домам: более свежий реестр

Скачан и рассчитан [обработанный реестр ГИС ЖКХ](https://tochno.st/datasets/gisgkh), версия `v20260917`, сведения за август 2026 года. Воспроизведение всех чисел этого подраздела: `python -X utf8 tools/research_population_size_means.py --download --housing`. Для повторного анализа сеть не нужна: убрать `--download`. SHA-256 архива, региональные группы и аудит сохранены в выходном JSON.

Из **956 147 записей** включены **829 285**: тип «Многоквартирный», стадия «Эксплуатация», положительное известное число квартир. Последовательно исключены: **675** зданий другого типа, **51 297** МКД без подтверждённой эксплуатации, **74 890** эксплуатируемых МКД без положительного числа квартир. Уникальность `gisgkh_guid` проверена; пустое число квартир не считается нулём жителей. Для исключённых зданий оценка остаётся неизвестной.

| Показатель выбранных МКД | Квартир на дом | Оценка жителей при прежней заселённости |
|---|---:|---:|
| Обычное среднее по домам | 56,95 | 131,85 |
| Медиана домов | 27 | 62,51 |
| Среднее с весом числа квартир | 184,63 | 427,46 |

Последняя величина рассчитана как `2,3152949159 × Σ(a_i²)/Σ(a_i)`, где `a_i` — квартиры дома. При одинаковой заселённости каждой квартиры это приближение среднего размера дома случайного жителя. Число квартир — наблюдаемая характеристика реестра; жители — оценка, а не данные регистрации проживания.

**Для обсуждения предлагаю около 427 жителей как временное среднее для проживания в МКД без известного числа квартир**, предпочтительно региональное значение из того же расчёта. **Не предлагаю использовать 79 как общую оценку для случайного жителя МКД:** это среднее другой генеральной совокупности и другого способа выбора дома. Медиана реестра также оказывается ниже порога, но это не причина предпочесть её. Отбор домов в ГИС ЖКХ и отсутствие числа квартир могут быть неслучайными; перенесение результата на отсутствующий дом требует явного принятия этого допущения. Поэтому статус остаётся исследовательским, полного национального покрытия реестр не доказывает.

## Улицы: источник и расчёт вместо произвольной константы

Проверен [публичный реестр ГИС ЖКХ и инструкция выгрузки](https://cdn.dom.gosuslugi.ru/webhelp/topics/houses/och/t_download_archive-och.html); доступна выгрузка домов. Также найден [обработанный набор ГИС ЖКХ](https://tochno.st/datasets/gisgkh), версия `v20260917`, сведения за август 2026 года. Его охват — внесённые в систему МКД, а не все жилые дома России. Нельзя считать отсутствующий дом нежилым или без жителей.

Рабочая формула конкретной улицы: сумма оценок жителей всех её жилых зданий. Для МКД — число квартир × среднее заселённости, для индивидуального дома — соответствующее среднее. Нужны уникальные дома, единый ID улицы внутри населённого пункта, число квартир, тип жилья и проверка покрытия. Разные улицы с одним названием не объединять; дубликаты корпусов исключать по идентификатору объекта, а не только строке адреса. Дорожный сегмент на карте не равен адресной улице.

**Единое численное среднее жителей улицы пока не подтверждено.** Деление населения России на число улиц ГАР даёт несогласованный знаменатель: там есть нежилые и незаселённые адресные объекты, а население не распределено по улицам. При известной только улице сохраняется неизвестная оценка, пока нет достаточного покрытия жилых домов. Это оставшийся пробел, а не основание придумать коэффициент около порога.
