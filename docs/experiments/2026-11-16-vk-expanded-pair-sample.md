# Эксперимент: расширенная выборка ФИ аккаунтов VK

- Дата / автор: 2026-11-16, команда проекта.
- Основание: пользователь попросил увеличить выгрузку и проанализировать.
- Гипотеза: расширение корпуса увеличит повторяемость ФИ и улучшит перенос совместной оценки на отложенные аккаунты.

## Настройка

- Данные: открытые активные аккаунты участников сообщества `vk`, `groups.getMembers`, `lang=ru`, версия обработки 2. Только поддерживаемые кириллические написания, дедупликация по ID аккаунта. Совпадающие ФИ разных аккаунтов сохраняются.
- План: лимит 100000 запрошенных записей, страницы по 1000, равномерные детерминированные смещения по прежнему диапазону `id_asc`. Это не случайная выборка людей. План не является моментальным снимком: страницы получены в разное время.
- Предыдущий план и отчёты сохранены в `data/private/name-dependence/vk-groups/vk/snapshots/limit-10000/`. Новая сетка включает все прежние смещения; страницы используются повторно. Сырые данные и идентификаторы остаются вне Git.
- Коммит основы: `68b090e5db4664e3802e09a17976f45e1d7601bb`, изменения рабочего дерева.
- Среда: Windows, Python, CPU, стандартная библиотека.
- Анализ: те же пять разбиений и четыре силы сглаживания, что в [пилоте](2026-11-16-vk-pair-sample-adequacy.md). Дополнительно описательные отношения совместной частоты к произведению маргинальных для клеток с числом наблюдений не менее 5, 10, 20; отдельно внутри заявленного пола.

Команды сбора и воспроизведения:

```powershell
python -X utf8 tools/collect_vk_group_members.py --group vk --limit 100000 --token-type service --download
# Следующие команды работают без сети:
python -X utf8 tools/collect_vk_group_members.py --group vk --limit 100000
python -X utf8 tools/assess_vk_pair_sample.py --group vk
python -X utf8 tools/assess_vk_pair_sample.py --group vk --snapshot-limit 10000
python -X utf8 -m unittest discover -s tests -p 'test_vk*.py'
```

## Интерпретация

Для пары определяем описательное отношение `R = count(Ф,И) × n / (count(Ф) × count(И))`. Это аналог lift: больше единицы означает, что наблюдаемая пара чаще независимого произведения в этой выборке. У редких фамилий отношение может быть большим даже без устойчивой зависимости. Отбор клеток по наблюдаемой частоте создаёт смещение вверх; медиана этих отношений не становится общей поправкой. В отчёте нет самих ФИ.

Сравнение log loss допустимо между оценками на одном разбиении и общем словаре. Абсолютные значения между размерами корпуса напрямую не сравниваются: меняются словарь и доля UNK. Общий эффект пола проверяется отдельной перестановкой внутри пола; это не устраняет остальные зависимости и смещение состава сообщества.

Метрики сессионного детектора не вычисляются. Результаты не подтверждают частоты населения России и не дают оснований автоматически переносить ФИ на ФИО: отчеств в источнике нет.
