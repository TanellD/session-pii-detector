# Эксперимент: Gemma-линкер на фиксированных 250 сессиях

- Дата: 2026-11-24.
- Статус: запущен; окончательные результаты находятся в `summary.json` после завершения.
- Гипотеза: Gemma точнее случайного линкера назначает владельцев атрибутов.

## Настройка

- Данные: `data/experiments/random-linker-250-2026-11-24/snapshot.json`, тот же синтетический снимок, что в эксперименте со случайным линкером. Размеры проверяются командой ниже.
- Вход: эталонные спаны; владельцы, сценарии и ожидаемые алерты модели не передаются. Предыдущие карточки строятся из собственных предсказаний модели.
- Конфиг: `configs/linker-gemma-baseline.json`, `gemma-owner-linker-v2`; окно предыдущих сообщений и проверки ответа сохранены после пилота.
- Коммит основы: `2172a364f5259ad7bcfd0066caba8a8004fac046`; код эксперимента находится в незакоммиченных изменениях worktree. Контрольные суммы исходников сохранены в `provenance.json` рядом с результатами.
- Модель: настроенный API `Gemma-4-31B-IT`; точная ревизия весов провайдером не подтверждена. Измеряется внешнее время API, локальное железо не определяет скорость инференса.
- Результаты и исходные ответы: `data/experiments/gemma-linker-250-2026-11-24/results/`; журналы процесса — в соседнем `logs/`.

Команда запуска из корня worktree:

```powershell
.\.venv-gliner\Scripts\python.exe -X utf8 -u tools/evaluate_gemma_linker.py --output data/experiments/gemma-linker-250-2026-11-24/results --all-sessions --env-file '../../.env'
```

Для продолжения остановленного процесса используется та же команда с `--resume`; одновременно второй процесс для этого каталога запускать нельзя. Успешные сессии не повторяются, незавершённая сессия выполняется в новой попытке. При транспортной ошибке оценщик останавливается; журнал и предыдущие ответы остаются на диске.

## Результаты

Живой Markdown-отчёт: `data/experiments/gemma-linker-250-2026-11-24/live-progress.md`.
Отдельный наблюдатель обновляет его по сохранённым ответам, не вызывает API и не меняет промпт:

```powershell
.\.venv-gliner\Scripts\python.exe -X utf8 tools/watch_gemma_linker.py
```

Интервал обновления — 15 секунд. После завершения или остановки оценщика наблюдатель сохраняет итоговое состояние и выходит. Для однократного обновления добавьте `--once`. После возобновления оценщика наблюдатель нужно запустить снова.

Финальные значения пока не зафиксированы. Оценщик автоматически сохранит `results/summary.json` по окончании процесса. Текущая сводка по уже завершённым сессиям пересчитывается без API:

```powershell
.\.venv-gliner\Scripts\python.exe -X utf8 tools/evaluate_gemma_linker.py --output data/experiments/gemma-linker-250-2026-11-24/results --report-only
```

Эта команда показывает размер выбранного среза и покрытие завершёнными сессиями, ошибки, pairwise Precision/Recall/F1, точное совпадение групп владельцев, Precision/Recall и F2-session/F2-timely для связки «эталонные спаны → Gemma → риск», медиану и максимум времени API. Неполное покрытие нельзя выдавать за итог всего среза. Неизвестные эталонные владельцы исключаются из pairwise с указанием количества; проверка точных групп учитывает их.

## Анализ ошибок и ограничения

Ошибки группировки и первых алертов доступны в `summary.json → cases`; предсказания, запросы и ответы сохраняются отдельно по сессиям и попыткам. Анализ характерных ошибок выполняется после завершения, без изменения промпта в ходе этого запуска.

Измеряется изолированный линкер и связка с расчётом риска на правильных спанах. Качество NER и полного сервиса с предсказанными спанами этим запуском не измеряется. Часть сценариев уже использовалась при отладке пилота; срез не является полностью независимым тестом. Результаты относятся к синтетическому корпусу, не подтверждают качество на реальных диалогах и максимальный RPS.
