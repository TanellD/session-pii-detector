# Эксперимент: оценка населения по разрешённому адресу

- Дата: 2026-11-18.
- Связано: [описание оценщика](../project/address-population-estimator.md).
- Гипотеза: разрешённый адрес и подтверждённый тип жилья позволяют применять согласованные средние, явно сохраняя неизвестность при недостатке характеристик.

## Настройка

- Базовый коммит: `2ee9c86`; реализация и проверки добавлены вместе с этим отчётом.
- Конфиг: `configs/annotation-estimator-policy.json`, разделы `housing_defaults` и `automatic_address_estimation`.
- Данные: ВПН-2020, дата учёта 2021-10-01; ГИС ЖКХ через «Если быть точным», период 2026-08, версия `v20260917`. URL и контрольные суммы записаны в конфиге и метаданных локального индекса.
- Исходный архив, индекс и браузерный профиль находятся в игнорируемом `data/`; в git они не входят.
- Среда: Windows, Python; локальный HTTP-сервер и Microsoft Edge в режиме headless.

Команды воспроизведения:

```powershell
python -X utf8 tools/build_housing_occupancy_reference.py
python -X utf8 tools/build_address_house_index.py
python -X utf8 -m unittest discover -s tests
python -X utf8 tools/annotation_calculator.py --port 8766
```

Для повторной сборки существующего индекса нужно указать новый `--output`: скрипт не перезаписывает готовый файл. Для установки без локальных статистических таблиц сервер запускается с `--policy-only`; средние из конфига остаются доступны.

## Результаты

- Полный набор проверок: **149 тестов, успешно**. Команда: `python -X utf8 -m unittest discover -s tests`.
- Индекс содержит **956 147 строк** с ID дома; число воспроизводится командой сборки индекса. Отдельные повторяющиеся ID сохраняются и при поиске дают неоднозначность.
- Синтетические тесты проверяют квартиру, индивидуальный дом, произведение числа квартир на заселённость, неоднозначный выбор, конфликт источников, комнату, зарубежный и неполный адрес. Нулевое число квартир и неизвестный тип жилья не превращаются в индивидуальный дом.
- Headless Edge загрузил страницу на порту 8766: новая форма присутствует, контекст калькулятора получен. Пустой адрес через HTTP возвращает `400 invalid_input`.
- Доступ к DaData проверен на заведомо синтетическом несуществующем адресе: запрос выполнен, подсказок нет. Ключ и ответы с реальными адресами в отчёт не включались.
- Метрики качества детектора не считались: это проверка реализации расчёта, а не оценка точности определения числа жителей.

## Анализ ограничений

Среднее занятого жилья не доказывает фактическую заселённость конкретного объекта. Для МКД принято согласованное допущение о занятости всех квартир. ГИС ЖКХ не обеспечивает полного покрытия индивидуальных домов; отсутствие записи не подтверждает тип жилья. Проверка синтетического запроса подтверждает доступность провайдера, но не качество разрешения реальных адресов.

## Вывод

Оценщик подключён к отдельной форме и HTTP API. Пользователь видит источник, тип жилья и допущения. Нехватка данных даёт неизвестную оценку. Адрес сам по себе не вызывает алерт; минимальная схема сущностей не расширяется.
