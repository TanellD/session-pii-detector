# Исправление эталона сочетаний атрибутов

- Дата: 2026-11-25; PR #47.
- Основа: `2b48014` плюс `tools/relabel_weight_300.py` и поддержка отдельного эталона в наблюдателе.
- Гипотеза: предварительные авторские алерты необходимо заменить результатом существующего калькулятора разметки, прежде чем оценивать веса сервиса.
- Данные: исходный `attribute-combinations-300-v1`; исправленный эталон `calculator-reviewed-weight-300-v2`.
- Конфиг эталона: `configs/annotation-estimator-policy.json`, рабочая версия `2026-11-22-working-v3`. Конфиг сервиса и исходные запросы Gemma не меняются.
- Железо: локальный пересчёт на CPU; обращений к моделям для исправления эталона нет.

## Воспроизведение

Из корня worktree:

```powershell
.\.venv-gliner\Scripts\python.exe -X utf8 tools/relabel_weight_300.py --run data/experiments/weight-combinations-300-gemma-v2-2026-11-25 --output data/experiments/weight-combinations-300-calculator-v2-2026-11-25/snapshot-reviewed.json
.\.venv-gliner\Scripts\python.exe -X utf8 tools/watch_gemma_linker.py --run data/experiments/weight-combinations-300-gemma-v2-2026-11-25 --once
.\.venv-gliner\Scripts\python.exe -X utf8 -m unittest discover -s tests -p test_relabel_weight_300.py -v
```

Первая команда воспроизводит состав исправленных меток и сохраняет хеши политики и использованных справочников; вторая — актуальные метрики только по уже завершённым сессиям. Данные остаются вне git. Повтор первой команды не перезаписывает отличающийся снимок: нужна новая версия пути.

## Что проверено при исправлении

Формы профессий приведены к именительному падежу только для слов из генератора. Бухгалтер и редактор используют существующее однозначное сопоставление; инженер и дизайнер остаются неоднозначными, корректор и лаборант — без сопоставления. Новые группы ОКЗ не назначались.

Явные адреса личного проживания с квартирой подтверждены автором синтетических сценариев как квартиры. Применяется уже выбранное среднее жителей занятой квартиры. Это допущение сценария, не результат геокодирования и не измеренная численность. Вымышленным городам население не назначается. Независимые доли не перемножаются. Для каждой персоны каждого префикса сохранены оценки, источники и нерешённые вопросы в `calculator_prefix_ledger`.

Тексты, границы, типы, владельцы и служебные контакты идентичны исходным. Проверка несовпадения этих полей блокирует подключение эталона. Прежние алерты сохранены в `previous_author_labels`; исходный снимок API и `results/summary.json` остаются для сравнения. Метрики исправленного эталона идут в `results/summary-corrected.json` и основной live-отчёт. Наблюдатель автоматически пересчитывает новые сохранённые предсказания, без повторения запросов Gemma.

## Ограничения

Это применение существующей рабочей политики, а не изменение принятого руководства по разметке. Человеческое независимое ревью ещё требуется. Корпус шаблонный и синтетический. Изменение метрик после исправления эталона не является улучшением модели: предсказания те же. Значения прежнего отчёта о предварительных авторских метках нельзя смешивать с новой версией.
