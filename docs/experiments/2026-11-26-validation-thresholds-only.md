## Результат

Покрытие: 448/480 сессий; 32 ошибочные исключены и перечислены в отчёте.
Это предварительный подбор на выбранном успешном подмножестве.
Перебрано 1765 кандидатов, включая исходный вариант; сетка порогов 0–2 с шагом
0.05 и верхний ограничитель. Пороги не допускают алерт по одному исходному
некрасному атрибуту; обязательные правила и все веса фиксированы.
Цель: F2-timely, затем F2-session, затем минимальное изменение порогов.

| Параметр | Исходный | Выбранный | Дельта |
|---|---:|---:|---:|
| Порог известного владельца | 0.50 | 0.35 | −0.15 |
| Порог неизвестной принадлежности | 0.50 | 0.60 | +0.10 |

| Метрика | Исходная | После подбора |
|---|---:|---:|
| Precision-timely | 0.8174 | 0.6151 |
| Recall-timely | 0.5222 | 0.9209 |
| F2-timely | 0.5629 | 0.8376 |
| F2-session | 0.5662 | 0.8818 |
| Ложные алерты среди всех отрицательных | 20 | 98 |
| FP0 на уверенно отрицательных | 0/116 | 0/116 |

Прирост F2-timely: 27.47 п.п. Увеличение полноты сопровождается падением
precision и ростом алертов среди отрицательных с недостатком статистики.
Нулевой FP0 на уверенно отрицательных не означает отсутствия ложных алертов.
Recall-timely соответствует принятому специальному протоколу и исключает
ранние алерты из знаменателя recall; это не доля точных попаданий среди всех
положительных сессий.

Выбранная политика проверена повторным расчётом настоящего RiskEvaluator
для всех выбранных сессий; матричный и фактический результаты совпали.
Политика сохранена в calibration/recommended-policy.json. Рабочий конфиг не
заменён: предварительный максимум на сетке не является подтверждённым
улучшением на независимых данных. Глобальный максимум по всем возможным
весам, правилам и порогам не заявляется.
