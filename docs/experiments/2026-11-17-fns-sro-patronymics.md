# Эксперимент: отчества и совместные ИО в ФНС и СРО

- Дата / автор: 2026-11-17 / исследование проекта.
- Issue: отдельный issue не назначен; запрос пользователя «давай изучим фнс СРО».
- Гипотеза: совместные частоты имени и отчества дают проверяемое улучшение относительно произведения маргинальных частот даже внутри групп грамматической формы отчества. Переносимость проверяется отдельно.

## Настройка

- Данные: существующий локальный фрагмент реестра МСП ФНС от 10.11.2026; отдельная выгрузка реестра Гильдии кадастровых инженеров. Хеши кешей и размеры — в выходном JSON. ФНС и СРО не объединяются.
- Конфиг: нормализация регистра, пробелов и ё/е; написания мужских и женских форм не объединяются. ИО разделяется по суффиксальной форме отчества, которая не является независимо наблюдаемым полом.
- Проверка: разбиение train/validation/test = 60/20/20; seed 42–46; порог частоты пары в train 3 и 5. На validation выбирается доля совместной частоты из 0, 0.25, 0.5, 0.75, 0.9, 0.99. Для межисточниковой проверки используется seed 42 и порог 5; параметры выбираются только на источнике обучения.
- Коммит-основа: `68b090e5db4664e3802e09a17976f45e1d7601bb` плюс рабочие изменения `tools/study_fns_sro_patronymics.py` и синтетические тесты. Это не хеш зафиксированной версии эксперимента.
- Среда: локальный Windows / Python; GPU не используется.

Команды:

```powershell
# Только получение СРО; повторно использует уже сохранённый кеш.
python -X utf8 tools/study_fns_sro_patronymics.py --download-sro
# Пересчёт всех результатов без сети:
python -X utf8 tools/study_fns_sro_patronymics.py
python -X utf8 -m unittest discover -s tests -p test_fns_sro_patronymics.py
```

Первоначальное получение ФНС: `python -X utf8 tools/research_name_pairs.py --download fns`. При изменении внешнего источника прежний хеш не гарантируется: точное повторение использует сохранённые локальные кеши.

## Результаты

Сводка и интерпретация: [исследование ФНС и СРО](../research/notes/fns-sro-patronymic-study-2026-11-17.md).

Обезличенный машинный отчёт: `data/private/name-dependence/fns-sro-patronymic-results-2026-11-17.json`. Все числа сводки воспроизводятся второй командой выше.

Оценка качества вероятностного приближения использует среднюю отрицательную логарифмическую вероятность в битах для конечного набора «частые пары, выбранные по train + OTHER». Это исследовательская величина для сравнения двух приближений, не метрика детектора и не изменение неопределённых метрик из `docs/kb/metrics.md`. Разность joint − independent ниже нуля означает улучшение. Разные наборы категорий нельзя напрямую сравнивать между направлениями переноса.

## Анализ ограничений

- Предприниматели и кадастровые инженеры не представляют всё население России. Структура частей имени зависит от состава источника.
- В ФНС анализируется фрагмент архива с тремя заполненными частями имени. Он не случайный и не измеряет долю людей без отчества.
- СРО получено по всем страницам подписанной HTML-таблицы после неудобной проверки CSV. Одинаковые аттестат и ФИО сворачиваются. Конфликтующие ФИО при одном аттестате исключаются. Это правило согласованности записей, а не гарантия идеальной идентификации людей.
- Редкие пары попадают в OTHER; выигрыш не доказывает точность вероятности каждой конкретной редкой пары или тройки ФИО.
- Возможны одни и те же люди в обоих источниках. Межисточниковая проверка не гарантирует отсутствие пересечения людей.
- Перестановочная проверка использует 199 перестановок с seed 42; проверяет зависимость внутри корпуса, не репрезентативность.
