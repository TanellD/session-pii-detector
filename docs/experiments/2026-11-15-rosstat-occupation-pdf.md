# Проверка и извлечение таблицы занятости из предоставленного PDF

- Дата: 2026-11-15.
- Основание: пользователь передал локальный сборник Росстата для проверки.
- Проверяемое предположение: файл содержит совместные агрегаты занятий и пола, пригодные как историческая основа разметки.

## Настройка

- Данные: единственный PDF выпуска 2024 года в `docs/project/drafts`, таблица 2.40, данные за 2023 год.
- SHA-256: `dbf9fcfdccbbf23afd4b91d8969745de7a4cd95884ca9a40c3f3d4d24b1bea51`.
- Базовый коммит: `68b090e5db4664e3802e09a17976f45e1d7601bb`; инструмент и отчёт — незакоммиченные изменения рабочего дерева.
- Среда: Python, `pypdf`, Windows. Детектор и метрики сессий не применяются; это извлечение официальных агрегатов.

```powershell
python -X utf8 tools/inspect_rosstat_occupation_pdf.py
python -X utf8 tools/inspect_rosstat_occupation_pdf.py --table 2.40
python -X utf8 -m unittest discover -s tests -p test_rosstat_occupation_pdf.py
```

## Результат

Первая команда воспроизводит: 154 страницы PDF, 43 строки таблицы с общим итогом и вложенными группами; год наблюдения — 2023. Общий итог — 73636000 занятых, мужчины 37690000, женщины 35946000, после перевода опубликованных округлённых тысяч в человек. Выход записывается в `data/reference/rosstat-occupations-2023.json` вне git.

Вторая команда показывает исходную таблицу на страницах PDF 76–77 (печатные 75–76). Третья проверяет синтетическую многострочную запись, условные проценты, число строк локального источника и выбранные ячейки, включая сохранение несовпадающих из-за округления итогов.

## Ограничения и вывод

Проверены источник, дата, единицы и извлечение. Таблица пригодна для расчёта по группам занятий с учётом пола без возраста человека. Это выборочные среднегодовые оценки и округлённые значения, а не точная перепись работников. Итоги и подгруппы нельзя суммировать вместе. Региональные разрезы требуют отдельного приложения. Сопоставление текстовых должностей с ОКЗ, перенос состава на конкретного работодателя и обновление до последнего доступного периода не выполнены этим извлечением.
