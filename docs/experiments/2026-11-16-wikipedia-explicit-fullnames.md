# Эксперимент: явно написанные ФИО в русской Википедии

- Дата: 2026-11-16.
- Автор: команда проекта.
- Issue: продолжение исследования совместных частот ФИО по запросу пользователя.
- Гипотеза: начало статьи позволяет получить явно написанное отчество при отсутствии структурированного свойства Викиданных.

## Настройка

- Данные: текущие ответы WDQS и MediaWiki, время и SHA-256 ответов в обезличенной сводке. Содержимое источников меняется; хеш фиксирует ответ, но не заменяет архив для точного повторения.
- Совокупность: первые по URI элементы «человек, гражданство РФ, русская статья». Это смещённая исследовательская выборка биографий, а не жители России.
- Конфиг: запрос и ограничение в `tools/pilot_wikipedia_fullnames.py`; начало статей запрашивается последовательно пакетами. Текст, имена, заголовки и идентификаторы обрабатываются только в памяти.
- Разбор: три начальных слова с поддерживаемым окончанием отчества; согласование частей с заголовком; ударения удаляются, ё и й сохраняются. Другие формы не угадываются.
- Коммит основы: `68b090e5db4664e3802e09a17976f45e1d7601bb`; незакоммиченные изменения рабочего дерева.
- Среда: Windows, Python, стандартная библиотека; GPU не нужен.

```powershell
python -X utf8 tools/pilot_wikipedia_fullnames.py --download
python -X utf8 tools/pilot_wikipedia_fullnames.py
python -X utf8 tools/pilot_wikipedia_fullnames.py --latest-attempt
python -X utf8 -m unittest discover -s tests -p test_wikipedia_fullnames.py
```

Первая команда повторяет сбор текущих ответов; вторая показывает сохранённую завершённую сводку `data/reference/wikipedia-fullname-pilot-2026-11-16.completed.json`, третья — последнюю попытку, в том числе частичную. Файлы вне git. Все численные результаты этого эксперимента доступны этими командами чтения; точное повторение расчёта из сохранённого исходного корпуса невозможно, поскольку персональные записи не сохраняются. Диагностика — описательная статистика источника, не метрики детектора из `docs/kb/metrics.md`.

## Анализ ограничений

- Отброшенное начало статьи не означает отсутствия ФИО в статье: возможны преамбула, псевдоним, другая письменная традиция и неподдерживаемая форма.
- Наличие всех структурированных свойств не означает совпадения их значений с текстом: в этом пилоте сравнивается доступность, не точность каждого поля.
- Единица подсчёта — элемент Викиданных. Не доказана дедупликация людей; одинаковые ФИО разных элементов не объединяются.
- Связь с отцом и имя отца проверяются на однозначность заполнения, но не по первоисточникам. Отчество из них не генерируется.
- Перестановочный фон учитывает разреженность таблицы, но не устраняет отбор известных биографий, половые, поколенческие и семейные зависимости.
