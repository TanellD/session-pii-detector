# Эксперимент: язык ответа VK и доступность пары ФИ

- Дата / автор: 2026-11-16, команда проекта.
- Issue: пользователь сообщил нулевые supported_accounts на непустых страницах сообщества.
- Гипотеза: представление имён в ответе не соответствует кириллическому фильтру.

## Настройка

- Данные: штатный groups.getMembers, сообщество vk, прежний детерминированный план страниц. Кеш с персональными полями хранится локально вне Git по разрешению пользователя.
- Конфиг: `lang=ru`, `parser_version=2`, поддерживаемая кириллическая запись, исключение закрытых/деактивированных аккаунтов. Минимальные исходные поля открытых активных записей теперь сохраняются до фильтра.
- Коммит основы: `68b090e5db4664e3802e09a17976f45e1d7601bb` и изменения рабочего дерева.
- Команды: `python -X utf8 tools/collect_vk_group_members.py --group vk --limit 10000 --download`, затем та же команда без `--download` для пересчёта без сети.
- Среда: Windows, Python, стандартная библиотека, CPU.

## Результаты

Получен непустой поддерживаемый корпус. Все численные результаты и оговорки приведены в [заметке](../research/notes/vk-community-member-pairs-2026-11-16.md) и воспроизводятся из локального кеша указанной командой. Хеши страниц, язык и версия обработки записаны в results.json. Кеш не содержит контактов и изображений. Метрики сессионного детектора не вычисляются.

## Анализ ошибок

Ранее язык запроса не задавался, а отклонённые написания не сохранялись. Причина нулевого результата скрывалась за общей категорией неподдерживаемого имени. Старые страницы сохранены в отдельном архиве; для них понадобилось повторное скачивание. Часть новых записей по-прежнему имеет неподдерживаемые написания; фильтр не доказывает правильность паспортного имени. Отсутствие страны и изменения членства между запросами ограничивают переносимость.

## Вывод и следующий шаг

Гипотеза подтверждена сравнением наличия письменностей в ответах и успешным сбором с явным языком. Следующий этап — исследование отклонённых форм на локальном кеше, зависимости ФИ с контролем пола и сопоставление с отдельным источником; национальные частоты пока не принимаются.
