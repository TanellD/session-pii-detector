## Ограничения и следующие действия

Веса риска остаются baseline. Нужна отдельная проверка на эталонных атрибутах и владельцах с независимыми ожидаемыми алертами. В первом срезе проверить происхождение эталонного алерта; в производном наборе по сценариям Андрея сохранён авторский момент.

Pairwise линкера оценивается только на сопоставленных спанах, неизвестные эталонные владельцы исключены. Алерты рассчитаны по завершённым сессиям, отказы опубликованы отдельно. Корпуса синтетические и частично использовались при отладке.

Далее: v2 + Gemma, разбор FIRST_NAME / PERSON и профессий, новые семейства диалогов с несколькими людьми и поздними уточнениями, отдельная оценка риска. Данные из data/ не добавлять в git.
