# Эксперимент: Gemma и Qwen через Radeon Cloud

- Дата: 2026-11-19.
- Базовый коммит: `79c8103`; код runner, проверки и отчёт добавлены вместе.
- Задача: использовать открытые модели для LLM-разметки с возможностью переноса на свой сервер.
- Гипотеза: предоставленные пользователем ID принимают Chat Completions запросы и позволяют получить валидную разметку по текущему контракту.

## Настройка

Провайдер: `https://developer.amd.com.cn/radeon/api/v1`, ID `Gemma-4-31B-IT` и `Qwen3.8-27B`. Ключ — только локальный `RADEON_API_KEY`. Конфигурация — `configs/llm-annotation-providers.json`. Карточки моделей и usage points предоставлены пользователем; денежная стоимость из points или поля `usage.cost` не выводилась.

Вход: `data/experiments/llm-annotation-pilot-2026-11-18/sessions.json`, только исходные синтетические сообщения, без сохранённых аннотаций и ожидаемых алертов. Использованы первые сессии до заданного лимита; runner останавливался при первой ошибке. Политика `2026-11-18-working-v2`, промпт, схема, вход и их хеши зафиксированы в манифестах каждого прогона. Среда — Windows / Python. Параметры: `temperature=0`, `max_tokens=6000`, timeout сетевой операции — 90 секунд для корпусных запросов. Это не гарантия общей длительности batch и не измерение p95.

## Команды

Короткие синтетические пробы, отдельно от корпусной разметки:

```powershell
python -X utf8 tools/run_compatible_annotation_pilot.py --model Gemma-4-31B-IT --probe --timeout 60
python -X utf8 tools/run_compatible_annotation_pilot.py --model Qwen3.8-27B --probe --timeout 60
```

Корпусные запуски выполнялись с новым выходным каталогом для каждого режима:

```powershell
python -X utf8 tools/run_compatible_annotation_pilot.py --model Gemma-4-31B-IT --limit 2 --output data/experiments/radeon/2026-11-19-gemma-run-01 --timeout 90
python -X utf8 tools/run_compatible_annotation_pilot.py --model Qwen3.8-27B --limit 2 --output data/experiments/radeon/2026-11-19-qwen-run-01 --timeout 90
python -X utf8 tools/run_compatible_annotation_pilot.py --model Gemma-4-31B-IT --span-mode quotes --limit 2 --output data/experiments/radeon/2026-11-19-gemma-quotes-run-01 --timeout 90
```

Повтор требует новых имён каталогов; старые результаты не перезаписываются. Для воспроизведения таблицы по сохранённым файлам **без сети**:

```powershell
python -X utf8 tools/summarize_annotation_runs.py data/experiments/radeon/2026-11-19-gemma-run-01 data/experiments/radeon/2026-11-19-qwen-run-01 data/experiments/radeon/2026-11-19-gemma-quotes-run-01
```

## Результаты

Обе короткие пробы вернули запрошенный JSON. В ответах API были alias `self-dploy/Gemma-4-31B-IT` и `self-dploy/Qwen3.8-27B`. Приём запроса с `json_schema` и корректный ответ на простую пробу не доказывают принудительное исполнение схемы сервером. Совпадение с конкретной публичной ревизией весов не установлено.

| Прогон | Корпусных запросов | Формально валидных аннотаций | Результат |
|---|---:|---:|---|
| Gemma, числовые offsets | 1 | 0 | Завершённый JSON, но границы сущности включают внешний пробел. Ответ сохранён и отклонён. |
| Qwen, числовые offsets | 1 | 0 | `TimeoutError`, полного ответа нет; качество разметки по этому запросу не оценено. |
| Gemma, точные quotes | 2 | 1 | Первая сессия прошла контракт; следующая завершилась `TimeoutError`. |

Количества и причина ошибки воспроизводятся командой сводки выше. Это технические исходы запросов, не Precision/Recall/F2. Независимая проверка человеком ожидается во всех манифестах.

В валидном кейсе `pilot-pair_then_email` обработчик получил сочетание частей имени с личной почтой и первый алерт `m3/combination_rule`. Ранние пометки неуверенности сохранились. Это согласуется с сохранённым сценарием, но не является независимой оценкой качества модели.

## Анализ ошибок

LLM может правильно выбрать сущность и ошибиться при счёте символов. Поэтому добавлен **явный** транспортный режим `annotation-quotes-v1`: модель возвращает точный фрагмент и номер вхождения, инструмент вычисляет Unicode-позиции и формирует тот же финальный `annotation-mvp-v2`. Не выполняются исправление цитаты, поиск похожих строк или переназначение владельца. Неверное/отсутствующее вхождение отклоняется. Исходный неуспешный offsets-прогон сохранён отдельно; его результат не подменён успехом нового режима.

Тайм-ауты не доказывают низкое качество модели и не позволяют ранжировать Gemma/Qwen. Автоматических повторов, смены модели или ослабления формата не было. Запрос, который истёк на клиенте, мог продолжиться у провайдера; его usage неизвестен и не считается нулевым.

## Проверки реализации и вывод

`python -X utf8 -m unittest discover -s tests` — **165 тестов успешно**. Проверены отсутствие сети в dry-run, отсутствие ключа, остановка на rate error, отсутствие секрета в артефактах, отказ при изменении сообщений, незавершённом ответе и неверных точных цитатах. Это тесты runner и прежнего проекта, не метрики качества LLM.

Доступ к обеим моделям подтверждён. Для следующего небольшого прогона рекомендуем явный режим `quotes`; для массовой разметки ещё нужны проверка доступности провайдера, независимый gold и сравнение ошибок на разнообразных сессиях. Руководство — [Radeon и свой сервер](../data/radeon-llm-annotation.md).
