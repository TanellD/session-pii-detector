# Неизвестный владелец сущности не делает вердикт неопределённым

- Дата: 2026-11-18.
- Основание: прямое уточнение пользователя после LLM-пилота.
- Связано: [общий конфиг и контекст](../project/annotation-context-config-2026-11-18.md).

## Что увидели

Обработчик ранее включал неопределённость при наличии любой сущности без персоны. Это смешивало принадлежность спана с недостатком статистики для алерта. Общие контакты могли сделать результат неопределённым, хотя по текущему правилу они просто не участвуют в личном сочетании.

## Доказательство

Синтетические регрессии: `python -X utf8 -m unittest discover -s tests -p test_annotation_contract.py`. Проверяется, что непривязанные контакты остаются в исходных сущностях с `null`, не создают персону и не включают флаг неопределённости вердикта. Неподтверждённые частоты имени по-прежнему дают неопределённость, если без них нельзя завершить численный путь.

## Что это значит для проекта

Принадлежность хранить в сущности, неопределённость вердикта — на уровне кейса. Конфиг и вычислительный обработчик использовать совместно с контекстом LLM; не поручать модели угадывать доступность статистик.
