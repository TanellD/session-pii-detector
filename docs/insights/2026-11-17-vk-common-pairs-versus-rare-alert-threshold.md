# Частые ФИ уже позволяют проверять зависимость, редкий национальный порог — ещё нет

- Дата: 2026-11-17.
- Автор: команда проекта.
- Связано: [эксперимент](../experiments/2026-11-17-vk-annotation-evidence.md), [результаты](../research/notes/vk-annotation-evidence-2026-11-17.md).

## Что увидели

На увеличенном кеше условная по полу поправка совместных частот улучшает оценку для выбранных частых ФИ плюс категории OTHER. Это положительный результат более узкой проверки, который не превращается в оценку вероятностей всех редких написаний. Большой объём и статистическая достаточность для порога алерта — разные вопросы.

## Доказательство

Все числа воспроизводятся `python -X utf8 tools/analyze_vk_annotation_evidence.py` по замороженным SHA-256 страниц. Принятых аккаунтов 384002, единичным ФИ соответствуют 71,39% аккаунтов. При отборе пар от пяти наблюдений в оценочной части смесь выиграла во всех пяти разбиениях; выбранные пары охватывают 6,11% отложенных аккаунтов. После отдельной проверки текущего плана результат сохраняется, но это вложенный срез, не независимая площадка.

В условной популяции 150 млн даже идеальная репрезентативная выборка такого размера в среднем содержит лишь 0,256 наблюдения сочетания на 100 человек. В реальном источнике дополнительно не подтверждены население, написания и уникальность людей; нет отчеств.

## Что это значит для проекта

Продолжать исследование условных частот частых ФИ уже можно. Общий поправочный коэффициент, перенос на ФИО или национальное число людей из этого результата не следуют. Текущий режим частот остаётся исследовательским; приоритет следующего сбора — охват и независимая проверка, а не только объём.
