# В таблице занятий есть оба направления условной вероятности

- Дата: 2026-11-15.
- Связано: [проверка PDF](../experiments/2026-11-15-rosstat-occupation-pdf.md).

## Что увидели

Предоставленный PDF закрывает пробел исторических совместных агрегатов занятия и пола. В одной таблице есть доля профессиональной группы среди занятых данного пола и доля пола среди работников группы. Это разные условные вероятности. Численности округлены, поэтому суммы отдельных ячеек могут не совпадать с опубликованным итогом.

## Доказательство

Команда `python -X utf8 tools/inspect_rosstat_occupation_pdf.py --table 2.40` показывает оригинальные заголовки и ячейки. Проверенный SHA-256, страницы и результаты указаны в отчёте. Парсер сохраняет исходные округлённые значения и не подгоняет их арифметически.

## Что это значит для проекта

Для калькулятора можно брать совместную численность группы и пола, избегая повторного независимого умножения. Редкость узкой должности из широкой группы не следует. Дата выпуска не равна дате данных, а исторический файл не становится последним доступным по факту успешного чтения.
