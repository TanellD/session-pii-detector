# API ОК: права приложения и отдельная проверка полноты имени

- Дата: 2026-11-17.
- Автор: команда проекта.
- Связано: [исследование API ОК](../research/notes/ok-api-name-access-2026-11-17.md).

## Что увидели

Переход с VK на ОК не даёт немедленной выгрузки без регистрации приложения. Для выбранной цепочки методов нужны выданные права и сессия; отдельное поле отчества в проверенной схеме профиля не найдено. Официальная инструкция содержит новое уведомление о VK Mini Apps и старые шаги регистрации, поэтому актуальный путь для внешнего REST-приложения требует уточнения.

## Доказательство

Источники и ограничения перечислены в исследовательской заметке. Команда `python -X utf8 tools/probe_ok_name_access.py` в текущем окружении вернула `configuration_required`, `network_used: false`. В `.env` отсутствуют нужные ключи ОК и ID группы; значения секретов не выводились. Проверки подписывания и ограничения пилота: `python -X utf8 -m unittest discover -s tests -p 'test_ok_access_probe.py'`.

## Что это значит для проекта

ОК рассматривается как кандидат для независимого корпуса ФИ аккаунтов. Сбор миллиона полных ФИО и репрезентативность для населения не подтверждены. Следующий внешний шаг — регистрация и выдача прав владельцу приложения; подготовленный пилот позволит проверить доступ до массовой разработки. Коды ошибок ОК отличаются от VK, обработчик ограничений нельзя копировать без проверки.
