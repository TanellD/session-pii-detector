# Нормализованный ранг популярности не является вероятностью имени

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [проверка направлений источников](../research/notes/name-sources-moscow-registries-corpora-2026-11-16.md).

## Что увидели

Один из найденных наборов с именами и «весами популярности» прямо определяет popularity_score как нормализованный ранг. Это не доля носителей имени. Ряд частот новорождённых также не содержит совместного наблюдения имени ребёнка и отчества без дополнительных данных.

## Доказательство

Поле описано владельцем: https://huggingface.co/datasets/rustemgareev/russian-names/raw/main/README.md. Карточка другого владельца повторяет описание и ссылку загрузки исходного проекта; независимость источников не установлена.

## Что это значит для проекта

Сначала установить единицу веса. Нормировать ранговые score до суммы единицы можно технически, но полученные веса не станут измеренными вероятностями населения. Совместную зависимость нельзя оценить по искусственным комбинациям или по несогласованным маргинальным таблицам.
