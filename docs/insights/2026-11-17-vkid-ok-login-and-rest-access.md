# Вход через ОК доступен в существующем приложении VK ID

- Дата: 2026-11-17.
- Автор: команда проекта.
- Связано: [доступ к API ОК](../research/notes/ok-api-name-access-2026-11-17.md).

## Что увидели

Актуальная страница OAuth ОК переводит интеграцию входа на VK ID SDK с OAuth 2.1. SDK поддерживает провайдер OK в одной конфигурации приложения с другими способами входа. Ранее рекомендация регистрировать новое приложение до проверки повторного использования VK ID была слишком общей.

## Доказательство

[OAuth ОК](https://apiok.ru/ext/oauth/); [официальный SDK VK ID](https://github.com/VKCOM/vkid-web-sdk), пример OAuthList с `VKID.OAuthName.OK` при общем `APP_ID`.

## Что это значит для проекта

Для входа через ОК следует начать с существующего приложения VK ID. Право массового чтения профилей через REST API ОК, необходимость REST-ключей и пригодность конкретного токена остаются отдельными неподтверждёнными вопросами. Из поддержки провайдера авторизации нельзя заключать, что доступ к спискам участников уже выдан.
