# Предварительные алерты нельзя использовать вместо калькулятора разметки

- Дата: 2026-11-25.
- Связано: PR #47, [проверка эталона](../experiments/2026-11-25-weight-label-calculator-review.md).

## Что увидели

Исходный корпус сочетаний имел авторские предположения об алертах, хотя в проекте уже есть калькулятор численности кандидатов. Маркировка меток как предварительных не делает их подходящим эталоном для проверки весов по существующей политике.

## Доказательство

Команда `tools/relabel_weight_300.py` из связанного эксперимента пересчитывает метки и сохраняет префиксные основания. Она отделяет неизвестную статистику от принятого достаточного основания. Исходные предсказания не меняются, поэтому изменение метрик отражает исправление эталона.

## Что это значит для проекта

Метки должны опираться на правила и доступные справочники независимо от весов сервиса. Неизвестную статистику нужно сохранять явно. Отрицательные метки с такой неопределённостью нельзя трактовать как доказательство безопасности или использовать без оговорок для калибровки весов. Пересмотр эталона версионируется отдельно от инференса.
