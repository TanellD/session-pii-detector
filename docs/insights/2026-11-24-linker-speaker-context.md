# Карточек атрибутов недостаточно для сохранения роли говорящего

- Дата: 2026-11-24.
- Автор: команда проекта.
- Связано: [пилот Gemma-линера](../experiments/2026-11-24-gemma-linker-baseline.md).

## Что увидели

В `synthetic-1000-0021` сначала названы автор сообщения и его коллега,
потом общий телефон, затем почта «только моя». Линкер без текста истории
правильно разделил имена и назначил телефону обоих владельцев. Почту
он отнёс к новому человеку, потому что в карточках не сохранилась роль говорящего.

## Доказательство

Первый результат сохранён в `gemma-linker-pilot-2026-11-24`, повтор с
окном контекста — в `gemma-linker-context-pilot-2026-11-24`. В повторе
почта принадлежит ранее названному автору. Промпт получает только прошлые
сообщения, готовые кандидаты и собственные прежние связи; эталонные
владельцы и будущие сообщения не передаются.

Числа и случаи воспроизводятся командами `--report-only` из эксперимента.

## Что это значит для проекта

Передача модели только значений фактов теряет дискурсивные роли.
В текущем baseline используется ограниченное окно текста внутри сессии.
Более компактная альтернатива для исследования — хранить подтверждённые
роли говорящего в структурированном состоянии. Пилот использован для
отладки и не доказывает качество на независимых данных.
