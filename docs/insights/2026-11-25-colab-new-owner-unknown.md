# Локальный линкер: новый профиль ошибочно заменяется неизвестным владельцем

- Дата: 2026-11-25.
- Связано: [Colab notebook](../api/colab-linker.md).

## Что увидели

Пользователь прислал исходный ответ Colab: при пустом `known_people` и двух кандидатах фамилии и имени одного явно названного заявителя модель назначила обоим пустые `owners`. Такой ответ допустим по JSON-контракту, но семантически неверен: должно быть назначение одного нового профиля обоим атрибутам.

## Доказательство

Исходный вход — начало `synthetic-1000-0001` из экспортированного среза. В пользовательском сообщении приведены запрос и ответ: оба назначения имеют `owners=[]`. Это подтверждает ошибку на данном сообщении; не доказывает, что все ошибки пилота имеют ту же причину. Полный архив результатов этого Colab-запуска в workspace отсутствует.

## Что это значит для проекта

`complete` означает валидность контракта, а не правильность принадлежности. Локальная инструкция уточнена: владелец — субъект сведений; отсутствие ранее созданных профилей не означает неизвестного владельца; части одного нового имени должны получить один `new:N`. Автоматически заменять пустые назначения на новые профили нельзя: для действительно неизвестных владельцев пустой список нужен.

В новой версии сохраняется фактический системный промпт, используется отдельная папка результатов и хеш дополнительных инструкций. Эффект уточнения на модели не измерен. Для оценки переноса нужны новые независимые сценарии, а не только повтор этого примера.
