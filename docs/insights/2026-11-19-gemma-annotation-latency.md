# Скорость последовательной разметки Gemma через Radeon

- Дата: 2026-11-19.
- Автор: команда проекта.
- Связано: [русские префиксы CONFIDE и выборочная проверка](../experiments/2026-11-19-russian-session-dataset-gemma-review.md).

## Что увидели

По сохранённым файлам последнего прогона приблизительное среднее время одного запроса — 14,22 с, медиана — 8,85 с, p95 по ближайшему рангу — 50,07 с, максимум — 80,35 с. Всего 38 ответов; от начала запуска до сохранения последнего ответа прошло около 657 с (11 минут), включая заданные паузы по 3 с. Таймаутов в этом запуске не было, но один ответ не прошёл проверку разметки.

## Доказательство

Воспроизводится без сети по локальным артефактам:

```powershell
python -X utf8 -c "import pathlib,json,statistics,datetime,math; p=pathlib.Path('data/experiments/radeon/2026-11-19-russian-dataset-gemma-01'); files=sorted(p.glob('*-response.json')); t=[f.stat().st_mtime-f.with_name(f.name.replace('-response.json','-request.json')).stat().st_mtime for f in files]; start=datetime.datetime.fromisoformat(json.loads((p/'manifest.json').read_text())['started_at']).timestamp(); print(dict(requests=len(t),mean_seconds=statistics.mean(t),median_seconds=statistics.median(t),p95_seconds=sorted(t)[math.ceil(.95*len(t))-1],max_seconds=max(t),wall_seconds=max(f.stat().st_mtime for f in files)-start))"
```

Это разность времён изменения файлов запроса и ответа, а не инструментированный таймер инференса. Она включает сеть, очередь провайдера и небольшие локальные операции между сохранениями. Перенос файлов с изменением времён делает такую реконструкцию недействительной. Общая длительность не включает завершающую обработку после последнего ответа. Настройки и источник зафиксированы в манифесте прогона.

## Что это значит для проекта

Скорости достаточно для небольшого офлайн-пилота с проверкой. Она пока не подтверждает пригодность для проверки каждого сообщения в интерактивном чате. Это результат облачного API на коротких префиксах, а не оценка скорости собственного развёртывания. Для следующих замеров стоит сохранять монотонную длительность каждого запроса непосредственно в манифесте.
