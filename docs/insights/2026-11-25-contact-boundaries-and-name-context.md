# Защита контактов и контекст ФИО решают разные ошибки

- Дата: 2026-11-25.
- Связано: [эксперимент v2](../experiments/2026-11-25-adapter-v2.md), PR #47.

## Что увидели

Сущности внутри email дают лишние спаны и отказ обработки. Неверные части ФИО могут прийти уже типизированными: обработка только PERSON их не исправляет.

## Доказательство

Раздельно измерены v1, защита контактов и правила имени. Таблицы и команда воспроизведения — в связанном эксперименте. EMAIL sampleclub.21@example.invalid не должен дополнительно становиться ORGANIZATION и AGE.

В первой реализации нового оценщика общий успешный срез использовал последний вариант для всех строк. Проверка счётчиков обнаружила ошибку; добавлен тест с различными предсказаниями. Результаты пересчитаны в -r2; raw-метрики не затронуты.

## Что это значит для проекта

Нужны отдельные показатели качества спанов и успешной обработки. Прирост на изученных шаблонах нужно подтвердить новыми диалогами. Устранение NER-конфликтов не исправляет невалидные ответы линкера.

Windows PowerShell pipeline при неверной кодировке может заменить русский текст знаками вопроса. Запись должна использовать UTF-8; содержимое нужно проверять перед публикацией, секрет-сканер такую потерю не выявляет.
