# Обнаруженная зависимость ФИ не означает достаточности данных для редких пар

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [эксперимент достаточности](../experiments/2026-11-16-vk-pair-sample-adequacy.md).

## Что увидели

После учёта заявленного пола внутри источника остаётся разведочный сигнал зависимости имени и фамилии, однако парных повторов мало. Проверенная совместная оценка проигрывает независимой базе на отложенных аккаунтах при всех исследованных силах сглаживания и разбиениях.

## Доказательство

Команда для сохранённого пилота `python -X utf8 tools/assess_vk_pair_sample.py --group vk --snapshot-limit 10000`, исходный локальный кеш и хеши страниц в `snapshots/limit-10000/adequacy.json`. Численные результаты и ограничения общего словаря с UNK описаны в исследовательской заметке. Тест `python -X utf8 -m unittest discover -s tests -p test_vk_pair_adequacy.py` использует только синтетические категории.

## Что это значит для проекта

Различать наличие статистической связи, точность её оценки для конкретного сочетания и переносимость на население. Слабое приближение не подтверждает истинную независимость. Нужны повторы, независимые источники и заданная целевая ошибка; по текущей выборке общий коэффициент не принимается.
