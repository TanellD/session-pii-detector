# Изменение границ реплик меняет индекс первого алерта

- Дата: 2026-11-26.
- Связано: [авторский пилот сложностей](../experiments/2026-11-26-difficulty-pilot-90.md).

## Что увидели

При изменении длины диалогов недостаточно скопировать индекс первого алерта из исходного сценария. Объединение соседних сообщений меняет индекс, а разделение триггерной реплики может создать более ранний доступный префикс. Это особенно существенно для исправлений внутри одного завершённого сообщения.

## Доказательство

Материализатор пилота сохраняет соответствие исходных абзацев конечным сообщениям и переводит авторский контрольный индекс, после чего пересчитывает весь эталон существующим калькулятором. Команда сборки и повторного аудита указана в связанном эксперименте. При расхождении контрольного и рассчитанного индексов сборка завершается ошибкой.

## Что это значит для проекта

Варьирование длины требует проверки конечных текстов по префиксам. Исходный порядок фактов и промежуточная разметка не заменяют эталон на окончательных границах сообщений; первый момент определяется завершённой репликой по текущему ТЗ.
