# Документация VK ID подтверждает поток PKCE, но не доступ к поиску аккаунтов

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [проверка инструкции VK ID](../research/notes/vk-api-name-pairs-setup-2026-11-16.md).

## Что увидели

Публичную инструкцию VK ID удалось прочитать прямым HTTP-запросом, хотя веб-инструмент сообщал об ошибке доступа. Описан Authorization Code + PKCE с проверкой state и обменом кода с device_id. Раздел прав относится к данным авторизовавшегося пользователя и не подтверждает доступ к users.search.

## Доказательство

[Присланная инструкция](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/auth-without-sdk/auth-without-sdk-web), [права VK ID](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/work-with-user-info/scopes). Ссылки и границы проверки записаны в исследовательской заметке. Токен не выдавался; поиск пользователей не выполнялся.

## Что это значит для проекта

Можно опираться на документированный поток авторизации, но готовность исследовательского поиска определяется отдельно доступом конкретного метода. Не превращать отсутствие подтверждения в категорическое утверждение о несовместимости. Сбор участников собственной авторизации отличается от поиска профилей по платформе.
