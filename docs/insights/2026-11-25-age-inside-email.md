# Проверки формата возраста недостаточно для AGE внутри email

- Дата: 2026-11-25.
- Связано: [проверка на следующих сессиях](../experiments/2026-11-25-adapter-next-250.md).

## Что увидели

На новом срезе зафиксированная ревизия адаптера сохраняет модельный AGE на цифрах внутри полного email. Число удовлетворяет формату возраста, но по контексту частью возраста не является. Сервис умеет подавлять PERSON внутри контакта, но конфликт AGE/EMAIL пока не разрешает и отклоняет сообщение.

## Доказательство

Синтетическая сессия `synthetic-1000-0459`, m2: `Моя личная почта testimir.21@example.invalid.` В сохранённых revised-предсказаниях EMAIL занимает [17:44], AGE — [26:28]. Ошибка `Unresolved cross-type overlap` находится в `results/summary.json → filtered.revised.errors`.

```powershell
.\.venv-gliner\Scripts\python.exe -X utf8 tools/evaluate_adapter_revision.py --snapshot data/experiments/adapter-next-250-2026-11-25/snapshot.json --recordings data/experiments/adapter-next-250-2026-11-25/ner --output data/experiments/adapter-next-250-2026-11-25/results
```

## Что это значит для проекта

Нужно отдельно согласовать и реализовать подавление числовых атрибутов внутри валидных контактов, не полагаясь только на fullmatch значения. Это не основание подавлять все неоднозначные пересечения без правила. Ревизия `adapter-candidate-v1` оставлена неизменной: исправление данного случая относится к следующей версии, а не к пересчёту уже просмотренного теста.
