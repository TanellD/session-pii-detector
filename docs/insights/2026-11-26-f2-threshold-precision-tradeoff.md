# Максимизация F2-timely увеличивает ложные алерты на неуверенных отрицательных

- Дата: 2026-11-26.
- Связано: [эксперимент с порогами](../experiments/2026-11-26-validation-thresholds-only.md).

## Что увидели

Снижение порога известного владельца при фиксированных весах повышает F2-timely,
одновременно снижая precision и увеличивая ложные алерты. FP0 по уверенно
отрицательным при этом может оставаться нулевым.

## Доказательство

Числа, исходные параметры и команда воспроизведения сохранены в связанном
эксперименте и calibration/report.json. Выбранный вариант проверен настоящим
RiskEvaluator, модели повторно не запускались.

## Что это значит для проекта

При выборе политики публиковать обе частоты ложных алертов, precision и покрытие
обработки. Максимум F2 на validation не заменяет проверку test и не доказывает
качество NER; ошибочные сессии не должны исчезать из отчёта о надёжности сервиса.
