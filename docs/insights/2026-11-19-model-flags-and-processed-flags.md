# Правильные сущности не гарантируют правильный флаг неуверенности

- Дата: 2026-11-19.
- Связано: [сравнение на авторских сессиях](../experiments/2026-11-19-ten-session-model-comparison.md), draft PR #44.

## Что увидели

В ответе Gemma на `compare-yellow_profile` выделены ожидаемые сущности и их персона, но исходный флаг неуверенности выключен. Обработчик отмечает недостаток статистики и сохраняет эту пометку в истории. Только просмотр итогового расчёта скрывает различие между решением модели и вычисленной частью результата.

## Доказательство

Команда сравнения сохранённых прогонов приведена в отчёте эксперимента. В `model-comparison.json` раздельно сохраняются `model_flags`, `gold_flags`, `model_flags_exact` и `processed_flags_exact`. Исходный ответ внешней модели не исправляется. Локальный файл `02-annotation.json` прогона Gemma содержит выключенный флаг, а `02-assessment.json` — вычисленную историческую неуверенность.

## Что это значит для проекта

Для автоматизации можно использовать вычисляемую часть флагов обработчика, сохраняя исходный ответ. Согласованность итоговых флагов нельзя объявлять качеством суждений LLM, если они добавлены после неё. Пробелы ТЗ, которые обработчик не распознаёт, всё ещё требуют разметчика или проверки человеком.
