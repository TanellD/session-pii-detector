# Вычисленное отчество не является независимым наблюдением имени отца

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [проверка Викиданных](../research/notes/wikidata-name-father-2026-11-16.md).

## Что увидели

Викиданные позволяют соединить человека с отцом и именем отца, однако отчество лучше брать из явно наблюдаемого источника. Генерация отчества по имени отца не создаёт нового свидетельства зависимости.

## Доказательство

Свойства: https://www.wikidata.org/wiki/Property:P22 и https://www.wikidata.org/wiki/Property:P5056. Воспроизведение выполненной проверки заполненности: `python -X utf8 tools/check_wikidata_name_coverage.py`.

## Что это значит для проекта

Отдельно учитывать наблюдаемое отчество и вычисленную форму. Для зависимости имени и отчества отец не обязателен; для межпоколенческой зависимости нужны реальные пары и учёт семей. Русскоязычная Википедия не является выборкой жителей России.
