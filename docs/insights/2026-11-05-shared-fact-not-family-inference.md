# Общий факт не следует автоматически из родства

- Дата: 2026-11-05
- Автор: не указан
- Связано: PR #16, #21/#24/#25, обсуждение MVP

## Что увидели
Явно общий адрес можно связать с несколькими людьми. Из «моё имя X,
фамилия моей мамы Y» общая фамилия не следует: признаки принадлежат разным людям.

## Доказательство
Это синтетические контрпримеры к отождествлению общей принадлежности факта
и переноса атрибута по родственной связи; см. [описание MVP](../project/mvp-scope-proposal-2026-11-05.md).

## Что это значит для проекта
В baseline поддерживать явные связи факт–человек, а вывод по родству
считать отдельной неподтверждённой гипотезой. Иначе линковка создаёт ложные профили.
