# Расширение корпуса ФИ увеличивает повторы, но не обосновывает общий коэффициент

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [эксперимент расширенной выборки VK](../experiments/2026-11-16-vk-expanded-pair-sample.md).

## Что увидели

В расширенном корпусе появились чаще повторяющиеся ФИ, но проверенная сглаженная совместная оценка по-прежнему проигрывает независимой базе на отложенных аккаунтах. При этом внутри пола остаётся отличие от перестановочного фона. Обнаружение зависимости и полезность конкретного способа оценки вероятностей — разные вопросы.

## Доказательство

Команды: `python -X utf8 tools/assess_vk_pair_sample.py --group vk` и `python -X utf8 tools/assess_vk_pair_sample.py --group vk --snapshot-limit 10000`.

Поддерживаемых аккаунтов стало 63098 против 6303, сочетаний с частотой не менее пяти — 184 против нуля. При seed=42 в проверочной части 11226 из 12620 пар ранее не встречались. При каждой из четырёх сил сглаживания совместная оценка выиграла в нуле из пяти разбиений. Медиана отношения совместной частоты к произведению маргинальных среди отобранных повторяющихся пар не является подтверждённой поправкой для нового сочетания.

## Что это значит для проекта

Нельзя заменить недостающую валидацию произвольным общим коэффициентом или автоматически перенести результат ФИ на ФИО. Пол следует учитывать через условные частоты; настройку оценки отделять от окончательной проверки. Данные одного сообщества остаются исследовательскими аккаунтами без подтверждённого охвата населения.
