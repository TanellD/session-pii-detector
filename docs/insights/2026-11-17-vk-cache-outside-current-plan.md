# Часть сохранённых страниц VK не входит в текущую сетку смещений

- Дата: 2026-11-17.
- Автор: команда проекта.
- Связано: [план миллиона записей](../experiments/2026-11-16-vk-million-pair-sample.md).

## Что увидели

Прежние отчёты правильно считали страницы текущего плана, но не показывали полный объём всех сохранённых страниц. При расширении менялась сетка смещений, поэтому часть прежних страниц осталась на диске вне нового плана. Это не потерянные данные и не результат последующего запуска с ошибкой.

## Доказательство

Команда полного офлайн-аудита: `python -X utf8 tools/audit_vk_cache.py --group vk`.

На момент проверки: текущему плану соответствуют 200 страниц и 200000 исходных записей; вне него находятся ещё 90 страниц и 90000 записей. Всего сохранено 290000 исходных записей и 180758 уникальных принятых ID аккаунтов. Из них 123963 относятся к текущему плану, дополнительные 56795 — только к другим страницам. Повреждённых актуальных JSON и временных файлов в папке группы не обнаружено. Папка `legacy-unlocalized` не включается в объединение актуальных страниц.

Последняя исходная страница изменена 2026-11-17 в 00:00:40 МСК; позднее пересчитывалась сводка, что не является новой выгрузкой. Приложенный лог содержит таймаут TLS до получения успешного ответа и вторичный сбой диагностики; он не свидетельствует о полученной, но не записанной странице с профилями.

## Что это значит для проекта

Для ответа «сколько сохранено на компьютере» нужен аудит всех страниц, а для прогресса детерминированного плана — только его страниц. Объединение разных планов нельзя выдавать за прежнюю процедуру выборки или незаметно включать в расчёт её статистик. Аудитор разделяет эти совокупности, считает уникальные ID без вывода самих ID и не использует сеть. Проверка пересечения ID и повреждённых файлов синтетическая: `python -X utf8 -m unittest discover -s tests -p 'test_vk_cache_audit.py'`.
