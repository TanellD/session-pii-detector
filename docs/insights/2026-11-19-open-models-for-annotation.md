# Открытые веса позволяют перенести LLM-разметку с API на свой сервер

- Дата проверки: 2026-11-19.
- Связано: `tools/run_llm_annotation_pilot.py`, `docs/data/llm-annotation-prompt.md`.
- Статус: проверка первичных источников и рекомендации для пилота; модели не запускались, качество русской разметки не измерялось.

## Что увидели

Сервис API и доступность весов — разные условия. У нескольких моделей из сообщения пользователя есть официальные публичные веса и инструкции собственного развёртывания. Это позволяет выбрать переносимого разметчика независимо от длительности бесплатного предложения провайдера.

| Кандидат | Первичный источник | Лицензия в карточке | Роль в нашем пилоте — предложение |
|---|---|---|---|
| Qwen3.8-27B | [Qwen](https://huggingface.co/Qwen/Qwen3.8-27B) | Apache-2.0; [файл лицензии](https://huggingface.co/Qwen/Qwen3.8-27B/raw/main/LICENSE) | Первый кандидат для сравнения, исходя из возможности собственного развёртывания; качество на наших данных не подтверждено |
| Gemma-4-31B-IT | [Google](https://huggingface.co/google/gemma-4-31B-it), [описание](https://huggingface.co/google/gemma-4-31B-it/raw/main/README.md) | Apache-2.0 по карточке этой версии | Второй разметчик для сравнения с Qwen; не переносить лицензионные сведения со старых Gemma |
| DeepSeek-V4.1-Flash-1017 | [DeepSeek](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017) | MIT | Дополнительный кандидат через API/кластер; доступные веса не означают малые требования к памяти |
| GLM-5.3-Flash | [Z.ai](https://huggingface.co/zai-org/GLM-5.3-Flash) | MIT | Дополнительный кандидат, крупная MoE-модель с опубликованными вариантами запуска |
| MiniCPM5-2B | [OpenBMB](https://huggingface.co/openbmb/MiniCPM5-2B) | Apache-2.0 | Компактный baseline; нельзя назначать основным источником gold только из-за доступности на небольшом оборудовании |

Точные требования к памяти зависят от весов, квантизации, длины контекста, batch и runtime. Активные параметры MoE не равны всему объёму хранимых весов. Проверка лицензий здесь относится к указанным репозиториям моделей, а не автоматически к их сторонним производным сборкам.

Страница [Radeon Token Factory](https://developer.amd.com.cn/radeon/tokenfactory) открывается как Radeon Cloud, но просмотр публичного содержимого возвращает JavaScript-заглушку. Текущий список бесплатных моделей, квоты, время их сброса, доступ российской регистрации и поддержка строгой JSON Schema на AMD этим просмотром не подтверждены. Авторизация и запросы с ключом не выполнялись. Одноимённый API alias также не доказывает совпадения с конкретной публичной ревизией весов.

## Доказательство и совместимость

Карточки Qwen/Gemma/DeepSeek/GLM/MiniCPM содержат примеры собственного serving. [vLLM поддерживает Structured Outputs](https://docs.vllm.ai/en/latest/features/structured_outputs/); поддержку выбранной модели, runtime и конкретного провайдера нужно проверять отдельно. Валидный JSON не доказывает правильность типов, границ или принадлежности сущностей.

Локальный `tools/run_llm_annotation_pilot.py` отправляет запросы в фиксированный OpenAI `/v1/responses`, использует `instructions`, формат Structured Outputs Responses и разбор `output[].content[]`. Поэтому замена ключа или адреса недостаточна для сервиса, который предоставляет только `/v1/chat/completions`. Это установлено чтением кода, не API-экспериментом.

## Что это значит для проекта

Переносимый адаптер подготовлен в `tools/run_compatible_annotation_pilot.py`: `base_url`, имя переменной ключа, точный ID модели и режим формата задаются явно. Остальные части сохранены: действующий промпт и каталог классов, валидатор, проверка неизменности текста и оценщик правил. Нельзя молча ослаблять JSON Schema или исправлять невалидный ответ до подсчёта ошибок. [Инструкция](../data/radeon-llm-annotation.md), [результат сетевого пилота](../experiments/2026-11-19-radeon-annotation-pilot.md). Выводы выше о непроверенном API относятся к исходному обзору до добавления пользователем ключа; пробы и ограничения зафиксированы отдельно.

Предлагаемый пилот: один синтетический набор для Qwen и Gemma, независимая проверка человеком, разрез ошибок по спанам/типам, персонам, флагам и первому алерту. Сохранять запрос/ответ, версию промпта/политики, полный ID/revision модели, настройки генерации, квантование и runtime при локальном запуске. Затем повторить проверку на выбранной локальной ревизии: API и локальные веса могут давать разные результаты. Модель извлекает сущности и связи, а численные основания и правила алерта рассчитывает наш обработчик.

Для внешнего API текущий проект допускает только синтетический пилот. Реальный исследовательский кеш ФИО не является разрешённым входом этого пилота. Модели-классификаторы, если их интерфейс возвращает только вероятности заданных категорий, не заменяют генератор структурированной спановой разметки.
