# Конкурентный обзор дополняет первичное исследование аналогов

- Дата: 2026-11-08
- Автор: команда проекта
- Связано: #12, #30, PR #20

## Что увидели

В #12 уже поставлен вопрос о PII-guardrails и DLP для LLM. В PR #20 есть
первичный обзор продуктов, детекторов и научного аналога; он явно не является
исчерпывающим обзором рынка. Создание ещё одной задачи с тем же объёмом
дублировало бы работу. #30 выделяет продолжение: сравнение готовых сервисов
как заменителей нашего решения и проверку заявлений о сессионных возможностях.
