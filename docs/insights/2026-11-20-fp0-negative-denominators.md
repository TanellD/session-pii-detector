# FP0 зависит от учёта неуверенных сессий

- Дата: 20.11.2026.
- Связано: [#41](https://github.com/TanellD/session-pii-detector/issues/41),
  [эксперимент](../experiments/2026-11-20-session-alert-baselines.md).

## Что увидели

В [протоколе метрик](../kb/metrics.md) общее правило включает сессии с
неуверенностью в FP0. Раздел 4 описывает срез уверенно отрицательных
сессий. На пилоте эти знаменатели дают разные результаты.

## Доказательство

В эталонном режиме со слиянием владельцев `test-02` дал ложный алерт после
объединения ФИ покупателя и адреса получателя. Сессия отрицательная по
рабочей политике и содержит пометку нехватки статистики. Поэтому FP0
равен 1/5 по всем отрицательным и 0/1 по уверенно отрицательным.

```powershell
python -X utf8 tools/evaluate_session_alerts.py --gold data/session-alerts-v1/gold.json --predictions runs/session-alerts-v1-reviewed/predictions.json --output runs/session-alerts-v1-reviewed/fp0-check.json
```

## Что это значит для проекта

Основной FP0 в отчёте считается по всем отрицательным сессиям. Срез
уверенно отрицательных приведён отдельно. Для обоих показаны числитель
и знаменатель.
