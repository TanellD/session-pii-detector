# Первый проход разметки не является независимой оценкой качества

- Дата: 2026-11-18.
- Связано: [пилот LLM-разметки](../experiments/2026-11-18-llm-annotation-pilot.md).

## Что увидели

LLM может подготовить примеры и аннотации в текущем диалоге, а обработчик — проверить согласованность первого алерта. При этом автор примеров уже знает правила и ожидания: прохождение проверки не показывает качество независимой модели. Вычисление границ по выбранным фрагментам также не проверяет самостоятельный счёт индексов моделью.

## Доказательство

`python -X utf8 tools/build_llm_annotation_pilot.py` сохраняет происхождение и число внешних API-вызовов в манифест. Отдельный API-runner получает только исходные сообщения, проверяет неизменность текста и сохраняет исходный ответ. При отсутствии локального ключа он возвращает явный статус до отправки запроса.

## Что это значит для проекта

Использовать текущие аннотации как предварительный материал для проверки человеком. Для следующего эксперимента отделить генерацию примеров, ответы независимого LLM-запуска и человеческий эталон. Совпадение отладочных ожиданий не называть точностью разметки.
