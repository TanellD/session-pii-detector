# Адресный справочник не подтверждает тип жилья

- Дата: 2026-11-18.
- Связано: [проверка оценщика](../experiments/2026-11-18-address-population-estimator.md).

## Что увидели

Обозначение «дом» в адресе и наличие одной квартиры не подтверждают индивидуальный жилой дом. Для выбора среднего требуется отдельное основание: явная квартира, подтверждённый тип дома или число квартир для оценки МКД.

## Доказательство

[Документация DaData](https://dadata.ru/api/suggest/address/) различает адресный тип объекта и поле числа квартир. Локальный индекс ГИС ЖКХ сохраняет отдельное поле типа дома. Синтетические проверки воспроизводятся командой `python -X utf8 -m unittest discover -s tests -p test_address_population_estimator.py`.

## Что это значит для проекта

Неизвестный тип жилья не заменяется индивидуальным домом. Конфликт источников и неоднозначный ID требуют уточнения. Среднее применяется только после классификации и показывается вместе с допущением о заселённости.
