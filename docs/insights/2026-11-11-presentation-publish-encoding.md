# Кодировка и окончания строк при публикации презентации

- Дата: 2026-11-11
- Автор: команда проекта
- Связано: публикация синка по прогрессу

## Что увидели

Передача русских строк через stdin Python из Windows PowerShell может заменить
их вопросительными знаками; запись текстов с CRLF вызвала ошибки diff --check.

## Доказательство

Проверка: `git diff --cached --check`. После записи текста в UTF-8 с LF проверка проходит.

## Что это значит для проекта

Русские публикационные тексты записываются напрямую в UTF-8; перед коммитом
проверяются кодировка и окончания строк. Содержимое презентации не изменилось.
