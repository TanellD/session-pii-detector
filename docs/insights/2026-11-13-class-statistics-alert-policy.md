# Статистика классов не определяет эталон первого алерта

- Дата: 2026-11-13
- Автор: команда проекта
- Связано: #32, #39; PR #16

## Что увидели

Агрегаты leaderboard показывают число эталонных упоминаний по меткам и наборам. Географического разреза в экспортируемых метаданных нет. NAME не различает полное ФИО и его части, DATE не означает дату рождения, ORGANIZATION не подтверждает место работы человека. Наши зоны нельзя корректно восстановить простым суммированием этих меток.

Старая локальная таблица не отражает рекомендацию ментора предпочесть алерт на одиночный телефон ради полноты. Это рекомендация для продуктовой политики, а не утверждение универсального правового правила.

## Доказательство

```powershell
python -X utf8 tools/summarize_mentor_leaderboard.py --output outputs/leaderboard-summary-2026-11-13.json
```

В JSON: `datasets` содержит состав наборов, `gold_mentions_by_dataset` — количество эталонных упоминаний, `consistency_warnings` — результаты проверки согласованности счётчиков между моделями. Счётчики не суммируются по повторным прогонам моделей и вариантам текста.

## Что это значит для проекта

Статистика полезна для выбора проверок извлечения и обнаружения пробелов покрытия. Частоты бенчмарка не обосновывают веса определяемости, порог или достаточность сочетаний. Для разметки нужно отдельно согласовать версию правил и положительные, отрицательные и неопределённые случаи. Предлагается начать с явных правил для поддержанных сценариев; неопределённые сочетания не превращать в отрицательные примеры. Принятая инструкция разметки и ADR этой заметкой не меняются.
