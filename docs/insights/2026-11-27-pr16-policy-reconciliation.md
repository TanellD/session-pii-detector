# Старый PR определения ПДн уже включён в актуальные документы

- Дата: 2026-11-27.
- Связано: PR #16, #44, #45, #47 и #48.

## Что увидели

Ветка PR #16 конфликтовала с более поздними уточнениями определения ПДн.
Её содержательные материалы уже присутствовали в main: актуальная версия
добавляет ссылки на рабочую инструкцию MVP и отделяет старые предложения
о скоре и любых двух оранжевых маркерах от действующих правил.

## Доказательство

Сравнение исходной вершины PR с main после слияния #47:

```powershell
git diff 2b5aff7b688e4f02e12e0b0fd17f3d175766aebd 0e60202 -- docs/kb/pii-definition.md docs/project/open-questions.md docs/project/drafts/mentor-questions-2026-11.md docs/project/stage-1-updates-2026-11-01.md
```

В разрешении конфликта сохранена версия main. Рабочие правила и типы берутся из
[инструкции разметки](../data/annotation-guidelines.md), ограничения runtime — из
[описания сервиса](../api/service-scaffold.md). Исторические материалы сохраняются
с исходными оговорками; новых правовых выводов это слияние не вводит.

## Что это значит для проекта

Слияние PR #16 завершает старую ветку исследования без возврата прежней политики.
Принятые ADR, инструкция разметки, конфиги и код сервиса не меняются.
Открытые вопросы правовых оснований и независимой проверки разметки этим не закрыты.
