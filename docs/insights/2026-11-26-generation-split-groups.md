# Разделение по сценариям не исключает повторения профилей

- Дата: 2026-11-26.
- Связано: [политика генерации](../data/synthetic-session-generation-policy.md), [подбор риска на разделении 90/90](../experiments/2026-11-25-risk-tuning-90-90.md).

## Что увидели

В описании подбора риска явно допускается повторение элементов синтетических профилей между разными семействами сценариев. Поэтому отсутствие общего семейства само по себе не подтверждает независимость профилей. Это ограничение предыдущего диагностического замера, а не свидетельство измеренной величины утечки.

## Доказательство

Раздел «Метод» связанного эксперимента описывает разделение по семействам и возможность повторения профилей. Новый шаблон задания предусматривает совместную группировку по семейству сценария, семейству профиля и родительскому диалогу перефразирования.

## Что это значит для проекта

Для нового отложенного теста нужны отдельные семейства сценариев и профилей. Если любые две сессии связаны общим шаблоном, профилем или перефразированием, вся связанная группа остаётся в одной части. Когда такие связи объединяют весь корпус, требуется новая генерация тестовых профилей; перемешивание ID проблему не решает.
