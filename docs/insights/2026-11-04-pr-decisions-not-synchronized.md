# Состояние PR и наличие предложения не равны принятому решению

- Дата: 2026-11-04
- Автор: не указан
- Связано: PR #14/#16/#19/#20, issues #10–#13

## Что увидели

Ответы ментора уже находятся в основной ветке. Политика срабатывания,
протокол метрик и контракт сервиса находятся в разных открытых PR;
несколько важных предложений существуют только в ревью. Рабочая ветка
содержит исследовательские документы, которых ещё нет в main.

## Доказательство

Проверенные версии, команды воспроизведения, ссылки на комментарии и
полная матрица вопросов — в
[аудите PR](../project/pr-audit-2026-11-04.md).
В #19 есть отдельное предложение F2-timely, но metrics.md его не содержит.
Основания алерта в постановке #19 и политике #16 различаются.
Для отмеченной в #11 сверки с задачей данных в проверенных PR нет общего
артефакта разметки или схемы. Это пробел подтверждения, не доказательство
отсутствия обсуждения вне репозитория.

## Что это значит для проекта

Следует учитывать отдельно ответ ментора, исследовательский результат,
предложение и принятое решение. До основной генерации данных нужно
свести политику срабатывания, эталон момента и метрики. Выводы из ревью
нужно переносить в согласованные документы, сохраняя источник и статус.
