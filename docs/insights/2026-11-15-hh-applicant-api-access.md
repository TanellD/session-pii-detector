# Документация метода hh не подтверждает доступность для исследования

- Дата: 2026-11-15.
- Основание: уточнение пользователя о прекращении поддержки API для соискателей 15 декабря 2025 года.

## Что увидели

Ранее сборщик был представлен как доступный путь получения агрегатов, а отказ — как возможная капча или требование токена. Такое объяснение недостаточно: действуют ограничения вида доступа и назначения приложения. Одного наличия метода в документации недостаточно.

## Доказательство

В [официальном описании API](https://github.com/hhru/api) различаются анонимный доступ, авторизация приложения, соискателя и работодателя. Доступность поиска для нашего приложения не подтверждена. Пробный запуск `python -X utf8 tools/collect_hh_occupation_statistics.py` вернул HTTP 403; он не доказывает конкретную причину отказа. Дата прекращения поддержки принята из уточнения пользователя; отдельное официальное уведомление с этой датой при текущей проверке не найдено.

## Что это значит для проекта

Сборщик остаётся инструментом диагностики и работы с подтверждённым доступом. Токен соискателя не предлагается как решение. Для получения статистики нужен разрешённый приложению доступ либо опубликованные агрегаты hh/официальные показатели занятости. Изменены диагностическое сообщение и инструкция; получение распределения не заявляется выполненным.
