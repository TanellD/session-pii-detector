# Ответ времени VK не доказывает действительность ключа для groups.getMembers

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [выборка участников сообщества](../research/notes/vk-community-member-pairs-2026-11-16.md).

## Что увидели

При успешном ответе utils.getServerTime метод groups.getMembers вернул явное сообщение об истёкшем access_token. Предыдущее толкование служебного запроса как достаточной проверки «рабочего ключа» было слишком сильным. Оно не заменяет проверку целевого метода и текста его отказа.

## Доказательство

Обезличенные диагностические JSON в `data/private/name-dependence/`; команды их чтения указаны в исследовательской заметке. Текст отказа содержит `access_token has expired`. Секрет и request_params не записываются в отчёт. Общие ошибки номера без сообщения не интерпретируются как доказательство ограничений типа токена.

## Что это значит для проекта

Нужен обновлённый сервисный ключ, затем новая проверка именно метода участников. Пока нельзя объявить этот метод недоступным для приложения по типу токена или начать оценивать частоты по отсутствующему ответу. Успешно полученные страницы должны сохраняться отдельно для возобновления без повторного скачивания.
