# xgrammar отклоняет uniqueItems в списке владельцев

- Дата: 2026-11-23.
- Автор: команда проекта.
- Связано: [расширение синтетического корпуса](../experiments/2026-11-23-annotation-1000.md).

## Что увидели

После добавления совместных владельцев сервер Gemma отклоняет транспортную
JSON-схему `annotation-quotes-v1`: `uniqueItems` в массиве `person_id` не
поддерживается компилятором xgrammar. Это ошибка совместимости схемы, а не
ошибка распознавания или неподдерживаемый список владельцев как таковой.

## Доказательство

В первом локальном прогоне `data/experiments/radeon/annotation-1000-gemma-2026-11-23/`
сохранены запросы и HTTP-статусы. Последовательный повтор запроса через
`tools/probe_annotation_endpoint.py` вернул сообщение:
`keyword(s) uniqueItems would be ignored` и HTTP 400.
Короткая проба того же endpoint без сложной схемы прошла успешно.

После удаления `uniqueItems` только из транспортной схемы первый запрос повторного
прогона `annotation-1000-gemma-2026-11-23-v2` получил валидный ответ.
Каноническая схема и локальная проверка по-прежнему запрещают дубли владельцев.
Воспроизведение проверки: `python -X utf8 -m unittest discover -s tests -p test_annotation_1000.py`.

## Что это значит для проекта

Принятие одиночных владельцев не доказывает совместимость новой схемы совместной
принадлежности с сервером. Проверка ответа локальным валидатором обязательна:
ослабление транспортного ограничения не меняет контракт разметки.
HTTP 429 при параллельном запуске зафиксирован отдельно; точная квота провайдера
не установлена, повтор выполняется одним потоком.
