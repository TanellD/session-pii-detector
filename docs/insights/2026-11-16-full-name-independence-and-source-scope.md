# Ошибка независимости не сводится к единому множителю частоты ФИО

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [проверка источников и пересчёт](../research/notes/full-name-frequency-validation-2026-11-16.md).

## Что увидели

Карточка russiannames раскрывает реестровое происхождение и предупреждает о редких ошибочных значениях; репрезентативность населения не установлена. Расширенный аудит не нашёл повторов исходного text: прежние совпадения являются коллизиями преобразованных написаний.

## Доказательство

Команды воспроизведения и источники приведены в связанном отчёте. Таблица статьи о российских ФИО непосредственно сравнивает независимые и условные частоты; пересчёт проверен по HTML-источнику. Отношение RMSE измеряет изменение ошибки метода, не отношение истинной частоты к оценённой.

## Что это значит для проекта

Для поправки отдельного сочетания нужен lift; для всего совместного распределения — total correlation. Из одних маргинальных справочников эти показатели не восстанавливаются. Совпадения текстовой нормализации не доказывают повторного подсчёта людей. Основное правило разметки ФИО остаётся исследовательским.
