# Общий контакт может вызвать алерт для другого владельца раньше

- Дата: 2026-11-25.
- Связано: [сложные диалоги](../experiments/2026-11-25-complex-200.md).

## Что увидели

При авторской проверке сюжета общего номера обнаружен более ранний триггер: если у второго человека уже есть личная почта, добавление общего телефона создаёт достаточную пару именно у него, до появления почты первого человека.

## Доказательство

Синтетический порядок: телефон первого → почта второго → телефон явно общий → почта первого. Первый алерт нужен на шаге общего телефона. В генераторе это задано автором, независимо от сервиса. Проверка `test_shared_number_can_trigger_before_last_contact` в `tests/test_complex_200.py`; команда — в связанном эксперименте. Предварительный корпус без этой поправки не используется в запуске.

## Что это значит для проекта

Авторский первый алерт нужно проверять для каждого владельца общего атрибута. Финальный достаточный профиль рассказчика не определяет самый ранний момент алерта всей сессии. Историю неизвестной принадлежности при этом не переписываем задним числом.
