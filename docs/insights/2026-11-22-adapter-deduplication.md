- Дата: 2026-11-22.
- Автор: команда проекта.
- Связано: PR #45.

## Что увидели

При A, B, повтор A прежний break удалял непересекающийся B. Также example.invalid ошибочно делал личную синтетическую почту служебной.

## Доказательство

Регрессии tests/test_adapter_regressions.py; команда python -X utf8 -m unittest discover -s tests -p 'test_adapter*.py'.

## Что это значит для проекта

Дедупликация сохраняет соседние кандидаты. EMAIL сохраняется, служебность определяет линкер. Исторические метрики не подтверждают исправленную версию.
