## Что это значит для проекта

Лид уточнил протокол: ранний первый алерт — строго FP, без FN.
Это заменяет прежнее предложение о двойном учёте из комментария PR.
Recall-timely при таком правиле не является долей своевременно обнаруженных
среди всех положительных сессий; ранние алерты штрафуются через Precision и F2.

Документы протокола можно доработать до запуска baseline.
Открытые вопросы вынесены отдельно; ТЗ предложено без изменения инструкции.
Закрытие #11 требует подтверждения её критериев, а не только обновления файлов.

Проверки пробелов, окончания файлов, конфликтных маркеров и размера файлов
прошли; проверка YAML не применима к изменённым Markdown. Установка Go-окружения
для gitleaks не завершилась и была остановлена. Проверка секретов локально
не подтверждена; требуется повторный запуск полного pre-commit или CI.

