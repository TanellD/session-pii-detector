# Валидный JSON не гарантирует корректные границы сущностей

- Дата: 2026-11-19.
- Связано: [сетевой пилот Radeon](../experiments/2026-11-19-radeon-annotation-pilot.md).

## Что увидели

Gemma приняла запрос и вернула завершённый JSON, но числовой спан включал внешний пробел. Короткая JSON-проба такой ошибки не обнаруживала. После явного перехода на точные цитаты та же синтетическая сессия прошла валидатор.

## Доказательство

Команды сводки и новые исходные/проверенные артефакты перечислены в эксперименте. Без сети результат проверяется `tools/summarize_annotation_runs.py`. Проверки точного выбора вхождения, Unicode-позиций и отказа от похожих строк — `python -X utf8 -m unittest discover -s tests -p test_compatible_annotation_pilot.py`.

## Что это значит для проекта

Разделяем выбор сущности моделью и вычисление её координат инструментом. Транспортный режим фиксируется в манифесте, финальный контракт разметки остаётся прежним. Формальная валидность и согласие моделей не заменяют независимую проверку границ, типов и принадлежности человеком.
