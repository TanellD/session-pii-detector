# Совместные региональные таблицы полезнее независимых частот для разметки

- Дата: 2026-11-15
- Автор: команда проекта
- Связано: #39, #25

## Что увидели

Официальный федеральный XLSX совместного распределения региона, возрастной группы и пола удалось загрузить и прочитать. В региональных каталогах найдены дополнительные разрезы, но сквозное получение региональных файлов не выполнено из-за сетевых тайм-аутов. Наличие заголовка в каталоге не доказывает полное покрытие всех деревень.

БД ПМО документирует получение таблиц через веб-форму и экспорт. Подтверждённого единого публичного REST API для нужных статистик не найдено. ФИАС решает нормализацию адресов, а не подсчёт людей; проверяемый endpoint метаданных выгрузок недоступен из текущего окружения.

## Доказательство

URL, SHA-256 загруженного XLSX, команды воспроизведения, региональные ссылки и статусы API собраны в [справочнике источников](../research/notes/statistics-sources-for-annotation-2026-11-15.md).

## Что это значит для проекта

Для правил разметки сначала использовать зафиксированные совместные таблицы и записывать координаты ячеек. Не строить эталон из произведения маргинальных частот без выбранного соглашения. Для непокрытых сочетаний фиксировать отсутствие основания, а не автоматически отрицательный алерт. Это исследование источников, не измерение качества реализации; инструкция разметки и принятые ADR не менялись.
