# Официальный перечень региональных сайтов шире охвата переписного среза

- Дата: 2026-11-15
- Автор: команда проекта
- Связано: #39, #25

## Что увидели

Официальный каталог Росстата позволил сопоставить территории и управления без угадывания доменов. Часть управлений общая для нескольких регионов, поэтому один каталог нельзя автоматически считать подтверждением одинаковых таблиц для всех обслуживаемых территорий.

Найдены региональные страницы переписи, населения и муниципальных показателей. Отдельные ссылки представлены официальными архивами/PDF. Нахождение публикации через индекс не подтверждает доступность экспорта, содержимое каждой таблицы или покрытие малых деревень. По Приморскому краю подтверждена строка федерального файла, но тематический региональный раздел в проверке не найден. Для дополнительных территорий текущего каталога не найдены строки в выбранном переписном срезе; население им не присваивается автоматически.

## Доказательство

- [Перечень сайтов Росстата](https://www.rosstat.gov.ru/territorial).
- [Реестр ссылок, статусов и координат строк](../research/notes/rosstat-all-regions-2026-11-15.md).
- `configs/rosstat-regional-catalogs.json` содержит найденные тематические URL и степень проверки.

Счётчики и сопоставление воспроизводятся:

```powershell
python -X utf8 tools/build_regional_statistics_registry.py
```

Первоначальная проверка из Python через stdin PowerShell исказила кириллицу в литералах регулярного выражения: нормализация могла превращать названия в пустые ключи. Подсчёты из такой проверки не использованы. Итоговый генератор записан в UTF-8-файле, дополнительно сопоставлены федеральные строки городов федерального значения с суффиксом городского населения. Географические коды и числа жителей из совпадения по одному названию не выводятся.

## Что это значит для проекта

Для разметки нужны фиксированный перечень территорий, отдельная проверка покрытия статистического среза и дата каждого источника. Реестр маршрутов готов для дальнейшего получения таблиц, но он не является единой базой населения всех деревень. Из каталога сохраняются только названия территорий и URL без персональных контактных сведений. Принятые ADR и инструкция разметки не менялись.
