# Рецензент может принять тёзок за противоречие

- Дата: 2026-11-26.
- Автор: авторский разбор рабочей ветки.
- Связано: [пробная генерация v2](../experiments/2026-11-26-generation-v2-trial.md), PR #47.

## Что увидели

В слепом ревью новой партии Gemma назвала противоречием две ситуации с одинаковым именем и разными фамилиями. В авторском разборе это разные явно представленные люди. Модель не обнаружила фактическую смену фамилии одного человека, а предположила её по совпадению имени.

## Доказательство

Синтетический пример `v2trial-016`: автор представляется «Шабломир Демонов», затем сообщает: «Отдельный заказ оформил Шабломир Тестоградов». Рецензент предлагает revise из-за совпадения имени. Тексты и исходные замечания сохранены вне git; команда воспроизведения — `--report-only` в связанном эксперименте.

## Что это значит для проекта

Сохранять цитаты недостаточно: цитата может быть настоящей, а объяснение ошибочным. Замечания о противоречии нужно разбирать по полному контексту. Не стоит автоматически удалять тёзок или принимать любой verdict=revise; авторское отклонение замечания также не заменяет независимого ревью.
