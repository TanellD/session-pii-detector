# Временная роль организатора требует отдельного разбора класса occupation

- Дата: 2026-11-24.
- Автор: команда проекта.
- Связано: [повторный аудит аннотаций](../experiments/2026-11-24-annotation-update-audit.md).

## Что увидели

В `andrey-500-0002` Qwen выделила `организатора` как `occupation` конкретного
человека из реплики «Меня зовут Черновимир, второго организатора — Пробослава».
В авторской разметке есть только имена. По контексту обсуждается организация
встречи, а не явно описанная профессия. Это неоднозначная граница класса:
название роли может описывать временную функцию или род занятий.

## Доказательство

Снимок и обе версии аннотации сохранены в
`data/experiments/annotation-update-review-2026-11-24/`.
Воспроизведение без API:

```powershell
python -X utf8 tools/review_annotation_update.py --output data/experiments/annotation-update-review-2026-11-24 --check
```

Дополнительный спан не изменил первый алерт на этой сессии. Модель правильно
сохранила совместных владельцев телефона и единственного владельца почты.

## Что это значит для проекта

Одного расхождения недостаточно, чтобы назвать модельный ответ ошибкой или
молча дополнить gold. Нужно явно разобрать временные роли и профессии по ТЗ,
сохранить решение и применить его к новой версии данных/инструкции.
Текущие правила и исходные аннотации этим наблюдением не меняются.
