# Совместная частота ФИ помогает для известных пар, но проигрывает на невстречавшихся

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [эксперимент](../experiments/2026-11-16-fns-name-pairs-and-fullnames.md).

## Что увидели

Увеличение числа ФИО само по себе не делает эмпирическую таблицу совместных частот пригодной для всех сочетаний. На отложенной части фрагмента ФНС совместная пара улучшает оценку уже встречавшихся ФИ, но в среднем проигрывает независимому приближению из-за невстречавшихся сочетаний.

## Доказательство

Команда: `python -X utf8 tools/research_name_pairs.py`, локальный кеш вне Git. Численные результаты и определения — в [отчёте](../research/notes/fns-wiki-name-pairs-2026-11-16.md). Синтетический XOR-тест показывает отдельную проблему: парные частоты не определяют тройку однозначно.

## Что это значит для проекта

Сохранять различие между измерением связи и качеством её оценки на новых записях. Не выводить общий поправочный множитель из редких клеток. Не объявлять независимость истинной из-за проигрыша плохо сглаженной совместной оценки. Локальный разрешённый кеш позволяет исследовать альтернативы без повторных скачиваний.
