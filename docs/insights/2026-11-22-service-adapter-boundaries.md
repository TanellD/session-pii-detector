# Адаптер подключается один раз, а источник не является весом риска

- Дата: 2026-11-22.
- Автор: команда проекта.
- Связано: [интеграционная проверка](../experiments/2026-11-22-service-adapter-integration.md).

## Что увидели

extract() уже выполняет regex и объединяет его с моделью. Подключение его к NER и повторный regex создают ненужные дубли. Локальные Mention ID сами по себе не уникальны между сообщениями. Старый Docker-контекст также не включал ownership.py, хотя сервис уже импортировал его.

## Доказательство

Сервисные тесты test_adapter_integration.py проверяют один вызов модели при retry, составные ключи после reset, источники и пересечения. Команды и ограничения приведены в эксперименте. Regex-режим действительно извлекает сущности, но с заглушкой линкера возвращает неполноту анализа.

## Что это значит для проекта

Используется один объединённый детектор и пустая вторая стадия. Сервис хранит provenance и составной ключ, отдельно нормализует повторы фактов. Confidence сохраняется для диагностики и не становится риском. Общий PERSON участвует в сумме без автоматического превращения в ФИО. Веса сервиса не создают эталон разметки.
