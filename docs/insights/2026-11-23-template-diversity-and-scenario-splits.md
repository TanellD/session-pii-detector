# Разные синтетические значения не делают сценарии независимыми

- Дата: 2026-11-23.
- Автор: команда проекта.
- Связано: [расширение сценариев Андрея](../experiments/2026-11-23-andrey-500-comparison.md).

## Что увидели

Первый корпус имеет уникальные полные тексты, но значительная часть различий
возникает из замены синтетических значений, обращения и идентификатора заявки.
Второй корпус меняет формулировки прикладных обращений, сохраняя ограниченный
набор исходных сюжетов. Лексическое разнообразие и независимость сценариев —
разные свойства.

## Доказательство

Воспроизведение всех чисел:

```powershell
python -X utf8 tools/compare_synthetic_corpora.py --first data/experiments/annotation-1000-2026-11-23 --second data/experiments/andrey-scenarios-500-2026-11-23 --output data/tmp/corpus-comparison-new
```

После замены авторских спанов обозначениями типов, удаления номера заявки и
нормализации чисел/пунктуации остаётся 360 различных текстов из 1000 в первом
наборе и 500 из 500 во втором. У второго при этом только 16 исходных сценариев.
На уровне последовательности типов и владельцев у источников есть 4 общих
структурных шаблона. Это консервативная диагностика, не полная оценка утечки.

Отдельная проверка склонения единицы возраста нашла 20 примеров вида «31 лет»
в первом наборе и ни одного во втором. Исходный первый набор не исправляется
во время активной разметки: для правки нужна новая версия, иначе изменится вход
уже сохранённых API-запросов.

## Что это значит для проекта

Нельзя случайно распределить все варианты по обучению и тесту и считать тест
независимым. При объединении нужно сохранять источник и сценарий, группировать
похожие формулировки и проверить смысловые пересечения между источниками.
Исходное разделение Андрея development/test само по себе не защищает от
пересечений с первым корпусом, где это разделение ещё не создано.

Структурные шаблоны слишком грубы, чтобы автоматически удалять все совпавшие
сессии: одинаковые типы атрибутов могут встречаться в разных полезных задачах.
Их следует использовать как сигнал для ревью разбиения.
