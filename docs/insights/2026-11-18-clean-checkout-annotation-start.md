# Запуск разметки из чистого checkout требует отдельного режима без справочников

- Дата: 2026-11-18.
- Связано: [инструкция работы с ТЗ](../data/annotation-workflow.md).

## Что увидели

Локальный калькулятор при создании безусловно открывал файлы статистических справочников из игнорируемого `data/`. Поэтому примеры, работавшие в исследовательском окружении, не запускались бы у нового участника после клонирования ветки.

## Доказательство

Добавлен явный `--policy-only` для обработчика и материализации LLM-пилота. Он использует конфиг, не загружает локальные таблицы профессий, географии и жилья и не подменяет их содержимое синтетическими значениями. Регрессии: `python -X utf8 -m unittest discover -s tests -p test_annotation_onboarding.py`. Команды первого запуска проверяются отдельно без локального `data/`.

## Что это значит для проекта

README должен различать запуск без справочников, полный численный режим и новый внешний LLM-вызов. Нельзя выдавать воспроизведение сохранённой разметки за новую генерацию или обещать восстановление всех исходников одной командой, которой пока нет.
