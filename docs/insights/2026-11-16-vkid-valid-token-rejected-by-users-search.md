# Токен принят VK ID, но отклонён users.search

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [проверка доступа VK](../research/notes/vk-api-name-pairs-setup-2026-11-16.md).

## Что увидели

Пользователь успешно завершил авторизацию PKCE. Сохранённый токен не истёк по метаданным и принят официальным VK ID user_info. При этом VK API отклоняет его как на получении страны, так и на отдельном прямом поиске пользователей. Выборка аккаунтов не получена.

## Доказательство

Код ошибки — 5 (`User authorization failed`) согласно [официальной схеме VK](https://raw.githubusercontent.com/VKCOM/vk-api-schema/master/errors.json). Это не код недостатка разрешения. Обезличенные результаты сохранены в `data/private/name-dependence/vk-users-search-access.json` и `vk-token-access-diagnostic.json`; команды проверки и чтения указаны в заметке. Ни токен, ни значения пользовательского объекта не экспортировались в отчёт.

## Что это значит для проекта

Успешный вход через VK ID и готовность исследовательского поиска — отдельные результаты. Истечение или подмена токена не объясняют этот конкретный отказ. Нужно уточнять принимаемый VK API пользовательский доступ для приложения; повторная выдача того же типа токена сама по себе не обоснована. Не распространять результат одной проверки на все типы приложений и токенов VK ID.
