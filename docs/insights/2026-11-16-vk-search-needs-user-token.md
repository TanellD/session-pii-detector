# Доступ к users.get не подтверждает доступ к users.search

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [подготовка VK API](../research/notes/vk-api-name-pairs-setup-2026-11-16.md).

## Что увидели

В официальной схеме поиск пользователей требует пользовательского типа токена; получение записи пользователя допускает и другие типы. Простая настройка сервисного ключа не закрывает задачу получения исследовательской выборки. Отдельное поле отчества в проверенной схеме не найдено.

## Доказательство

[Схема методов VKCOM](https://raw.githubusercontent.com/VKCOM/vk-api-schema/master/users/methods.json), [поля профиля](https://raw.githubusercontent.com/VKCOM/vk-api-schema/master/users/objects.json). Локальная готовность проверяется командой `python -X utf8 tools/collect_vk_name_pairs.py`, без вывода секрета и сетевого обращения. Пользователь подтвердил отсутствие доступа; фактический поиск ещё не выполнялся.

## Что это значит для проекта

Сначала зарегистрировать подходящее приложение и проверить конкретный метод официальным пользовательским токеном. Сбор ФИ и исследование полного ФИО вести раздельно. Не обещать национальную выборку по ранжированной выдаче и не выдавать неподтверждённую инструкцию старого OAuth за актуальную.
