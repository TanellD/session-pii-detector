# Явное ФИО в статье доступнее заполненных свойств Викиданных

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [эксперимент](../experiments/2026-11-16-wikipedia-explicit-fullnames.md).

## Что увидели

Покрытие структурированного патронима нельзя использовать как оценку доступности отчества в тексте статьи. Узкое правило извлечения начала статьи даёт существенно больше совместных наблюдений. При этом большое сырое TC тройки почти повторяется на перестановочном фоне: разреженность делает его плохим самостоятельным доказательством зависимости.

## Доказательство

Команды: `python -X utf8 tools/pilot_wikipedia_fullnames.py --download` и `python -X utf8 tools/pilot_wikipedia_fullnames.py`.

В пилоте получены начала всех 500 статей; поддерживаемые ФИО — 468, все три структурированных свойства заполнены у 15 элементов. TC около 12,16 бита практически совпадает с перестановочным фоном. Для имени и отчества обнаружено превышение фона в объединённой выборке, требующее проверки согласования по полу и других смешивающих факторов. См. [сводку](../research/notes/wikipedia-explicit-fullnames-2026-11-16.md).

## Что это значит для проекта

Разделять доступность структуры и текста, наблюдаемое и восстановленное отчество. Не делать вывод о независимости или российской частоте из одного TC и не переносить lift редких клеток на население. Семейные связи сохраняют отдельный статус проверки доступности.
