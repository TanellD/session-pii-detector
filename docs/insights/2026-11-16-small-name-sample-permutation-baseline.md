# Малый список может показывать зависимость даже после перемешивания имён

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [пилот](../experiments/2026-11-16-public-fullname-pilot.md).

## Что увидели

В небольшом списке с уникальными фамилиями и отчествами высокая эмпирическая total correlation сохраняется после случайного перемешивания колонок. Её нельзя трактовать как готовую поправку независимости ФИО.

## Доказательство

`python -X utf8 tools/pilot_public_fullname_statistics.py` показывает сохранённую сводку и перестановочный фон. Синтетическая проверка эффекта: `python -X utf8 -m unittest discover -s tests -p test_public_fullname_pilot.py`.

## Что это значит для проекта

Открытые списки позволяют начать работу, но численность выборки и единица подсчёта должны сопровождать результат. Нужны повторения значений и внешняя проверка. Нельзя автоматически считать строки, аккаунты или совпавшие ФИО уникальными людьми.
