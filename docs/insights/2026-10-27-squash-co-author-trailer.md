# Squash-мерж на GitHub переносит Co-authored-by из коммитов ветки

- Дата: 2026-10-27
- Автор: @TanellD
- Связано: PR #1

## Что увидели
При squash-мерже GitHub добавляет в итоговый коммит трейлеры `Co-authored-by` из всех коммитов ветки. Это происходит даже тогда, когда сообщение squash-коммита берётся из описания PR (`squash_merge_commit_message = PR_BODY`), а в описании трейлера нет.

## Доказательство
В PR #1 первый коммит ветки содержал `Co-Authored-By: Claude …`. Перед мержем в настройках репо включили сообщение из описания PR, само описание было чистым. В итоговом коммите `c7fd169` в `main` трейлер всё равно оказался: `git log -1 --format=%B c7fd169`.

## Что это значит для проекта
- Настройка сообщения squash-коммита не защищает от лишних соавторов. Трейлер надо убирать из коммитов ветки до мержа (переписать коммит) или вычищать вручную в диалоге мержа.
- Правило в AGENTS.md запрещает указывать AI-агентов соавторами. Агенты не должны добавлять трейлер с самого начала.
- `c7fd169` решили не переписывать: для этого нужен force-push в защищённый `main`.
