# Перенос корпуса и разметки в main

- Дата: 2026-11-22.
- Автор: команда проекта.
- Связано: PR #44, слитые PR #45 и #46.

## Что увидели

После squash-слияния адаптера в main согласование ветки разметки потребовало разрешения повторных конфликтов в regex_detector.py, инструкции разметки и открытых вопросах. Это конфликт истории: реализация адаптера уже присутствует в обеих ветках.

## Доказательство

Сохранены текущая полная сессионная инструкция, совместные владельцы и необязательный параметр require_valid_checksum для исторических запусков; по умолчанию checksum остаётся фильтром. Дополнительные вопросы адаптера сохранены отдельно. Принятые ADR не менялись, данные вне Git.

Проверки: python -X utf8 -m unittest discover -s tests и pre-commit run --all-files. Подробности функциональной проверки — docs/experiments/2026-11-22-corpus-finalization.md. Конфликты разрешены в отдельной рабочей копии без изменения пользовательских незакоммиченных файлов.

## Что это значит для проекта

PR переносит ТЗ, калькулятор, код корпуса и оценку Андрея в main вместе с совместимым адаптером. HTTP-сервис ветки feat/session-service сюда не включён. Новому gold по-прежнему требуется независимая проверка; исторические результаты не объявляются качеством новой политики.
