# Подготовка модели и сеть отделены от offline-проверки

- Дата: 02.11.2026.
- Автор: `Kopylov-Andrey`.
- Связано: #12, `benchmarks/pii_smoke/prepare.py`.

## Что увидели
В ограниченной оболочке pip не подключался к proxy; стандартный ensurepip venv
завершился ошибкой. Venv без ensurepip с системным pip/PyTorch позволил изолировать
новые зависимости. Requests при загрузке модели встретил недоверенную цепочку TLS.

## Доказательство
Подготовка через `python -m benchmarks.pii_smoke.prepare` завершилась с проверкой
сертификатов из доверенного хранилища Windows через truststore из pip.
Веса и backbone зафиксированы в конфиге; измерение выполнено с HF/Transformers offline.

## Что это значит для проекта
Не отключать TLS-проверку. Скачать веса отдельно, исключить загрузку из времени
inference. На другой машине использовать команды README и отдельно установить
PyTorch. Внешний inference и передача текстов не используются.
