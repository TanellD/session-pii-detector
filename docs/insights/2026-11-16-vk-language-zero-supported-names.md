# Ноль поддерживаемых имён возник из-за языка ответа VK API

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [сбор участников VK](../research/notes/vk-community-member-pairs-2026-11-16.md), [эксперимент](../experiments/2026-11-16-vk-community-language-fix.md).

## Что увидели

Страницы groups.getMembers были непустыми, но все открытые активные записи отклонялись кириллическим фильтром. Поля имени и фамилии присутствовали и в проверочном запросе были представлены латиницей. Явное lang=ru изменило представление на кириллическое и дало поддерживаемые пары.

## Доказательство

Обезличенные диагностики `data/private/name-dependence/vk-name-script-diagnostic.json` и `vk-name-language-diagnostic.json` фиксируют только наличие полей, письменность и счётчики. Исправленный корпус и сводка получены командой `python -X utf8 tools/collect_vk_group_members.py --group vk --limit 10000 --download`; локальный пересчёт — та же команда без `--download`.

## Что это значит для проекта

Язык ответа — часть конфигурации и версии кеша. Успешный HTTP-ответ с пустым результатом фильтра нужно объяснять причинами исключения, не объявлять успешной готовой выборкой. Для повторного анализа сохранять минимальные исходные поля разрешённой локальной выборки до фильтрации. Старые версии не смешивать с новой.
