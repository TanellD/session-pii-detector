# Частоты частей имени доступны, но знаменатель остаётся вопросом

- Дата: 2026-11-15.
- Связано: [уточнения оценщика](../project/annotation-estimator-next-steps-2026-11-15.md).

## Что увидели

У `datacoon/russiannames` подтверждены отдельные агрегаты имени, фамилии и отчества; DataCrafter описывает счётчики. Это конкретный доступный кандидат сверх рейтингов новорождённых. Однако разрозненная выборка не становится распределением нынешнего населения после простого нормирования. Частоты полного ФИО этим не подтверждены.

## Доказательство

[Дерево репозитория](https://github.com/datacoon/russiannames/tree/master/data), [схема счётчиков](https://data.apicrafter.ru/tables/russiannames/names/schema). Проверка доступа без сохранения персональных записей: `python -X utf8 tools/check_annotation_source_access.py`. Каталог Росстата доступен, но дата нового плана или обновления страницы не доказывает наличие свежих наблюдений; найденные файлы и их даты требуют отдельной проверки. Поиск вакансий hh из текущей среды вернул HTTP 403; доли вакансий не рассчитаны.

## Что это значит для проекта

Возраст можно исключить из признаков человека, сохранив его во внутреннем взвешивании общепопуляционной частоты имени. Для hh значение `other` закрывает классификацию, но не смещение платформы относительно всех работников. Неопознанную профессию нельзя объявлять редкой и уменьшать круг из-за отсутствия в справочнике.
