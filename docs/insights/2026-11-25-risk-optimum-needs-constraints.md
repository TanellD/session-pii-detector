# Максимум F2 может разрешить алерт по одиночному контакту

- Дата: 2026-11-25.
- Связано: PR #47, [эксперимент 90/90](../experiments/2026-11-25-risk-tuning-90-90.md).

## Что увидели

Свободный подбор весов по F2-timely повышает вес телефона и адреса выше порога персоны. Обязательные качественные правила при этом формально сохраняются, но численный путь даёт алерт от одного атрибута. Хорошая агрегированная метрика не гарантирует сохранения смысла политики.

## Доказательство

Скрипт `tools/tune_runtime_risk.py` и замороженный вход из эксперимента воспроизводят свободный поиск, поиск с ограничениями и отдельную проверку порога неизвестных. Для всех кандидатов расчёт совпадает с настоящим RiskEvaluator. Исходные предсказания модели и эталон при подборе не изменяются.

## Что это значит для проекта

Нужно задавать смысловые ограничения поиска до внедрения весов и отдельно показывать FP0, временные ошибки и покрытие неизвестных владельцев. Неизменность метрик на проверке при изменении порога неизвестных означает недостаток подтверждений эффекта. Следующий замер должен использовать свежие сценарии; повторная настройка по уже просмотренной проверочной половине требует нового отложенного теста.
