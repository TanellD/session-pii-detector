# Словесная запись чисел меняет первый алерт

- Дата: 2026-11-19.
- Связано: [переразметка CONFIDE](../experiments/2026-11-19-confide-reannotation.md), draft PR #44.

## Что увидели

В синтетических диалогах полный личный телефон сначала произносится словами, а затем подтверждается цифрами. ТЗ требует полное значение, но валидатор телефона требует цифровую запись. Для возраста также допускается только цифровая форма; словесный СНИЛС не даёт полного красного маркера в обработчике.

## Доказательство

Воспроизведение текущих моментов и пометок: `python -X utf8 tools/review_confide_annotations.py --check`. Указатели на словесные упоминания и потенциальные более ранние моменты находятся в локальном `review-notes.json` и отчёте эксперимента. Сами значения остаются вне Git.

## Что это значит для проекта

Проверка JSON не гарантирует, что раннее полное упоминание не пропущено. До согласования словесных чисел полученные первые моменты нельзя выдавать за окончательный эталон. Исходный текст менять для прохождения валидатора нельзя. Нужны решение по ТЗ и отдельная нормализация полных словесных значений с сохранением исходных границ; текущая работа их не вводит молча.
