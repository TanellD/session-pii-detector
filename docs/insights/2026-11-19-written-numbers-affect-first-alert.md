# Словесная запись чисел меняет первый алерт

- Дата: 2026-11-19.
- Связано: [переразметка CONFIDE](../experiments/2026-11-19-confide-reannotation.md), draft PR #44.

## Что увидели

В синтетических диалогах полный личный телефон сначала произносится словами, а затем подтверждается цифрами. ТЗ требует полное значение, но валидатор телефона требует цифровую запись. Для возраста также допускается только цифровая форма; словесный СНИЛС не даёт полного красного маркера в обработчике.

## Доказательство

Воспроизведение текущих моментов и пометок: `python -X utf8 tools/review_confide_annotations.py --output data/experiments/confide-annotation-review-2026-11-19-numeric-only --check`. Указатели на словесные упоминания, прежние сомнения и принятое решение находятся в локальном `review-notes.json` и отчёте эксперимента. Сами значения остаются вне Git.

## Что это значит для проекта

Проверка JSON не гарантирует, что раннее полное упоминание не пропущено. Пользователь уточнил границу MVP: телефон, СНИЛС и возраст пока учитываются только в цифровой записи. Это закреплено в ТЗ, таблице классов и задании LLM. Поддержка словесных чисел не вводится; исходный текст не меняется. Прежние пометки неуверенности остаются историческими, но новые такие случаи сами по себе больше не требуют пометки. Независимая проверка разметки человеком всё ещё необходима.
