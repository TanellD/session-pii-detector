# Предупреждение о подтверждении профиля не устанавливает причину ошибки VK ID

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [настройка VK ID](../research/notes/vk-api-name-pairs-setup-2026-11-16.md).

## Что увидели

Пользователь получил общую ошибку загрузки уже на стороне VK ID и сообщил о требовании подтверждения профиля в кабинете. Callback не получен. Формат PKCE-запроса соответствует описанной структуре, однако действительность настроек приложения и наличие блокировки извне не подтверждены.

## Доказательство

Сообщение пользователя и [официальный раздел создания приложения](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application), ранее прочитанный в этой сессии. Раздел различает предупреждения о необходимости подтверждения и блокировку приложения. Повторное прямое чтение страницы не вернуло ожидаемых текстовых фрагментов, поэтому новых выводов о текущем интерфейсе из него не сделано. Секреты и авторизационная ссылка не сохранялись.

## Что это значит для проекта

Сначала владелец проверяет статус и подтверждение в кабинете, затем выполняется новая попытка входа. Не объявлять профиль доказанной причиной общего сбоя и не ослаблять PKCE или проверки callback ради такого сообщения. Документы подтверждения вводятся владельцем только на стороне VK.
