# VK: ошибка Flood control при расширении выборки

- Дата: 2026-11-17.
- Автор: команда проекта.
- Связано: [выгрузка миллиона записей](../experiments/2026-11-16-vk-million-pair-sample.md).

## Что увидели

Коллектор остановился с `ApiFailure`, кодом 9. Это `Flood control` по официальной схеме VK. В той же схеме превышение числа запросов в секунду обозначено отдельным кодом 6. По одному коду 9 нельзя установить конкретную квоту, срок ограничения или доказать истечение токена.

## Доказательство

[Официальная схема ошибок VK](https://github.com/VKCOM/vk-api-schema/blob/master/errors.json), разделы `api_error_flood`, `api_error_too_many`, `api_error_auth`. Локальный диагностический файл `data/private/name-dependence/vk-groups-last-attempt.json` содержит только безопасный код и тип ошибки; исходный ответ с параметрами авторизации не сохраняется.

Команда продолжения из корня проекта:

```powershell
python -X utf8 tools/collect_vk_group_members.py --group vk --limit 1000000 --token-type service --download
```

Код пропускает существующие страницы с актуальными языком и версией обработки и запрашивает первую отсутствующую страницу плана. Кеш удалять или переименовывать не требуется.

## Что это значит для проекта

Повторный запуск продолжает сбор, но не гарантирует снятия внешнего ограничения. При повторении кода 9 не запускать частые циклы повторов; выдержать паузу и уточнить действующие ограничения в кабинете или поддержке VK. Подтверждённого интервала ожидания у нас нет. Коллектор сохраняет успешные страницы; итоговый анализ полного плана требует завершения всех его страниц.

## Ограниченные повторы и настраиваемая пауза

Добавлены `--delay-seconds` (по умолчанию 1, допустимо 1–3600) и `--max-retries` (по умолчанию 4, допустимо 0–10). Бюджет повторов общий для запуска, не сбрасывается после каждой успешной страницы. Код 6 повторяется с базовой экспоненциальной задержкой 1, 2, 4… секунды, код 9 — 60, 120, 240… секунд. Верхняя граница экспоненциальной составляющей — 900 секунд. Фактическая пауза не меньше `--delay-seconds`. Степень увеличивается при последовательных ошибках одного запроса и сбрасывается после успеха; бюджет всего запуска не сбрасывается. Это настройки клиента, не обещание снятия ограничений VK.

После исчерпания бюджета сбор останавливается. Авторизационные отказы, CAPTCHA и остальные коды не повторяются. Логи повторов содержат только код, длительность ожидания и счётчики; токены и исходные ответы ошибок не печатаются. Параметры политики и использованный бюджет входят в завершённую сводку.

Команда с увеличенной обычной паузой и ограниченным бюджетом:

```powershell
python -X utf8 tools/collect_vk_group_members.py --group vk --limit 1000000 --token-type service --download --delay-seconds 3 --max-retries 4
# Синтетические проверки без сети, в том числе повторы и остановка:
python -X utf8 -m unittest discover -s tests -p 'test_vk*.py'
```

Таблица общих лимитов из сторонней статьи не подтверждает квоту конкретного сервисного ключа. В [официальной схеме execute](https://github.com/VKCOM/vk-api-schema/blob/master/execute/methods.json) заявлены типы `user` и `group`, без `service`. Это основание не подключать `execute` к текущему сервисному сборщику без отдельной проверки доступности. Умножение пропускной способности на число вложенных вызовов не принимается за гарантированное ускорение или снятие Flood control.

## Минимальная проверка сохраняющегося отказа

2026-11-17 выполнены два запроса `groups.getMembers` с сервисным ключом, без автоматических повторов, по одной записи каждый: начало списка и первая отсутствующая страница текущего плана. Между ними была пауза. Оба вернули `ApiFailure`, код 9. Записи профилей не сохранялись. Это подтверждает сохраняющийся отказ API и для минимального запроса с начальным смещением; причиной нельзя считать только большой offset или попытку получить миллион записей одним вызовом.

Диагностика без токена и персональных строк доступна локально. Прочитать результат без новых запросов:

```powershell
python -X utf8 -c "from pathlib import Path; print(Path('data/private/name-dependence/vk-flood-minimal-diagnostic.json').read_text(encoding='utf-8'))"
```

Из этого опыта нельзя определить область ограничения: токен, приложение, аккаунт, IP, метод или их сочетание. Нельзя установить и срок снятия. Паузы клиента не отменяют серверное ограничение. Для точного объяснения нужны сообщения кабинета или ответ поддержки с ID приложения, методом и временем отказов; секреты в обращение не включаются. Новая успешная выгрузка этой диагностикой не заявляется.
