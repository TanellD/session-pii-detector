# Локальный callback VK ID требует отключить логирование URL

- Дата: 2026-11-16.
- Автор: команда проекта.
- Связано: [помощник авторизации VK ID](../research/notes/vk-api-name-pairs-setup-2026-11-16.md).

## Что увидели

Код, state и device_id приходят в URL callback. Стандартный HTTP-лог локального сервера сохранил бы строку запроса. Даже при отсутствии access token в URL такой лог содержит временные данные авторизации.

## Доказательство

[Официальный поток VK ID](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/start-integration/auth-without-sdk/auth-without-sdk-web). В `tools/authorize_vk_id.py` отключён `log_message`, исключения печатаются без URL и текста ответа. Callback использует no-store и no-referrer, не загружает внешние ресурсы и после сохранения перенаправляет на страницу без параметров. Проверки выполняются командой `python -X utf8 -m unittest discover -s tests -p test_vk_id_authorization.py` на синтетических значениях.

## Что это значит для проекта

Для реального входа пользователь работает в браузере провайдера. Секреты сохраняются только в игнорируемый `.env`; проверка транспорта и callback не означает, что токен уже получен или что доступ к поиску подтверждён. Приложение и вход пользователя остаются необходимыми внешними шагами.
