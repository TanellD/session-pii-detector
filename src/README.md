# src/

`session_pii/` — запускаемый каркас HTTP-сервиса. Точки замены NER, regexp и линкера находятся в `components.py`; сборка компонентов — в `app.py`. [Запуск и интеграция](../docs/api/service-scaffold.md). Базовый режим подключает regex-адаптер и заглушку линкера, сообщая о неполноте анализа. GLiNER включается явно для локальной модели.
